Для соседних пар N = 1 проверяет отсутствие пар, а три числа — перекрытие двух пар. Отрицательные подходящие суммы выявляют неправильное начальное значение максимума. Тест должен иметь объяснимую причину и независимо вычисленный ожидаемый результат.'
