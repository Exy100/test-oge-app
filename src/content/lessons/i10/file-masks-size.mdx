<Theory>
  <h3>Сначала область, затем расширения</h3>
  <p>
    Имя обычно состоит из основной части и расширения после последней точки.

    Для подтверждённого №12 объедини файлы всех перечисленных расширений из всех
    заданных каталогов, включая вложенные. Считай полные пути, а не одинаковые
    имена.
  </p>

  <h3>Что означает маска</h3>
  <p>
    В этой лаборатории * заменяет любое число знаков, включая ноль; ? — ровно
    один знак. Маска применяется ко всему имени, без пути и без учёта регистра;
    точка обычная. Поэтому note_?.txt не выбирает note_ab.txt, а note_*.txt
    выбирает. Синтаксис реального файлового менеджера может отличаться: не
    переноси правило без проверки.
  </p>
  <svg role="img" viewBox="0 0 450 160" aria-label="Две подстановки">

    </text>
    <text x="14" y="81" fill="currentColor">
      {'? → ровно один знак'}
    </text>
    <text x="14" y="124" fill="currentColor">
      {'Маска имени не содержит путь'}
    </text>
  </svg>
  <h3>Количество и размер — разные ответы</h3>
  <p>
    Количество файлов — число выбранных путей. Объём — сумма размеров их
    содержимого в байтах. Для текста UTF-8 число символов не равно числу байтов.
    В лаборатории 1 КиБ = 1024 байта; размер ZIP и занятое место на диске не
    участвуют. В экзамене используй единицы и условия конкретного задания. Маски
    и вычисление объёма здесь не подменяют подтверждённый формат подсчёта
    расширений.
  </p>
