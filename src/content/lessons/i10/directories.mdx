<Theory>
  <h3>Имя не определяет файл целиком</h3>
  <p>

    набора описывает цепочку папок и имя файла. Два файла с одинаковым именем в
    разных папках — разные объекты. В учебных путях используем /; файловый
    менеджер Windows может показывать обратный слеш.
