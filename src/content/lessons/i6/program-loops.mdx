<Theory>
<h3>for перебирает диапазон</h3>
<p>В Python range(1, n + 1) даёт целые от 1 до n включительно: правая граница n + 1 не входит. В лаборатории в сумму добавляются только чётные i. Не смешивай сумму отобранных чисел и число подходящих итераций.</p>
<svg role="img" viewBox="0 0 400 150" aria-label="Трасса цикла while">
<title>Трасса цикла while</title>
<rect x="4" y="4" width="392" height="140" rx="8" fill="none" stroke="currentColor" />
<text x="14" y="35" fill="currentColor">{'Проверка → ложь → выход'}</text>
<text x="14" y="77" fill="currentColor">{'Проверка → истина → тело'}</text>
<text x="14" y="119" fill="currentColor">{'После тела → новая проверка'}</text>
</svg>
<h3>while сначала проверяет условие</h3>
<p>Тело выполняется, пока условие истинно. Перед первым проходом оно тоже проверяется, поэтому возможны ноль итераций. После тела нужно вновь проверить условие на обновлённом состоянии. В режиме суммы цифр n // 10 удаляет последнюю цифру, а n % 10 извлекает её.</p>
<svg role="img" viewBox="0 0 400 150" aria-label="Разные роли переменных">
<title>Разные роли переменных</title>
<rect x="4" y="4" width="392" height="140" rx="8" fill="none" stroke="currentColor" />
<text x="14" y="35" fill="currentColor">{'i или n: управляет обходом'}</text>
<text x="14" y="77" fill="currentColor">{'s: накапливает результат'}</text>
<text x="14" y="119" fill="currentColor">{'Условие решает, что добавить'}</text>
</svg>
<h3>Следи за изменением состояния</h3>
<p>Записывай отдельно управляющую переменную и накопитель. Ноль внутри записи числа не завершает while n > 0: важна вся оставшаяся часть n. При n = 0 тело не выполнится, и начальная сумма останется нулём. Для трассировки лаборатория ограничивает for числом n ≤ 20; это предел упражнения, не правило Python.</p>
</Theory>

<Mistakes>
<Mistake title="Включить правую границу range">
<p>range не включает свою правую границу; в range(1, n + 1) последнее значение равно n.</p>
</Mistake>
<Mistake title="Выполнить while хотя бы раз всегда">
<p>Условие проверяется до тела. При ложном начальном условии итераций нет.</p>
</Mistake>
<Mistake title="Остановиться на нулевой цифре">
<p>Для while n > 0 проверяется оставшееся число целиком, а не digit. Нулевая цифра просто добавляет ноль.</p>
</Mistake>
</Mistakes>
