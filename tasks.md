# tasks.md: план ОГЭ-тренажёра по информатике

Актуализирован 2026-10-05. Архив математического плана — `docs/archive/mathematics/`.

**Правила исполнения** (дополняют PROMPT.md):
- Фазы идут строго по порядку. Задачи внутри фазы — по порядку, если не указано иное.
- У каждой задачи: что сделать, файлы, минимумы, проверка, «Готово, когда».
  Задача принята, только если выполнены **все** пункты «Готово, когда».
- **Gate фазы** — обязательная проверка в конце. Без неё следующая фаза не начинается.
- Отметки: `[ ]` не начато, `[~]` в работе, `[x]` принято. Дублируются в `STATUS.md`.
