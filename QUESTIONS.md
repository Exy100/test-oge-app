# Вопросы и решения текущего проекта

Дата: 2026-10-05. Первый предмет — ОГЭ по информатике.
История математической подготовки сохранена в `docs/archive/mathematics/QUESTIONS.md`.

## Ответы владельца

### Q-I1. Предмет — решён

Ответ: «сначала для информатики делаем сайт». Первая версия и активные документы
переведены на информатику. Математика сохранена для последующего этапа (ADR-004).

### Q-I4. Хостинг — решён ранее

Ответ: «пока в пейджес». Используем GitHub Pages, базовый путь `/test-oge-app/`.
Будущую серверную часть ИИ и заголовки, недоступные на Pages, решаем отдельно
на соответствующем этапе; ограничение отражено в ADR-001.

### Q-I5. Адаптивный поток — решён ранее

Ответ: «нормально - вперед» на предложение 50 % равномерно / 50 % по слабым темам.
Формула сохраняется для 16 номеров, минимум каждого при выборе всех — 3.125 %.
Выбор варианта №13 не создаёт отдельный экзаменационный номер (ADR-002/004).

## Сверка ФИПИ

- Подтверждено проектом 2027: 16 номеров, 150 минут, 21 балл.
- №1–10 — первая часть, №11–16 — компьютерная. Автоматические краткие ответы
  остаются у №11–12; нельзя отождествлять всю вторую часть с файловой самооценкой.
- У №13 две альтернативы, но один балл из максимум 2; №15 и №16 выполняются оба.
- №14 допускает 3 балла. Типы, zod-схемы, подсчёт и контракт ИИ должны учитывать это.
- Подтверждена шкала только 2026: 0–4 / 5–10 / 11–16 / 17–21.
  Окончательные материалы и шкала 2027 остаются UNVERIFIED.
- В демоверсии 2027 есть служебная строка «ПРОЕКТ ОГЭ 2026». Ссылка, название
  и основной колонтитул относятся к 2027; редакционную неоднородность не скрывать.
- Источники, страницы, статусы и контрольные суммы — `docs/exam-format.md`
  и `docs/sources/informatics-2026-10-05.json`.

## Зависимости предстоящих этапов

- Зависимость T1.1/T1.2 закрыта: обе проверки реализованы и входят в verify (ADR-007).
  Полный Gate 1 сохраняется; следующий шаг — T1.3.
- Для T1.3 уже есть реальная приветственная страница с e2e/Lighthouse из T1.1.
  При создании новых страниц в T1.7 проверки расширяются на них.
- GitHub Pages не исполняет Worker и не применяет Cloudflare `_headers`.
  Нельзя объявить эти серверные требования выполненными только наличием файла.
- Генерация ZIP/ODF и интерпретатор «Робота» требуют отдельных проверок T2.10/T2.11.
- В Фазе 7 временные SVG вместо интерактивов допускаются только до T8.10;
  список замен ведётся явно и закрывается перед окончательной проверкой покрытия.
- Название, серверный домен ИИ, модели OpenRouter, бюджет и ответственный за
  проверку учебного контента уточняются перед соответствующими этапами.
- Ключи вводятся в настройках серверной среды, а не в чат или клиентские файлы.

Примеры стартовых и аудиторских сообщений в PROMPT.md — шаблоны, не новые запросы
пользователя. Дополнительных блокирующих вопросов для настройки инструментов нет.
