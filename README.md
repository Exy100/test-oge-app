# Тренажёр ОГЭ по математике

Проект учебного сайта с интерактивными материалами, потоком задач и вариантами
экзамена. Требования находятся в [spec.md](spec.md), порядок разработки —
в [tasks.md](tasks.md), текущий результат — в [STATUS.md](STATUS.md).

На текущем этапе доступна статическая приветственная страница. Фаза 0 посвящена
требованиям, проверке источников и подготовке документов. Приложение на Astro
и npm-команды создаются начиная с T1.1.

## Локальный запуск текущей страницы

Требуется Python 3, установка зависимостей не нужна.
Из корня репозитория:

```bash
cd /workspace/test-oge-app
python3 -m http.server 8000 --bind 127.0.0.1
```

Для проверки из второго терминала:

```bash
curl --fail --silent --show-error http://127.0.0.1:8000/
```

Ожидается HTML со строкой `Добро пожаловать!`. Сервер останавливается `Ctrl+C`.
При работе вне облачной среды сначала перейдите в каталог своей копии репозитория.

## Размещение

Текущий хостинг — GitHub Pages, репозиторий `Exy100/test-oge-app`, ветка `main`,
корень репозитория. Файл `.nojekyll` включает публикацию статических файлов.
Адрес сайта: `https://exy100.github.io/test-oge-app/`.

При переходе на Astro необходимо настроить сборку и публикацию её результата,
а также базовый путь `/test-oge-app/`. Это часть предстоящей настройки фундамента.
Размещение серверной части ИИ рассматривается отдельно; ключи не помещаются
в статические файлы. Подробнее — [ADR-001](DECISIONS.md#adr-001-github-pages-на-текущем-этапе).

## Состояние проверки экзамена

Структура сверена по официальному **проекту 2027 года**, шкала оценок — по
рекомендациям **2026 года**. Это разные источники с разными годами.
Окончательный статус комплекта 2027, шкала 2027 и часть сюжетов открытого банка
остаются UNVERIFIED. Полный перечень ограничений — в `docs/exam-format.md`.

## Порядок работы

Выполнять задачи последовательно, фиксировать фактически запущенные проверки,
обновлять `STATUS.md` и `tasks.md`. Одна задача — один логический коммит вида
`T<фаза>.<номер>: описание`. На границе фазы оформлять отчёт и проверять её критерии.

В Фазе 0 проверяются документы и источники. `npm run verify`, `npm run e2e`
и `npm run lh` пока отсутствуют, поскольку нет `package.json`.
Их отсутствие не следует выдавать за успешный запуск проверок приложения.

Следующая задача после подготовки — T1.1: проект Astro и инструменты разработки.
