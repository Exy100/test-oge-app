Авторский учебный набор №15. CC0-1.0. Открой assignment.txt и source/example.png. Зелёные круги — клетки, которые нужно закрасить; оранжевый крест — Робот, тёмные линии — стены. Крест и круг могут находиться в одной клетке. Исходной закраски нет.
Программа должна решать всё описанное семейство, а не один рисунок. source/family.json содержит параметры восьми проверочных полей; validation/fields.json — их полные схемы. JSON — собственный учебный формат, не файл обстановки «Кумира»: перенеси пример в редактор поля вручную по рисунку и координатам (индексы с 0).
Сохрани программу answer.txt в UTF-8. Язык: использовать Робот / алг / нач / кон; вверх, вниз, влево, вправо, закрасить; датчики сверху/снизу/слева/справа свободно или стена; если ... то / иначе / все; нц пока ... / кц. Одна команда или граница блока на строку. Это ограниченный учебный язык, не полный «Кумир».
После самостоятельного решения сравни с reference/answer.txt. Локальная проверка использует не больше 5000 инструкций на поле, без сохранения полной трассы. Конечная позиция не ограничена. Конечный набор тестов помогает найти ошибки и не является доказательством для всех возможных полей. Учебные критерии 0/1/2 не заменяют официальную экспертную оценку. Персональные данные не нужны.
