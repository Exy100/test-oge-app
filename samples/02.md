# Задание №2 — 12 примеров

## 1. Расшифровка равномерного двоичного кода

Генератор: fixed-code-v1

Seed: "t3.1-review:0"

Каждая буква кодируется тремя битами. Коды записаны слева направо без разделителей.

| Буква | Код |
| ----- | --- |
| А     | 100 |
| Б     | 010 |
| В     | 000 |
| Г     | 001 |
| Д     | 101 |
| Е     | 011 |

Передано: `001101010100011000`. Расшифруй сообщение. Ответ запиши последовательностью заглавных кириллических букв из таблицы, без пробелов; регистр учитывается.

**Ответ:** ГДБАЕВ

### Решение

1. Раздели сигнал на группы по три бита: 001 | 101 | 010 | 100 | 011 | 000.

2. Подставь буквы по таблице: 001 → Г; 101 → Д; 010 → Б; 100 → А; 011 → Е; 000 → В.

3. Соедини буквы в исходном порядке: ГДБАЕВ. Обратное кодирование даёт 001101010100011000.
