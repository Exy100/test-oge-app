## Задание №1

Текст перевели из условной кодировки 8 бит на символ в условную кодировку 16 бит на символ. Объём вырос на 48 байт. Символы текста не изменились; служебных данных нет. Сколько символов в тексте?

**Ответ / эталон:** 48

#### Решение

1. Каждый символ стал занимать на 16 − 8 = 8 бит больше.

2. Это 8 ÷ 8 = 1 байт на символ.

3. Число символов: 48 ÷ 1 = 48.

## Задание №3

Рассматриваются целые X от 0 до 93 включительно. Выражение: `(X кратно 2) ИСКЛЮЧАЮЩЕЕ ИЛИ (X кратно 5)`. Сколько значений X делают выражение истинным? «Кратно» означает делимость без остатка. ИСКЛЮЧАЮЩЕЕ ИЛИ истинно, когда истинно ровно одно из двух условий. Ноль кратен любому положительному целому числу.

**Ответ / эталон:** 46

#### Решение

1. Ноль не подходит: обе делимости для него истинны. Количество положительных кратных 2: 93 ÷ 2 с округлением вниз = 46. Кратных 5: 18.

3. Общие кратные вошли в сумму дважды, а нужны числа только из одной группы: 46 + 18 − 2 × 9 = 46.

## Задание №6

```python
n = int(input())
s = 0
while n > 0:
    digit = n % 10
    if digit >= 4:
        s = s + digit
    n = n // 10
print(s)
```

Какое целое число напечатает программа?

**Ответ / эталон:** 13

#### Решение

2. В сумму входят цифры не меньше 4: 4, 5, 4.

3. Сумма выбранных цифр: 13. При n = 0 цикл заканчивается; вывод: 13.

#### Решение

1. Запомни первое число. Каждое следующее образует пару с предыдущим; при N = 1 пар нет.

2. Для подходящей пары обнови счётчик и максимум. Первая подходящая сумма задаёт максимум даже тогда, когда она отрицательная.

3. На каждом шаге сохраняй текущее число как предыдущее. Так соседние пары могут перекрываться; при отсутствии подходящих выведи 0 0.

```
n = int(input())
previous = int(input())
count = 0
best = 0
for i in range(n - 1):
    current = int(input())
    pair_sum = previous + current
    if pair_sum % 2 == 0:
        if count == 0 or pair_sum > best:
            best = pair_sum
        count += 1
    previous = current
print(count, best)

```

#### Учебные критерии

- 0: Ни один тест не пройден: нет запуска, ошибка исполнения или неверный вывод. Само наличие файла не даёт балла.
