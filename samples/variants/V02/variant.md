## Задание №3

Рассматриваются целые X от 0 до 99 включительно. Выражение: `(X кратно 2) И НЕ (X кратно 3)`. Сколько значений X делают выражение истинным? «Кратно» означает делимость без остатка. И требует истинности обоих операндов, НЕ отрицает условие в следующих скобках. Ноль кратен любому положительному целому числу.

**Ответ / эталон:** 33

#### Решение

1. Ноль не подходит: обе делимости для него истинны. Количество положительных кратных 2: 99 ÷ 2 с округлением вниз = 49.

2. Общие кратные делятся на НОК(2, 3) = 6. Их количество: 16.

3. Исключи из первой группы общие кратные: 49 − 16 = 33.

```python
n = int(input())

while n > 0:
    digit = n % 10
    if digit >= 2:
        s = s + digit
    n = n // 10

```

**Ответ / эталон:** 14

#### Решение

1. Создай счётчик и сумму с начальными значениями 0.

2. Для каждого из N чисел проверь одновременно кратность и включённую границу. Меняй обе величины только для подходящих чисел.

3. После цикла выведи счётчик и сумму; если ничего не подошло, оба значения останутся 0.

```
n = int(input())
count = 0
total = 0
for i in range(n):
    x = int(input())
    if x % 6 == 0 and x >= -42:
        count += 1
        total += x
print(count, total)

```

- 0: Ни один тест не пройден: нет запуска, ошибка исполнения или неверный вывод. Само наличие файла не даёт балла.

- 2: Программа нормально завершилась и дала верный вывод на всех десяти тестах, включая граничные случаи.
