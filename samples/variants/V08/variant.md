## Задание №1

Сообщение может занимать не более 473 байт. Из них 44 байт занимает служебный заголовок. В условной кодировке каждый символ текста занимает 32 бита. Какое наибольшее целое число символов можно поместить в сообщение? Других служебных данных нет.

**Ответ / эталон:** 107

#### Решение

1. Для текста остаётся 473 − 44 = 429 байт.

2. Один символ занимает 32 ÷ 8 = 4 байта.

3. Количество целых символов: 107; останется 1 байт. Ещё один символ потребовал бы 476 байт, больше лимита 473.

## Задание №3

Рассматриваются целые X от 0 до 78 включительно. Выражение: `(X кратно 4) И НЕ (X кратно 6)`. Сколько значений X делают выражение истинным? «Кратно» означает делимость без остатка. И требует истинности обоих операндов, НЕ отрицает условие в следующих скобках. Ноль кратен любому положительному целому числу.

**Ответ / эталон:** 13

#### Решение

1. Ноль не подходит: обе делимости для него истинны. Количество положительных кратных 4: 78 ÷ 4 с округлением вниз = 19.

2. Общие кратные делятся на НОК(4, 6) = 12. Их количество: 6.

3. Исключи из первой группы общие кратные: 19 − 6 = 13.

```python

    digit = n % 10
    if digit >= 6:
```

## Задание №8

Поиск выполняется по одной неизменной базе страниц. Каждая страница учитывается один раз. A, B и C — множества страниц с соответствующими словами. И означает наличие всех указанных слов, ИЛИ — хотя бы одного. Все количества даны точно, в страницах.

A — «алгоритм», B — «сеть», C — «программа».

| Запрос    | Страниц |
| --------- | ------- |
| C         | 420     |
| B И C     | 210     |
| A И C     | 220     |
| A И B И C | 170     |
| B         | 360     |
| A         | 420     |
| A И B     | 190     |

Сколько страниц найдёт запрос A ИЛИ B ИЛИ C? Ответ запиши целым числом без единиц измерения.

**Ответ / эталон:** 750

#### Решение

1. Сумма отдельных множеств: 420 + 360 + 420 = 1200.

3. Итого: 420 + 360 + 420 − 190 − 220 − 210 + 170 = 750 страниц.

#### Решение

1. Запомни первое число. Каждое следующее образует пару с предыдущим; при N = 1 пар нет.

2. Для подходящей пары обнови счётчик и максимум. Первая подходящая сумма задаёт максимум даже тогда, когда она отрицательная.

3. На каждом шаге сохраняй текущее число как предыдущее. Так соседние пары могут перекрываться; при отсутствии подходящих выведи 0 0.

```
n = int(input())
previous = int(input())
count = 0
best = 0
for i in range(n - 1):
    current = int(input())
    pair_sum = previous + current
    if pair_sum % 9 == 0:
        if count == 0 or pair_sum > best:
            best = pair_sum
        count += 1
    previous = current
print(count, best)

```

- 2: Программа нормально завершилась и дала верный вывод на всех десяти тестах, включая граничные случаи.
