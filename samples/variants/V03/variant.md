## Задание №2

Сообщение закодировано с помощью таблицы. Между кодами букв нет дополнительных разделителей.

| Буква | Код   |
| ----- | ----- |
| Г     | `~`   |
| В     | `~#`  |
| Д     | `~##` |
| Б     | `###` |

Сигнал: `######~####~#####`. Расшифруй сообщение и запиши последовательность букв.

**Ответ / эталон:** ББВБДБ

#### Решение

1. В таблице «Г» — `~`, а «В» — `~#`. Короткий код совпадает с началом длинного. Поэтому при выборе буквы нужно проверить, удаётся ли разобрать оставшуюся часть сообщения.

С позиции 7 записано `~####~#####`. К началу этой строки подходят «Г» — `~`; «В» — `~#`; «Д» — `~##`.

Если выбрать букву «Г» (код `~`):

После `###` остаётся `#~#####` (с позиции 11). К началу этого остатка не подходит ни один код из таблицы.

С таким выбором прочитать сообщение целиком не получится.

Если выбрать букву «Д» (код `~##`):

Остаётся `##~#####` (с позиции 10). К началу этого остатка не подходит ни один код из таблицы.

С таким выбором прочитать сообщение целиком не получится.

Берём код `~#` — это буква «В». Ниже проверим разбиение всего сообщения.

2. Разделим всю запись на коды букв:

`### / ### / ~# / ### / ~## / ###`

| № буквы | Код   | Буква |
| ------- | ----- | ----- |
| 1       | `###` | Б     |
| 2       | `###` | Б     |
| 3       | `~#`  | В     |
| 4       | `###` | Б     |
| 5       | `~##` | Д     |
| 6       | `###` | Б     |

Читаем буквы сверху вниз: **ББВБДБ**.

3. Проверим обратным кодированием: «Б» → `###`; «Б» → `###`; «В» → `~#`; «Б» → `###`; «Д» → `~##`; «Б» → `###`.

Соединив коды без разделителей, получим `######~####~#####` — исходную запись. Значит, все знаки использованы. Ответ: **ББВБДБ**.

## Задание №16

Напиши программу на Python 3. Рассмотри соседние пары N целых чисел: первое и второе, второе и третье и далее. Пары могут перекрываться. При отсутствии подходящих пар, в том числе при N = 1, выведи 0 0.

Выводи только указанные целые числа, без приглашений и пояснений. Числа результата разделяй пробелом.

**Ответ / эталон:** python-pairs-v1:["informatics-variant-v1","informatics-variant-v1:V03",16]:reference

#### Решение

1. Запомни первое число. Каждое следующее образует пару с предыдущим; при N = 1 пар нет.

2. Для подходящей пары обнови счётчик и максимум. Первая подходящая сумма задаёт максимум даже тогда, когда она отрицательная.

3. На каждом шаге сохраняй текущее число как предыдущее. Так соседние пары могут перекрываться; при отсутствии подходящих выведи 0 0.

```
n = int(input())
previous = int(input())
count = 0
best = 0
for i in range(n - 1):
    current = int(input())
    pair_sum = previous + current
    if pair_sum % 7 == 0:
        if count == 0 or pair_sum > best:
            best = pair_sum
        count += 1
    previous = current
print(count, best)

```
