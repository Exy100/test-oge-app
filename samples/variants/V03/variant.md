## Задание №1

Используется условная кодировка. Размер символа: 8 бит. Количество символов: 243. Сколько байт занимает текст? Учитывай только символы, без служебных данных.

**Ответ / эталон:** 243

#### Решение

1. Количество символов: 243. Размер каждого: 8 бит.

## Задание №3

Рассматриваются целые X от 0 до 98 включительно. Выражение: `(X кратно 5) ИСКЛЮЧАЮЩЕЕ ИЛИ (X кратно 4)`. Сколько значений X делают выражение истинным? «Кратно» означает делимость без остатка. ИСКЛЮЧАЮЩЕЕ ИЛИ истинно, когда истинно ровно одно из двух условий. Ноль кратен любому положительному целому числу.

**Ответ / эталон:** 35

#### Решение

1. Ноль не подходит: обе делимости для него истинны. Количество положительных кратных 5: 98 ÷ 5 с округлением вниз = 19. Кратных 4: 24.

2. Общие кратные делятся на НОК(5, 4) = 20. Их количество: 4.

3. Общие кратные вошли в сумму дважды, а нужны числа только из одной группы: 19 + 24 − 2 × 4 = 35.

#### Решение

1. Запомни первое число. Каждое следующее образует пару с предыдущим; при N = 1 пар нет.

2. Для подходящей пары обнови счётчик и максимум. Первая подходящая сумма задаёт максимум даже тогда, когда она отрицательная.

3. На каждом шаге сохраняй текущее число как предыдущее. Так соседние пары могут перекрываться; при отсутствии подходящих выведи 0 0.

```
n = int(input())
previous = int(input())
count = 0
best = 0
for i in range(n - 1):
    current = int(input())
    pair_sum = previous + current
    if pair_sum % 7 == 0:
        if count == 0 or pair_sum > best:
            best = pair_sum
        count += 1
    previous = current
print(count, best)

```

- 0: Ни один тест не пройден: нет запуска, ошибка исполнения или неверный вывод. Само наличие файла не даёт балла.

- 1: Программа нормально завершилась и дала верный вывод на части из десяти тестов, но не на всех.

- 2: Программа нормально завершилась и дала верный вывод на всех десяти тестах, включая граничные случаи.
