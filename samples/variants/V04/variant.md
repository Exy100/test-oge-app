## Задание №1

В кодировке каждый символ занимает 8 бит. Записан список слов: «крапива, дуб, берёза, сосна, клён, хризантема». Одно слово удалили вместе с лишними запятой и пробелом; двойных пробелов не осталось. Размер текста уменьшился на 12 байт. Какое слово удалили?

**Ответ / эталон:** хризантема

#### Решение

1. Один символ занимает 8 ÷ 8 = 1 байт. Всего удалили 12 ÷ 1 = 12 символов.

2. Вместе со словом удалили запятую и пробел — два символа. На само слово приходится 12 − 2 = 10 символов. Дефис тоже считается символом.

3. В списке такую длину имеет слово «хризантема». Проверка: (10 + 2) · 1 = 12 байт.

## Задание №2

Сообщение закодировано с помощью таблицы. Между кодами букв нет дополнительных разделителей.

| Буква | Код   |
| ----- | ----- |
| В     | `~`   |
| Е     | `~#`  |
| Б     | `~##` |
| А     | `###` |

Сигнал: `~#~##~~####~`. Расшифруй сообщение и запиши последовательность букв.

**Ответ / эталон:** ЕБВЕАВ

#### Решение

1. В таблице «В» — `~`, а «Е» — `~#`. Короткий код совпадает с началом длинного. Поэтому при выборе буквы нужно проверить, удаётся ли разобрать оставшуюся часть сообщения.

С позиции 1 записано `~#~##~~####~`. К началу этой строки подходят «В» — `~`; «Е» — `~#`.

Если выбрать букву «В» (код `~`):

Остаётся `#~##~~####~` (с позиции 2). К началу этого остатка не подходит ни один код из таблицы.

С таким выбором прочитать сообщение целиком не получится.

Берём код `~#` — это буква «Е». Ниже проверим разбиение всего сообщения.

2. Разделим всю запись на коды букв:

`~# / ~## / ~ / ~# / ### / ~`

| № буквы | Код   | Буква |
| ------- | ----- | ----- |
| 1       | `~#`  | Е     |
| 2       | `~##` | Б     |
| 3       | `~`   | В     |
| 4       | `~#`  | Е     |
| 5       | `###` | А     |
| 6       | `~`   | В     |

Читаем буквы сверху вниз: **ЕБВЕАВ**.

3. Проверим обратным кодированием: «Е» → `~#`; «Б» → `~##`; «В» → `~`; «Е» → `~#`; «А» → `###`; «В» → `~`.

Соединив коды без разделителей, получим `~#~##~~####~` — исходную запись. Значит, все знаки использованы. Ответ: **ЕБВЕАВ**.

## Задание №16

Напиши программу на Python 3. Рассмотри соседние пары N целых чисел: первое и второе, второе и третье и далее. Пары могут перекрываться. **Ответ / эталон:** python-pairs-v1:["informatics-variant-v1","informatics-variant-v1:V04",16]:reference

#### Решение

1. После N отдельно прочитай первое число как previous. Каждое из оставшихся N − 1 чисел образует пару с предыдущим. Сумма пары должна делиться на 5. При N = 1 пар нет.

2. Проверь (previous + current) % 5 == 0. Для первой подходящей пары присвой её сумму максимуму, даже если она отрицательная. Проверка на числах -10, -5, 0: суммы -15, -5, количество 2, максимум -5. Начальный максимум 0 дал бы ошибку.

3. После каждой пары сохрани current как previous: соседние пары могут перекрываться. Для примера из условия получается 3 145. Если подходящих пар нет, выведи 0 0; иначе — их количество и наибольшую сумму.

```
n = int(input())
previous = int(input())
count = 0
best = 0
for i in range(n - 1):
    current = int(input())
    pair_sum = previous + current
    if pair_sum % 5 == 0:
        if count == 0 or pair_sum > best:
            best = pair_sum
        count += 1
    previous = current
print(count, best)

```
