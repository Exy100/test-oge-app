## Задание №1

Используется условная кодировка. Размер символа: 16 бит. Количество символов: 33. Сколько байт занимает текст? Учитывай только символы, без служебных данных.

**Ответ / эталон:** 66

#### Решение

1. Количество символов: 33. Размер каждого: 16 бит.

2. Общий объём: 33 × 16 = 528 бит.

3. В байте 8 бит: 528 ÷ 8 = 66 байт.

## Задание №2

| Буква | Код |
| ----- | --- |
| Р     | ?   |
| К     | 110 |
| А     | 10  |
| О     | 00  |
| М     | 01  |

Сообщение: «КРАРО». Передано: `1101111011100`. Восстанови код буквы Р. Ответ запиши строкой из 0 и 1 без пробелов; ведущие нули обязательны.

**Ответ / эталон:** 111

3. Выдели группы по порядку букв: 110 | 111 | 10 | 111 | 00. В обоих местах букве Р соответствует 111. Ответ: 111.

## Задание №6

Выполняется программа на Python 3. Числа ввода подаются по одному на строку.

```python
n = int(input())
s = 0
while n > 0:
    digit = n % 10
    if digit >= 4:
        s = s + digit
    n = n // 10
print(s)
```

Ввод: `30450`.

Какое целое число напечатает программа?

**Ответ / эталон:** 9

#### Решение

1. n % 10 извлекает последнюю цифру, n // 10 удаляет её. Порядок обработки: 0, 5, 4, 0, 3.

2. В сумму входят цифры не меньше 4: 4, 5.

3. Сумма выбранных цифр: 9. При n = 0 цикл заканчивается; вывод: 9.

#### Решение

1. Запомни первое число. Каждое следующее образует пару с предыдущим; при N = 1 пар нет.

2. Для подходящей пары обнови счётчик и максимум. Первая подходящая сумма задаёт максимум даже тогда, когда она отрицательная.

3. На каждом шаге сохраняй текущее число как предыдущее. Так соседние пары могут перекрываться; при отсутствии подходящих выведи 0 0.

```
n = int(input())
previous = int(input())
count = 0
best = 0
for i in range(n - 1):
    current = int(input())
    pair_sum = previous + current
    if pair_sum % 5 == 0:
        if count == 0 or pair_sum > best:
            best = pair_sum
        count += 1
    previous = current
print(count, best)

```

- 0: Ни один тест не пройден: нет запуска, ошибка исполнения или неверный вывод. Само наличие файла не даёт балла.

- 1: Программа нормально завершилась и дала верный вывод на части из десяти тестов, но не на всех.

- 2: Программа нормально завершилась и дала верный вывод на всех десяти тестах, включая граничные случаи.
