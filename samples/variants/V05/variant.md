## Задание №1

Условная кодировка: 8 бит на каждый символ. Текст без кавычек: «кот, тигр, дельфин, собака». Удалили одно слово и ровно одну запятую с одним пробелом. Объём уменьшился на 8 байт. Какое слово удалили? Буквы, запятая и пробел занимают одинаковый объём; других изменений нет. Ответ запиши кириллицей, регистр не важен.

**Ответ / эталон:** собака

#### Решение

1. Один символ занимает 1 байт. Число удалённых символов: 8 ÷ 1 = 8.

2. Запятая и пробел — ещё два символа. Длина слова: 8 − 2 = 6.

3. В списке только слово «собака» имеет длину 6. Ответ: собака.

## Задание №2

Коды имеют разную длину. Ни один код не является началом другого. Коды записаны слева направо без разделителей.

| Буква | Код  |
| ----- | ---- |
| А     | 110  |
| К     | 1110 |
| М     | 0    |
| О     | 10   |
| Р     | 1111 |

Передано: `111111001110110`. Расшифруй сообщение. Ответ запиши последовательностью заглавных кириллических букв из таблицы, без пробелов; регистр учитывается.

**Ответ / эталон:** РАМКА

#### Решение

2. Подставь буквы по таблице: 1111 → Р; 110 → А; 0 → М; 1110 → К; 110 → А.

3. Соедини буквы в исходном порядке: РАМКА. Обратное кодирование даёт 111111001110110.

## Задание №3

#### Решение

1. Учти, что запись числа 0 состоит из одной подходящей цифры 0.

2. Остаток от деления на 10 даёт последнюю цифру. Проверь её кратность, обнови счётчик и сумму, затем отбрось цифру целочисленным делением.

3. Частное уменьшается до 0, поэтому цикл завершится. Порядок просмотра цифр на количество и сумму не влияет.

```
n = int(input())
count = 0
total = 0
if n == 0:
    count = 1
while n > 0:
    digit = n % 10
    if digit % 3 == 0:
        count += 1
        total += digit
    n //= 10
print(count, total)

```
