## Задание №1

Условная кодировка: 8 бит на каждый символ. Текст без кавычек: «зебра, собака, дельфин, антилопа». Удалили одно слово и ровно одну запятую с одним пробелом. Объём уменьшился на 9 байт. Какое слово удалили? Буквы, запятая и пробел занимают одинаковый объём; других изменений нет. Ответ запиши кириллицей, регистр не важен.

**Ответ / эталон:** дельфин

#### Решение

1. Один символ занимает 1 байт. Число удалённых символов: 9 ÷ 1 = 9.

2. Запятая и пробел — ещё два символа. Длина слова: 9 − 2 = 7.

3. В списке только слово «дельфин» имеет длину 7. Ответ: дельфин.

**Ответ / эталон:** 13

#### Решение

1. Храни длину текущей цепочки и наибольшую найденную длину; начни с нулей.

2. При числе не меньше порога увеличивай текущую длину и сразу обновляй максимум; при меньшем числе сбрасывай текущую длину.

3. Выведи максимум после всех N чисел. Обновление внутри цикла учитывает цепочку в конце; если подходящих чисел не было, ответ равен 0.

```
n = int(input())
current = 0
best = 0
for i in range(n):
    x = int(input())
    if x >= 28:
        current += 1
        if current > best:
            best = current
    else:
        current = 0
print(best)

```
