## Задание №1

Текст перевели из условной кодировки 8 бит на символ в условную кодировку 32 бита на символ. Объём вырос на 333 байта. Символы текста не изменились; служебных данных нет. Сколько символов в тексте?

**Ответ / эталон:** 111

#### Решение

1. Каждый символ стал занимать на 32 − 8 = 24 бита больше.

2. Это 24 ÷ 8 = 3 байта на символ.

3. Число символов: 333 ÷ 3 = 111.

## Задание №2

Каждой букве соответствует непустой двоичный код длиной не более четырёх бит. Коды записываются слева направо без разделителей. Один код в таблице скрыт знаком ?.

| Буква | Код |
| ----- | --- |
| К     | ?   |
| А     | 111 |
| М     | 110 |
| Р     | 00  |
| О     | 10  |

Сообщение: «АКМКР». Передано: `111011100100`. Восстанови код буквы К. Ответ запиши строкой из 0 и 1 без пробелов; ведущие нули обязательны.

**Ответ / эталон:** 01

#### Решение

1. Буква К встречается дважды. Известные коды занимают 8 бит из 12.

2. Оставшееся число бит для двух одинаковых групп: 4. Длина искомого кода: (12 − 8) ÷ 2 = 2.

3. Выдели группы по порядку букв: 111 | 01 | 110 | 01 | 00. В обоих местах букве К соответствует 01. Ответ: 01.

## Задание №6

Выполняется программа на Python 3. Числа ввода подаются по одному на строку.

```python
n = int(input())
s = 0
while n > 0:
    digit = n % 10
    if digit >= 2:
        s = s + digit
    n = n // 10
print(s)
```

Ввод: `23401`.

Какое целое число напечатает программа?

**Ответ / эталон:** 9

#### Решение

1. n % 10 извлекает последнюю цифру, n // 10 удаляет её. Порядок обработки: 1, 0, 4, 3, 2.

2. В сумму входят цифры не меньше 2: 2, 3, 4.

3. Сумма выбранных цифр: 9. При n = 0 цикл заканчивается; вывод: 9.

#### Решение

1. Создай счётчик и сумму с начальными значениями 0.

2. Для каждого из N чисел проверь одновременно кратность и включённую границу. Меняй обе величины только для подходящих чисел.

3. После цикла выведи счётчик и сумму; если ничего не подошло, оба значения останутся 0.

```
n = int(input())
count = 0
total = 0
for i in range(n):
    x = int(input())
    if x % 5 == 0 and x >= -50:
        count += 1
        total += x
print(count, total)

```

#### Учебные критерии

- 0: Ни один тест не пройден: нет запуска, ошибка исполнения или неверный вывод. Само наличие файла не даёт балла.

- 1: Программа нормально завершилась и дала верный вывод на части из десяти тестов, но не на всех.

- 2: Программа нормально завершилась и дала верный вывод на всех десяти тестах, включая граничные случаи.
