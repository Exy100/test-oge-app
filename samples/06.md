## 1. Последовательные присваивания

Генератор: program-assign-v1

Seed: "t3.3-review:0"

Выполняется программа на Python 3. Числа ввода подаются по одному на строку.

```python
x = int(input())
y = int(input())
x = x + y
y = x - y
x = x * y
print(x)
```

Ввод: `6 3`.

Какое целое число напечатает программа?

**Ответ:** 54

### Решение

1. После ввода x = 6, y = 3. После x = x + y: x = 9, y = 3.

2. В строке y = x - y используется уже новое x: y = 9 − 3 = 6.

3. Последнее присваивание даёт x = 9 × 6 = 54. Программа выводит 54.

## 4. Обработка цифр в цикле while

Генератор: program-while-v1

Seed: "t3.3-review:3"

Выполняется программа на Python 3. Числа ввода подаются по одному на строку.

```python
n = int(input())
s = 0
while n > 0:
    digit = n % 10
    if digit >= 2:
        s = s + digit
    n = n // 10
print(s)
```

Ввод: `10032`.

Какое целое число напечатает программа?

**Ответ:** 5

### Решение

1. n % 10 извлекает последнюю цифру, n // 10 удаляет её. Порядок обработки: 2, 3, 0, 0, 1.

2. В сумму входят цифры не меньше 2: 3, 2.

3. Сумма выбранных цифр: 5. При n = 0 цикл заканчивается; вывод: 5.
