# Задание №7 — 12 примеров

## 1. Адрес файла в корне сервера

Генератор: url-root-v1

Seed: "t3.4-review:0"

Протокол: `http`. Сервер: `library.example`. Файл: `notes.txt`. Файл расположен в корне сервера.

| Метка | Фрагмент   |
| ----- | ---------- |
| A     | `http`     |
| B     | `.example` |
| C     | `.txt`     |
| D     | `://`      |
| E     | `notes`    |
| F     | `library`  |
| G     | `/`        |

Составь полный адрес из фрагментов таблицы. Запиши подряд их метки — заглавные латинские буквы без пробелов. Каждый выбранный фрагмент используй ровно один раз. Используй все фрагменты. Адрес не содержит порта, параметров запроса или якоря. Сервер учебный; открывать адрес не нужно.

**Ответ:** ADFBGEC

### Решение

1. Начало адреса — протокол, разделитель :// и имя сервера: http://library.example.

2. Путь к файлу: /notes.txt. Расширение относится к имени файла, а не к имени сервера.

3. Полный адрес: http://library.example/notes.txt. По таблице ему соответствуют метки ADFBGEC.
