## 1. Адрес файла: цифровые метки

Генератор: url-fragments-v2

Seed: "t3.15-final-20261017:0"

Доступ к файлу hello.jpg на сервере smile.info осуществляется по протоколу HTTPS. Фрагменты адреса закодированы цифрами от 1 до 7. Запиши последовательность цифр, кодирующую адрес файла.

| Цифра | Фрагмент |
| ----- | -------- |
| 1     | `hello`  |
| 2     | `://`    |
| 3     | `.jpg`   |
| 4     | `https`  |
| 5     | `/`      |
| 6     | `info`   |
| 7     | `smile.` |

**Ответ:** 4276513

### Решение

1. Порядок частей URL: протокол, ://, сервер, /, имя файла.

2. Полный адрес: https://smile.info/hello.jpg.

3. Замени его части цифрами из таблицы: 4276513. Проверь, что использованы все семь фрагментов.
