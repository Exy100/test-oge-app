Напиши программу на Python 3. Вводится последовательность натуральных чисел, за которой следует 0 — признак конца ввода. Найди количество чисел, восьмеричная запись которых состоит ровно из четырёх цифр и заканчивается цифрой 5. Выведи количество в десятичной системе; если подходящих чисел нет, выведи 0. Завершающий ноль в последовательность не входит.

Ввод: по одному числу на строке, от 1 до 10000 включительно; не более 1000 чисел. Последняя строка — 0. Первое число тоже может быть нулём. Количество чисел заранее не задано.
Выводи только указанные целые числа, без приглашений и пояснений. Числа результата разделяй пробелом.

Пример ввода:
```
4561
4659
915
4633
5581
538
7117
1169
1956
5063
4136
4081
0
```
Пример вывода:
```
0
```

Сохрани код в answer.py, UTF-8. В архиве находятся десять тестов, эталон и инструкция локального запуска. Проверка использует лимит 2 секунды на тест; это учебное ограничение, а не норма экзамена. Учебные критерии 0/1/2 относятся к результатам запусков и не заменяют официальную экспертную оценку.
