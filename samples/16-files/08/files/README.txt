Авторский учебный набор №16. Все материалы CC0-1.0. Персональные данные не нужны.
1. Прочитай assignment.txt. Напиши собственную программу на Python 3 и сохрани как answer.py в UTF-8.
2. В tests/index.json перечислены десять пар файлов ввода и ожидаемого вывода, включая пример и границы. В каждой строке входа одно целое число. Параметры задачи — source/parameters.json.
3. Запусти в терминале из распакованного каталога: python3 check.py answer.py (Windows: py -3 check.py answer.py). Скрипт запускает программу заново для каждого теста, подаёт стандартный ввод и сравнивает числа стандартного вывода. Для среднего допускается абсолютная погрешность не более 0.000001; дробная часть через точку, допустима экспоненциальная запись. Количество и остальные целые результаты сравниваются точно. Пробелы и переводы строк между числами не влияют на результат; лишние слова, пропущенные числа, авария или превышение 2 секунд делают тест непройденным.
4. Для одного теста в обычном терминале: python3 answer.py < tests/01.input.txt. В среде разработки можно ввести те же строки вручную.
5. После самостоятельного решения сравни с reference/answer.py. Его можно проверить командой python3 check.py reference/answer.py.
Проверяющий скрипт исполняет выбранный локальный файл с обычными правами пользователя; это не песочница. Запускай только свой или доверенный код. Проверяется конечный набор тестов, а не доказательство корректности для всех вводов. Сохранение файла само по себе не подтверждает решение. Критерии учебные, не официальный рубрикатор экзамена.
