# Задание №8 — 12 примеров

## 1. Число страниц для ИЛИ

Генератор: search-union-v1

Seed: "t3.4-review:0"

Поиск выполняется по одной неизменной базе страниц. Каждая страница учитывается один раз. A, B и C — множества страниц с соответствующими словами. И означает наличие всех указанных слов, ИЛИ — хотя бы одного. Все количества даны точно, в страницах.

A — «программа», B — «сеть».

| Запрос | Страниц |
| ------ | ------- |
| B      | 440     |
| A И B  | 190     |
| A      | 530     |

Сколько страниц найдёт запрос A ИЛИ B? Ответ запиши целым числом без единиц измерения.

**Ответ:** 780

### Решение

1. Сумма отдельных результатов: 530 + 440 = 970.

2. Страницы с обоими словами (190) вошли в эту сумму дважды. Вычти одно пересечение.

3. Итого: 530 + 440 − 190 = 780 страниц.
