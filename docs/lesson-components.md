# Компоненты урока

T7.2. Компоненты находятся в `src/components/lessons/`. Рабочие вызовы всех
компонентов — в `src/dev/lesson-components.mdx`; галерея открывается при `npm run dev`
по `/test-oge-app/dev/lessons/`. Для страницы нужен контейнер `.lesson-page`.
`LessonHeader` подключает общие стили. Пути сайта обрабатываются через `sitePath`.

## Структура и свойства

| Компонент | Данные |
|---|---|
| LessonHeader | `lesson`: метаданные коллекции; `lessons`: массив `{id, title, route}` для ссылок на пререквизиты |
| Motivation | Содержимое: назначение темы и пример экзаменационного формата |
| Theory | Содержимое: объяснения, схемы и читаемый код; для Markdown/формул/кода есть `RichText.astro` |
| Interactive | `id`, `title`, `goal`, `controls`, `taskNumbers`, `modulePath`; обязательный текст альтернативы. [Контракт](interactives.md) |
| Examples | Содержимое из компонентов Example |
| Example | Уникальный `id`, `title`, `source: {generatorId, taskNumber, seed}` |
| Mistakes | Содержимое из компонентов Mistake |
| Mistake | `title`: ошибка; содержимое: объяснение и способ её избежать |
| Quiz | Содержимое из компонентов Question, пояснение о пределах проверки встроено |
| Question | Уникальный `id`, `title`, и ровно одно из `source` или `choice` |
| StreamLink | `taskNumbers`, для №13 при необходимости `variant13="document"` или `"presentation"` |
| CheatSheet | Содержимое с правилами; сворачивается нативным `details`, раскрывается при печати |
| TOC | `entries: [{id, title}]`; id должны соответствовать существующим разделам |
| LessonNav | Необязательные `previous` и `next` со свойствами `{id, title, route}` |

У блоков Motivation, Theory, Examples, Mistakes, Quiz, StreamLink, CheatSheet
значения `id` по умолчанию: `motivation`, `theory`, `examples`, `mistakes`, `quiz`,
`practice`, `cheatsheet`. Их можно переопределить, сохранив соответствие оглавлению.
Порядок и минимумы полного урока описаны в [проверках качества](quality-checks.md).

## Примеры и вопросы из существующих источников

```mdx
import Example from '../components/lessons/Example.astro';
import Question from '../components/lessons/Question.astro';

export const source = {
  generatorId: 'removed-word-v2',
  taskNumber: 1,
  seed: 'lesson-word-example',
};

<Example id="word-example" title="Удалённое слово" source={source} />

<Question id="word-question" title="Найди слово" source={source} />
```

Пути импортов зависят от расположения MDX. `lessonTask` восстанавливает задачу
на сервере через реестр потока и проверяет схему. Условия, ответы и шаги решения
вычисляются генератором; текст проходит общий безопасный рендерер. Для авторских
наборов №13 используются их `generatorId` и seed, например `curated-documents-v2`
и `D01`. Example предоставляет подготовку настоящего ZIP с исходниками и эталоном
через общий TaskFiles. Подготовка файлов требует JavaScript.

Разбор открывается по одному шагу с клавиатуры, фокус переходит на новый шаг.
Без JavaScript нативное раскрытие показывает все шаги. При печати видны все шаги
и шпаргалка; элементы управления и мини-тест скрыты. Печатная версия использует
чёрный текст на белом фоне независимо от темы экрана.

В Question допустимы краткие ответы. Используется общий checker, включая формат,
регистр, алфавит, допустимые альтернативы и объяснения известных ошибок.
Неправильный ответ можно изменить и проверить повторно; состояние каждого вопроса
отдельное. Для проверки требуется JavaScript; до готовности модуля кнопка выключена.

Практическая работа с artifact-ответом в Question вызывает ошибку сборки.
Для проверки понятия в офисном уроке можно задать вопрос с выбором:

```mdx
<Question
  id="check-saved-file"
  title="Проверь сохранение"
  choice={{
    kind: 'choice',
    prompt: 'Как убедиться, что документ сохранился и открывается?',
    options: [
      { id: 'name', text: 'Посмотреть только на имя' },
      { id: 'open', text: 'Открыть файл и проверить содержимое' },
    ],
    correctId: 'open',
    explanation: 'Имя не показывает содержимое. Открой сохранённый документ.',
  }}
/>
```

Нужны непустые вопрос и объяснение, минимум два варианта с разными id,
`correctId` одного из них. Численные данные и результаты программ в учебном
содержании вычисляются по PROMPT.md §5; правильность авторских формулировок
и возрастающую сложность примеров проверяют при подготовке уроков T7.5–T7.11.

Галерея компонентов не входит в коллекцию уроков и счётчик 45 материалов.
Оболочка интерактивов готова в T7.3; учебные модули добавляются в задачах разделов.
