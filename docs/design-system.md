# Оформление сайта

Общие стили находятся в `src/styles/tokens.css` и `global.css`, оболочка страниц —
в `src/layouts/SiteLayout.astro`. Цвета, типографика, отступы, радиусы, тени и
анимации задаются токенами. Новая страница использует этот layout и семантические
токены и компоненты [UI-кита](ui-kit.md), реализованного на шаге T1.5.

## Тема

В шапке доступны системная, светлая и тёмная темы. По умолчанию используется
системная. Выбор хранится только в браузере, ключ `oge.theme`, значения `system`,
`light`, `dark`. Это настройка оформления, она не сохраняет учебный прогресс.
Нет cookies, внешних запросов или идентификаторов пользователя.

Небольшой локальный `theme.js` исполняется в head до CSS и содержимого страницы;
его загрузка не зависит от React. Режим применяется до появления body.
Смена системной темы учитывается только при выборе «Системная». Изменения
синхронизируются между вкладками. При недоступном localStorage выбор действует
до перезагрузки; неизвестное сохранённое значение означает системную тему.
На каждой странице настройка применяется до body; при возврате из bfcache
обновляется через pageshow. Навигация обычная, с нативными CSS View Transitions
там, где они поддерживаются. ClientRouter не совместим с CSP Astro (ADR-012).

CSS `light-dark()` и `color-scheme` обеспечивают системную тему даже без JavaScript;
переключатель в таком случае отключён. Основная теория остаётся доступной.
`prefers-reduced-motion` отключает анимации и плавную прокрутку.

## Шрифты

Две локальные variable-гарнитуры: Golos Text для текста, JetBrains Mono для чисел
и кода. В `src/assets/fonts/` включены только normal WOFF2-подмножества latin и
cyrillic, всего 112 460 байт. `fonts.css` содержит исходные unicode-range и
`font-display: swap`; основной кириллический шрифт предзагружается в layout.
Файлы получают хеши при сборке и загружаются с того же адреса GitHub Pages.

## Проверки

`npm run check:contrast` вычисляет WCAG-контраст непосредственно из CSS-токенов
для обеих тем. Матрица включает унаследованный текст на всех нейтральных фонах,
акценты, состояния наведения кнопок и сообщения проверки ответа. Порог для всех
размеров текста — 4,5:1. Новое сочетание нужно внести в `textPairs` скрипта;
проверка дополнена axe в настоящем браузере.

`npm run e2e` проверяет главную в production и служебную страницу на dev-сервере:
темы, сохранение до появления содержимого, недоступное хранилище, другие вкладки,
переходы страниц, клавиатуру, reduced motion, локальные шрифты, увеличенный текст и
отсутствие служебного маршрута в production. Все четыре браузерных проекта
выполняют эти сценарии.

Страница `/test-oge-app/dev/ui/` доступна только через `npm run dev`: интеграция
регистрирует маршрут исключительно для команды dev. Она находится вне
`src/pages/` и не входит в `astro build`. Показывает палитру, типографику,
существующие действия и сообщения, а также все 14 компонентов UI-кита T1.5.
