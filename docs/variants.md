# Сборщик учебных вариантов

`src/core/variants/index.ts` собирает воспроизводимые варианты с номерами 1–16.
Экзаменационный формат и максимумы берутся из существующей конфигурации,
сверенной в [exam-format.md](exam-format.md). Это авторские учебные задания,
не официальные варианты ФИПИ. Формат 2027 года имеет статус проекта.

## Сборка и выбор №13

```ts
import {
  buildVariant, buildFixedVariant, variant13Alternatives, variantSeed,
} from './src/core/variants';

const random = buildVariant('мой-seed', 'document');
const fixed = buildFixedVariant('V01', 'presentation');
const alternatives = variant13Alternatives(variantSeed(fixed));
```

`buildVariant(seed, selection)` возвращает существующий тип Variant: generated,
id, seed и ровно 16 задач. `buildFixedVariant(id, selection)` возвращает fixed,
id и задачи; исходный seed находится по неизменяемому реестру V01–V10.
Второй аргумент — presentation или document; значение по умолчанию для API и
разбора — presentation. Публичный экзаменационный экран позднее должен предложить
ученику явный выбор и обработать смену самооценки по требованиям фазы 6.

В scored-массив входит только выбранная работа №13. Другая доступна через
variant13Alternatives и экспорт, номер и баллы не добавляет. №15 и №16 присутствуют
оба. Максимумы: двенадцать единиц, затем 2, 3, 2, 2 — всего 21.

Именованные дочерние RNG выбирают генератор отдельно для каждого номера и
кураторский набор отдельно для каждой альтернативы №13. Смена выбора не меняет
другие задачи или их файлы. Модификация возвращённого задания не меняет банки
и последующие сборки. Версия сборщика — informatics-variant-v1.

## Выгрузка

```sh
npm run sample:variant -- --id V01 --variant document --output-dir .cache/variant-review
npm run sample:variant -- --seed 'мой-seed' --output-dir .cache/random-review
npm run --silent sample:variant -- --all --output-dir samples/variants > samples/variants.md
npx prettier --write samples/variants.md 'samples/variants/*/variant.md'
npm run check:variants
```

[V01–V10 с условиями и файлами](../samples/variants.md) сохранены в репозитории.
CLI записывает dataset.zip, manifest.json и variant.md. Без output-dir один
вариант печатается в Markdown. Для all путь обязателен. Несовместимые режимы,
повторные/неизвестные аргументы и неизвестный фиксированный id отвергаются.

Архив предназначен **для разбора и проверки** и включает решения/эталоны.
Это не архив исходных материалов экзаменационного режима. В нём 19 файлов:
README.txt, variant.txt, variant.json, alternatives13.json, index.json,
а также семь ZIP и семь манифестов для №11, №12, обеих работ №13, №14, №15, №16.
Вложенные архивы распаковываются в отдельные папки и полностью сохраняют исходные
пути, данные, лицензии и SHA-256. index.json связывает их с taskId/datasetId.
Так соблюдаются прежние лимиты ZIP: 100 записей, 1 MiB на файл, 8 MiB суммарно,
10 MiB на архив. Лимиты не увеличены. Все материалы CC0-1.0, без персональных данных.

Экспорт принимает только точный вариант своего seed/id и выбранной ветки,
проверяет VariantSchema и сравнивает с канонической сборкой. Изменённые задания,
ответы, порядок номеров, подменённые id/seed и семнадцатая задача отклоняются.

## Проверки

1000 различных seed проверены для обеих веток №13: схема, порядок 1–16,
уникальность id, максимум 21, генераторные verify, повторяемость и неизменность
остальных задач при смене ветки. Кампания действительно выбирает все 58 подтипов.
Три seed имеют золотые снимки обеих сборок и альтернатив; три — манифестов.

Все десять фиксированных вариантов экспортируются и проверяются с обеими ветками:
реальные вложенные ZIP, CRC, хеши, соответствие манифестам/заданиям, точное
совпадение с компонентными наборами и повторная сборка. Десять сохранённых ZIP
воспроизводятся по байтам. Подсчёт баллов даёт 21 при полном наборе правильных
ответов/максимальных самооценок, сохраняет неполный результат без оценок практики
и отвергает оценку от другой ветки №13.

check:variants независимо проверяет 10 пакетов, 70 вложенных наборов и 975
вложенных файлов, запускает 100 Python-тестов и 80 полей Робота. Обе альтернативы
№13 побайтово сверяются с ранее проверенными кураторскими архивами. Calc открывает
20 ODS новых вариантов; кэш формул эталонов удалён, заново вычислены 2430 формул,
все 30 ответов совпали с независимым расчётом, исходные ячейки сохранены.

Node/Worker/браузер сравниваются на одинаковых данных. В разработке маршрут
/dev/variants/ позволяет проверить оба вида сборки, обе альтернативы и скачивание
комплекта. Он исключён из production. Публичные страницы, таймер и история попыток
относятся к фазе 6. Итоговый отчёт фазы 3 — [generator-coverage.md](generator-coverage.md).
