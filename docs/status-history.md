## T4.1 — движок адаптивного потока

Чистое TypeScript-ядро src/core/stream реализует создание/настройку сессии,
строгое восстановление JSON, выдачу конкретной ссылки, приём результата и очередь.
DOM, часы, сеть и хранилище не используются. Версия informatics-stream-v1;
именованные Rng fork и отдельный счётчик случайных выдач. Повторный next сохраняет
карточку, форматная ошибка не меняет счётчики/статистику/очередь. Состояние копируется,
порядок номеров/источников канонизируется; неверные границы отклоняются.

Формула ADR-002: 0.5/N плюс половина массы по весам ошибок. Без статистики,
при одинаковой точности и нулевых весах — равномерно. Неизученный номер сохраняет
accuracy=null и нейтральный вес среднего по изученным выбранным номерам.
Практика нормируется на maxScore из examConfig. automatic, self и aiAccepted
хранятся отдельно; без оценки/при пропуске точность не выдумывается.

Конкретная ошибка/неполный балл возвращается после трёх других завершений;
полный успех на возврате назначает интервал 10, затем 30; третий успех удаляет запись.
Ошибка сбрасывает ступень к 3. Пропуск/неоценённый возврат сохраняет ступень
и откладывает на три задачи. FIFO обслуживается отдельно от случайных выборов.
Смена номеров и ветки №13 сохраняет скрытые записи, ссылки не дублируются.
Переполнение очереди 1000 или безопасного целого отклоняет переход без мутации.
Реальный каталог подключает 58 генераторов и 24 набора №13, проверяет ссылки
и возвращает независимые копии банков. По умолчанию выбираются номера 1–10.

18 профильных тестов: 500 наборов статистики с независимой формулой;
три кампании по 5000 фактических выдач, граница шесть стандартных отклонений;
500 seed по 20 переходов с JSON-восстановлением и проверкой неизменности;
три золотые последовательности; интервалы/сбросы/FIFO/фильтрация/дедупликация,
практика, отсутствие оценки и неверные входы. Все 58 генераторов и 24 ссылки
банков разрешены в задания; обе ветки проверены двумя сессиями по 100 выдач.
Ещё один тест сравнивает 64 перехода на семи seed в Node и настоящем Worker.

Полный npm run verify успешен: 1101 тест в 42 файлах, 98,17% строк ядра
(3074/3131), lint, типы, ограничения, контраст, минимум фазы 3 и сборка.
Два профильных Playwright-теста Chromium/mobile прошли за 8,9 секунды:
