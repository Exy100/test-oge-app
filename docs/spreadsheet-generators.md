# №14: таблицы и круговые диаграммы

Приёмка согласована владельцем: Q-I10 / ADR-039. Обязательны три подтверждённых
семейства ФИПИ; прежние четыре упражнения по 240 строк сохранены в `learning.ts`
и `samples/learning-14-files/`, исключены из экзаменационного подбора.

| Генератор | Источник формата | Данные | Два расчёта и диаграмма |
|---|---|---|---|
| `sheet-count-range-v2` | D2025, с. 13, 25–26 | 1000 записей, 5 столбцов | Число по полу/статусу; размах правой руки; распределение статусов выбранного пола |
| `sheet-sum-mean-v2` | D2026, с. 13, 26–27 | 370 перевозок, 6 столбцов, по датам | Сумма расстояний за три дня; средняя масса из пункта; число перевозок 1/2/3 октября |
| `sheet-count-mean-v2` | D2027, с. 14, 28–29 | 1000 участников, 4 столбца | Число по классу и порогу; средний балл школы; число участников 7/8/9 классов |

Все записи авторские, вымышленные, детерминированы seed. Нет личных данных.
Параметры отбора изменяются, но операции и объём соответствуют источникам.
Внутренняя сложность — 3 для совмещения двух условий и отдельной средней
на 1000 записях, 2 для остальных двух семейств. Это инженерная оценка нагрузки,
не официальная классификация ФИПИ.

В каждом наборе исходные ODS/CSV, условие, критерии, JSON ответов и редактируемая
эталонная ODS. H2/H3 содержат два ответа, J2:K4 — вспомогательную таблицу для
диаграммы. Пять настоящих формул COUNTIF/COUNTIFS, SUMIF, AVERAGEIF, ROUND,
MAX/MIN. Calc допускает локализованные имена функций. Все исходные ячейки
сохраняются; заголовок не включается в диапазоны.

Диаграмма — объект ODF Chart в `Object1/content.xml`, с тремя секторами,
легендой и числовыми подписями, вблизи G6. Это редактируемая диаграмма с локальной
таблицей данных, не PNG. В эталоне она показывает фиксированные данные набора;
после изменения исходных записей её данные нужно обновить. Печать эталона
ограничена областью результатов и диаграммы, все строки доступны в редакторе.
Валидатор допускает только этот локальный ресурс в ODS; внешние ссылки,
дополнительные объекты и скрипты отвергаются. Лимиты ZIP не меняются.

Баллы 0–3 — количество верных элементов: первое число, второе число, диаграмма.
Для диаграммы нужны правильные данные, соотношения секторов, легенда и значения.
Официальные исключения сохранены: другие ячейки ответа и эквивалентная точность
отображения допустимы. Произвольный файл автоматически не оценивается.

[12 наборов](../samples/14.md) и [12 реальных примеров всех баллов](../samples/office-scores/14/).
Примеры каждого семейства имеют 0/1/2/3 верных элемента. Unit-тесты проверяют
500 seed на генератор общим харнессом с реальными файлами, независимый CSV-оракул,
три золотых примера, подмены метаданных и повреждённые диаграммы.
`scripts/check-spreadsheets.py` независимо решает CSV, удаляет кеши всех формул,
пересчитывает их в Calc и проверяет печатный вид диаграмм. `check-variants.py`
повторяет независимые расчёты для V01–V10.
