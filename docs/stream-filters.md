# Фильтры и ссылки практики

На `/stream/` быстрый выбор открывает один номер, №1–10 или все №1–16.
«Фильтры заданий» позволяет выбрать произвольное непустое множество номеров,
тему, сложность 1–3, повторение ошибок и вид работы №13. Изменения вступают
в силу по кнопке «Применить фильтры». Сводка показывает применённый выбор.

## Адрес

| Параметр | Значение |
| --- | --- |
| `numbers` | Уникальные номера 1–16 через запятую; без параметра 1–10 |
| `topic` | Точное название темы из `TaskInstance.topics`; без параметра все темы |
| `difficulty` | 0 — любая, 1–3 — вычисленная сложность экземпляра |
| `variant13` | `presentation` или `document` |
| `review` | 0 — обычный поток, 1 — только готовые повторения ошибок |
| `task` и `seed` | ID источника и точный seed, включая символы Unicode |

Ссылка с одними `task/seed` определяет номер и ветку №13 по заданию. Явные
фильтры должны соответствовать экземпляру. Неполные ссылки, неизвестные
источники, отсутствующий кураторский seed, повторные параметры и неверные
значения показывают сообщение об ошибке. Применение фильтров восстанавливает
рабочий адрес. Чужие параметры не интерпретируются как инструкции или HTML.

«Скопировать ссылку на задачу» включает текущие фильтры и точный экземпляр.
При запрете Clipboard API появляется подписанное поле для ручного копирования.
Условие и файлы восстанавливаются из того же ядра; имена ответов и оценки
ученика через ссылку не передаются. Префикс `/test-oge-app/` сохраняется.

Смена фильтров создаёт запись истории; следующие задачи заменяют текущую.
Back/Forward восстанавливают выбор и экземпляр без записи ответа. Сбой загрузки
форматтера не изменяет карточку, черновик, адрес или статистику.

## Подбор и очередь

Сложность проверяется на реальном экземпляре после генерации. Поиск проверяет
до 16 seed каждого генератора, у выбранного банка №13 — все 12 наборов. Номера,
для которых кандидаты не найдены, перечисляются; пустое пересечение не выдаёт
задачу другой темы или сложности. Повтор подбора проверяет новую последовательность.
Веса 50/50 применяются к номерам с кандидатами, затем выбирается источник.
Число генераторов номера и частота успеха подбора не становятся его весом.

Повторение использует существующую очередь 3/10/30. Готовые задачи идут первыми
и проходят те же фильтры. В режиме только ошибок новая случайная задача не
выдаётся; пустая очередь и оставшееся число других задач объясняются отдельно.
Применение фильтров к подходящему неотвеченному заданию сохраняет его.

Начиная с T4.5 очередь и результаты сохраняются в браузере после перезагрузки;
экспорт, импорт и сброс доступны в настройках. Режим повторения в ссылке
переносит выбор, а не чужую историю. Прямая ссылка всё равно открывает указанную
задачу; следующий переход использует очередь получателя.

Статический HTML показывает стартовое задание, URL восстанавливается после
гидратации. Без JavaScript это ограничение объясняется в `noscript`.
