# Учебный интерпретатор «Робота»

Чистое TS-ядро: `src/core/robot/`. Оно не исполняет JavaScript или полный язык
«Кумир». Поддерживается описанное ниже подмножество, без переменных и процедур.
Команды нечувствительны к регистру; одна команда или граница блока на строку.
Пустые строки игнорируются, `|` начинает комментарий. Ошибки содержат исходный
номер строки и подсказку на «ты». Неизвестные команды и выражения отклоняются до запуска,
включая недостижимые ветви.

## Язык

Движения: `вверх`, `вниз`, `влево`, `вправо`. `закрасить` красит текущую клетку;
повторная закраска разрешена. Строки поля растут вниз, столбцы — вправо, индексы с 0.
Граница поля и внутренняя стена одинаково препятствуют движению в обе стороны.
Столкновение останавливает программу, положение остаётся прежним.

Условия: `сверху свободно`, `снизу свободно`, `слева свободно`, `справа свободно`;
вместо `свободно` можно написать `стена`. Также `клетка закрашена` и
`клетка не закрашена` — учебные дополнения, не обязательные датчики из демоверсий.
Составные условия допускают `не`, `и`, `или` и круглые скобки. Приоритет:
`не` выше `и`, `и` выше `или`; скобки меняют порядок. `не справа свободно`
и `справа стена` эквивалентны. Между скобками и словами пробел необязателен.

```text
если (справа свободно) и (не снизу свободно) то
  вправо
все

нц пока не (справа стена или сверху стена)
  вправо
кц
```

Первый пример — запись из описания исполнителя проекта демоверсии ФИПИ 2027,
с. 15. Составные условия подтверждены также демоверсиями 2025/2026, с. 14–15;
источники и границы выводов — [матрица M15](exam-matrix.md).

```text
если справа свободно то
  вправо
иначе
  закрасить
все

нц пока клетка не закрашена
  закрасить
кц

нц 3 раз
  влево
кц
```

`иначе` необязательно. `нц N раз` и датчики закраски — учебные расширения.
Цикл с количеством 0 не выполняет тело. Циклы и условия
могут быть вложенными. Допустима оболочка:

```text
использовать Робот
алг пример
нач
  закрасить
кон
```

Строка `использовать Робот` необязательна и допускается без оболочки. Если указан
`алг` (с необязательным именем), требуются `нач` и завершающий `кон`.

## API и результаты

```ts
const execution = new RobotExecution(source, field, { maxSteps: 1000, traceLimit: 100 });
const event = execution.step();
const batch = execution.run(100);
execution.cancel();
const result = execution.snapshot();
```

Поле — существующий `FigureSpec` вида `robot-field`, проверяется Zod и лимитами.
Входное поле и возвращённые снимки не дают изменять внутреннее состояние.
Для полного ограниченного запуска есть `runRobot(source, field, options)`.
Чтобы сохранить отзывчивость интерфейса, вызывающая сторона выполняет небольшие
порции `run(budget)` и отдаёт управление браузеру между ними; пока порция синхронно
исполняется, обработчик клика отмены не может сработать. `step()` позволяет паузу.
Сброс — создание нового экземпляра с теми же исходными данными.

Статусы: `ready`, `running`, `completed`, `crashed`, `step_limit`, `cancelled`.
Терминальное состояние не меняется от повторного шага/отмены. Отмена до первого
шага не выполняет команд. Пустая программа завершается без шагов.

Шаг — одна инструкция внутреннего исполнителя, включая условия, переходы и
управление циклами. Поэтому пустой бесконечный цикл также расходует лимит.
Трасса фиксирует номер шага и исходной строки, вид инструкции, положение,
состояние текущей клетки и статус. Она ограничена независимо от числа шагов;
при усечении выставляется `traceTruncated`. Полная закраска есть в `painted`.

`success` истинно только при нормальном завершении и точном совпадении итогового
множества закрашенных клеток с `targets`. Лишняя закраска и недостающие клетки —
неуспех. Начальная закраска участвует в сравнении; конечная позиция не ограничена.
Разные программы могут дать правильный результат. Это учебная проверка,
**не официальный балл ОГЭ**.

## Пределы

- Исходник: 32 000 UTF-16 единиц, до 2000 строк.
- Вложенность блоков: 32; скобок/отрицаний условия: 32; инструкций: до 4000.
  Длинные цепочки `и`/`или` хранятся плоско, не растят рекурсивный стек.
- Повторений одного цикла: 0…10 000; суммарный лимит шагов: 1…10 000.
- Поле: до 100 × 100; число исходных клеток и стен ограничено размером поля.
- Сохранённая трасса: 0…1000 событий. Повторная закраска не увеличивает множество.

Исполнение не использует eval, Function, рекурсивный вызов тела цикла или
расширяющийся на каждой итерации стек. Отдельные тесты проверяют аварии,
бесконечные/пустые/вложенные циклы, синтаксис, лимиты, отмену и разные решения.
Playwright сравнивает результаты и трассы Node с Chromium, Firefox, WebKit и
мобильным проектом. Независимый Python-исполнитель разбирает выражения алгоритмом
сортировочной станции (постфиксная запись), а TS — рекурсивным спуском.
Оба исполняют официальные эталоны и шесть равнозначных записей каждого из них;
отдельно проверяются все 16 комбинаций четырёх датчиков, ошибки и границы.
Публичный редактор поля относится к дальнейшему интерфейсу.

Контракт расширен в ADR-036. Не заявляется полный «Кумир», переменные, процедуры
или терпимость эксперта к произвольным синтаксическим ошибкам. `всё`, `дано`/`надо`
и `клетка чистая` не подтверждены выбранными источниками как обязательные формы;
повторная сверка открытого банка остаётся UNVERIFIED.
