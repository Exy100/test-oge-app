# Задания №16: программы на Python 3

В потоке и вариантах используются три подтверждённых формата. Условия авторские,
материалы CC0-1.0; источники — [матрица M16a–M16c](exam-matrix.md),
демоверсии ФИПИ 2025/2026 и **проект** 2027. Полнота по открытому банку не установлена.

| Генератор | Что вычисляется | Ввод и вывод |
|---|---|---|
| python-positive-mean-v1 | Среднее положительных и их количество | N, затем N целых; хотя бы одно положительное; сначала среднее, затем целое количество |
| python-base7-sum-v1 | Сумма чисел с последней семеричной цифрой 1 | N, затем N натуральных; одна десятичная сумма, 0 при отсутствии |
| python-octal-sentinel-v1 | Количество четырёхзначных восьмеричных чисел на 5 | Натуральные до 0, без N; одно целое количество |

N и длина последовательности ограничены 1000; значения — от −10000 до 10000
для среднего и от 1 до 10000 для остальных форматов. Это явные ограничения
авторских задач. Ноль завершает последовательность и не входит в неё; допустим
ввод сразу 0. Граница четырёх восьмеричных цифр — 512 ≤ x < 4096.

Четыре прежних упражнения `python-filter`, `python-digits`, `python-pairs`,
`python-run` сохранены с прежними ID в `learningGenerators`, галерее и регрессиях.
Они не участвуют в экзаменационном подборе и не заменяют подтверждённые форматы.
Минимум четырёх учебных семейств остаётся обязательным; обязательны все три формата (ADR-055).
Сложность по структуре алгоритма: сумма по остатку — 2, среднее с отбором и
дробным делением, а также цикл до нуля с двойным условием — 3. Параметры примера
не меняют необходимый алгоритм; это учебная классификация, не оценка ФИПИ.

## Локальная проверка

Python выполняется на компьютере ученика. Редактор, экспорт `answer.py`, примеры,
ZIP с тестами, эталоном и критериями доступны в практике. В экзаменационном режиме
до завершения доступен только пример условия, остальные тесты и эталон скрыты.
В браузер не добавляется движок Python.

```sh
python3 check.py answer.py
python3 answer.py < tests/01.input.txt
python3 check.py reference/answer.py
```

В Windows: `py -3 check.py answer.py`. Каждый тест запускается отдельно с `-I`,
временным рабочим каталогом и лимитом 2 секунды. Это учебное ограничение.
Скрипт запускает только выбранный собственный или доверенный файл с обычными
правами пользователя; он не является песочницей.

В `tests/index.json` явно записана политика вывода:

- `integer`: целые токены сравниваются точно, допустимы знаки и ведущие нули;
- `positive-mean`: два токена, среднее с абсолютной погрешностью ≤0.000001,
  количество — точное целое. Допустимы точка и экспоненциальная запись среднего.

Пробелы и переводы строк между числами не влияют на результат. Лишние слова,
пропущенные/лишние числа, NaN, бесконечности, запятая, дробное количество,
ненулевой выход и таймаут отклоняются. Максимум — 1024 символа вывода.
Для целочисленных задач дробная или экспоненциальная запись не принимается.
Учебные 0/1/2 означают ни одного / часть / все десять тестов; они не заменяют
официальную экспертную оценку и не доказывают правильность для всех вводов.

## Наборы и воспроизводимость

```sh
npm run --silent sample -- --task 16 --n 12 --seed python-review --files-dir samples/16-files > samples/16.md
npm run --silent sample:variant -- --all --output-dir samples/variants > samples/variants.md
npm run check:python
npm run check:variants
npm run verify
```

В [samples/16.md](../samples/16.md) — 12 наборов, по четыре на формат.
В каждом ZIP 27 настоящих файлов: условие, README, параметры, эталон, check.py,
критерии, индекс и десять пар вход/выход. Манифест фиксирует SHA-256, размер,
формат и лицензию. Архив и виртуальные файлы совпадают; воспроизведение побайтовое.
V01–V10 сохраняют прежние seed и обновляют только №16 и его вложенный набор.
Новые попытки получают `pythonFormatVersion: 1`. Черновики и история без этого
поля восстанавливают прежнее №16; код и самооценка не переносятся на новую задачу.
Совместимость сверена с десятью заданиями из main `99b2e72`.

Каждый из семи подтипов проверяется на 500 seed общим харнессом, независимым
оракулом и реальным Python на всех десяти входах: 35000 исполнений эталона.
На подтип — три золотых снимка задачи и манифеста. Тесты перебирают также все
значения 1–10000 для трёх новых форматов, короткие последовательности и цифры
старых упражнений. Мутации ловят целочисленное деление, неверный остаток,
неверные границы восьмеричной длины и прежние ошибки четырёх упражнений.
Общий набор правильных и ошибочных выводов проверяет согласованность
TypeScript и экспортируемого Python checker; 11 официальных входов проходят
продуктовый парсер, вычисление результата и настоящий эталон.

`scripts/check-python.py` независимо читает 324 файла 12 наборов, проверяет
ZIP/CRC/SHA-256, ответы и 120 отдельных запусков Python, затем запускает
каждый экспортированный check.py. Проверяются ошибки синтаксиса, исполнения,
выхода, пустой/нечисловой вывод, таймаут и частичная оценка. Браузерные сценарии
проверяют все три формата на публичной практике, десять входов, экспорт кода,
ZIP и предпросмотр, обе темы, axe и мобильную ширину.
