# Авторские наборы №13.1

Банк содержит 12 кураторских заданий. Это собственные учебные тексты, схемы и
макеты, а не копии заданий ФИПИ. Общий формат ответа ODP и максимум №13 подтверждены
в [сверке экзамена](exam-format.md). Конкретные темы, оформление и чек-лист ниже —
условия тренажёра; они не выдаются за официальные критерии экзамена.

| ID | Тема |
|---|---|
| P01 | От семени к дереву |
| P02 | Путешествие капли |
| P03 | Энергия солнечного света |
| P04 | Как найти книгу |
| P05 | Почему мост держится |
| P06 | Робот на маршруте |
| P07 | Пчела у цветка |
| P08 | Парус и ветер |
| P09 | Как движется ракета |
| P10 | Сообщение в сети |
| P11 | Порядок в цифровом архиве |
| P12 | Маяк на побережье |

Каждый набор содержит `assignment.txt`, исходный `source/material.odt`, три PNG
в `images`, схемы трёх слайдов PNG, пояснение макета и координаты блоков в
`layout`, `criteria.json`, эталон `reference/answer.odp` и данные для его проверки.
README и манифест указывают лицензию CC0-1.0 для авторского содержимого.
Имена, фамилии и контакты не запрашиваются: на титуле используется заданный P01–P12.

Эталон состоит из трёх слайдов 16:9: титул; текст с иллюстрацией; сравнение двух
иллюстраций с подписями. Макеты чередуют размещение текста и изображений.
Заголовки — 32 пт, основной текст — 24 пт, подписи — 20 пт. Изображения встроены
в ODP, сохраняют пропорции и не требуют сети. Текст остаётся редактируемым.

## Учебная самооценка

Шесть проверок охватывают число слайдов и идентификатор, смысловые пункты второго
слайда, подписи третьего, изображения, единое оформление/шрифты и отсутствие
перекрытий или обрезанного текста. Открываемый ODP и все шесть пунктов дают 2;
четыре или пять — 1; не более трёх — 0. Неоткрываемый или отсутствующий ODP — 0.
Эти правила предназначены для учебной самооценки. Автоматическое оценивание
офисного файла ученика и официальный экспертный балл из них не следуют.

## Выгрузка и проверка

```sh
npm run --silent sample -- --task 13 --n 12 --files-dir samples/13-1-files > samples/13-1.md
npm run check:office
```

Номер 13 в текущем CLI выбирает банк презентаций. По умолчанию выгружаются все
12 наборов; количество 1–12 позволяет выбрать начальную часть банка. Seed не меняет
кураторские материалы. Описание [всех наборов](../samples/13-1.md) содержит ссылки
на ZIP, манифесты и эталоны. Архив и распакованные файлы имеют одинаковые байты.
Сохранённые материалы не форматировать: размеры и SHA-256 входят в манифест.

Проверки ядра проходят каждый набор: схема задания, состав, SHA-256, ODF и PNG,
соответствие встроенных иллюстраций исходным, пропорции и отсутствие перекрытия
прямоугольников, детерминизм и совпадение с сохранёнными примерами. Для P01/P06/P12
сохранены золотые снимки задач и манифестов. Подстановка случайных seed не применяется
к кураторскому банку.

CI открывает все 12 исходных ODT в Writer и все 12 эталонных ODP в Impress.
Проверяются исходный текст, 36 страниц PDF, тексты слайдов, число изображений,
формат 16:9 и границы текстовых блоков. PDF, PNG-превью слайдов и результаты конвертации
сохраняются в `quality-reports`, каталог `.cache/presentation-office`.
Для локальной проверки нужны LibreOffice Writer/Calc/Impress и poppler-utils.

Публичное рабочее место и самооценка подключаются последующими задачами плана.
