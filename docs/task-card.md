# Карточка задания и практика — T4.2

Публичная страница `/stream/` соединяет двигатель T4.1 с `TaskCard`.
На главной есть ссылка «Открыть практику №1–16», основная кнопка
«Начать тренировку» и пункт меню «Практика» ведут в поток. По умолчанию поток выбирает
№1–10; практические номера и обе альтернативы №13 включаются явно.
Это базовый выбор номера: фильтры по теме/сложности/ошибкам и URL относятся к T4.3.

## Ответы и состояние

`TaskCard` получает проверенный `TaskInstance`, безопасный HTML условия
из `renderRichText` и сообщает `StreamOutcome`
через `onResult`. Integer, word и sequence используют единый `checkTaskAnswer`.
Поле текстовое: целые не округляются браузерным Number, сохраняются ведущие нули
последовательностей; правила регистра, алфавита и пробелов определяет ядро.
Enter отправляет форму. Ошибка формата показывает пояснение, возвращает фокус
в поле и не отправляет событие результата. Верный или неверный ответ отправляется
один раз; повторная отправка формы не создаёт вторую попытку.

Практика №13–16 показывает все уровни критериев. Радиокнопки доступны стрелками
и пробелом. Самооценка требует отдельного подтверждения. «Оставить без оценки»
отправляет `score: null`, даже если ранее выбран балл. Результат Робота
не становится автоматически баллом и не называется экспертной оценкой.

Страница применяет результат к двигателю при переходе. Пропущенная задача
передаётся как `skip`; принятый результат — ровно один раз. Невалидный формат
не изменяет счётчики/очередь. После перехода фокус на заголовке позиции.
Первая задача предрендерится с постоянным начальным seed; проверка и переходы
включаются после гидратации. Первый переход добавляет `crypto.randomUUID`
для последующих выборок, не теряя результата текущей задачи; постоянное
хранение — T4.5.
Текст страницы прямо объясняет срок жизни кода, черновика и результатов.

Новая попытка пересоздаёт карточку, включая одинаковую curated-задачу.
Смена ссылки задания внутри `TaskCard` также сбрасывает внутреннее состояние.
Редакторы, самооценка, результаты и заметка «Как я решал» из прежней карточки
не переходят в следующую.

## Файлы и редакторы

Общий `components/tasks/TaskFiles` используется публичной карточкой и прежней
dev-галереей. Набор генерируется по явному действию через `createTaskDataset`.
ZIP и манифест скачиваются как blob; исходные файлы и эталоны доступны для
учебной самостоятельной работы. Текстовый просмотр экранируется React;
HTML-корпус превращается в обычный текст, PDF показывается как скачиваемый
документ. Офисные файлы и изображения открываются после скачивания в соответствующем приложении.
Смена карточки снимает обработку результата асинхронной подготовки; созданные
object URL освобождаются при размонтировании.

`CodeEditor` — обычный textarea с меткой, описанием, лимитом 32 000 символов
и скачиванием точного текста UTF-8. Enter добавляет строку, Tab выводит фокус
из редактора, отступы вводятся пробелами. Никаких сетевых редакторов или CDN.
URL выгрузки создаётся по нажатию кнопки из текущего текста; предыдущий URL
освобождается при повторном скачивании и размонтировании.

№15 использует существующий ограниченный `RobotExecution` и все восемь полей
соответствующего генератора. Доступны отдельный шаг, выполнение пакетами
по 16 инструкций с отдачей управления браузеру, пауза/продолжение и сброс.
Поле показывает актуальную позицию и закраску через доступный SVG/HTML `Figure`.
Ошибки синтаксиса, столкновения, несовпадение закраски и лимит 10 000 шагов
объясняет ядро. Изменение кода/поля отменяет прежнее выполнение;
смена карточки освобождает таймер и отменяет интерпретатор.

№16 показывает редактор Python, примеры ввода и вычисленный ожидаемый вывод
из `programCases`. Файл `answer.py` и ZIP с `check.py` предназначены для запуска
на компьютере ученика через Python 3, как требует spec §3.5/7.3.
Произвольный Python в браузере не исполняется.

## Проверка

`/dev/tasks/` доступна только в dev: реальный каталог генераторов и банков,
контрольный seed, та же карточка и журнал её событий. Дополнительные dev-источники
содержат параметры и ответы 36 официальных фикстур без переноса условий
в production. Проверка ввода принимает все опубликованные альтернативы. Production не включает
галерею. `tests/e2e/task-card.spec.ts` проверяет клавиатуру, все форматы ответов,
точные ZIP №11–16 и обеих веток №13, самооценку/отказ от оценки,
семь семейств Робота и четыре типа Python, точный экспорт кода, публичную страницу под CSP,
доступность, темы и узкий экран с увеличенным шрифтом.

Подсказки, решение и типичные ошибки в этой карточке добавляются в T4.4;
постоянная статистика — T4.5, общие горячие клавиши — T4.6.

Первое условие форматируется при сборке Astro. RichTextView отображает только
результат безопасного форматтера и сохраняет копирование кода. Форматтер для
следующих задач и подготовка файлов загружаются по действию. Пока новая задача
готовится, действия отключены; при ошибке прежняя карточка и результат сохраняются.
