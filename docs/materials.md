# Каталог материалов и прогресс

T7.4. Страница `/materials/` использует `MaterialsCatalog.astro`, SVG-карту `TopicMap.astro`
и описание 14 разделов из `src/lib/lessons/catalog.ts`. Названия и номера
соответствуют spec §10.1; связи на карте — рекомендуемые учебные основы,
не официальный порядок заданий ФИПИ. Пререквизиты не закрывают доступ к теме.
HTML формируется на сервере; небольшой `src/scripts/materials.ts` управляет
фильтром и локальными счётчиками без React на странице каталога. Это сохраняет
бюджет 60 КБ gzip для страниц без учебных интерактивов.

## Содержимое каталога

Каталог читает только настоящую коллекцию `lessons`. Каждый урок получает путь
`/materials/[section]/[lesson]/`, время чтения и отметку из локального хранилища.
При отсутствии уроков нет фиктивных карточек или процентов прохождения:
все 14 тем ведут к работающей практике с подсказками и разборами. Для №13
предусмотрены отдельные ссылки на презентацию и документ. №4 и №9 относятся
к общему разделу графов, №11 и №12 — к разделу файлов.

Список дополнен настоящими результатами тренировок. Краткие ответы №1–12
показываются отдельно от самооценок практики №13–16; тренировка не отмечает урок
пройденным. Счётчики результатов не считаются прогнозом экзаменационного балла.

`?numbers=1,13` оставляет подходящие темы и уроки в списке и выделяет темы на карте.
Можно выбрать несколько номеров; пустой выбор означает все. Состояние сохраняется
в URL, работает с перезагрузкой и кнопками «Назад»/«Вперёд». Ошибочная ссылка
показывает весь каталог и понятное сообщение. Переход по узлу карты или ссылке
на основу снимает фильтр, чтобы целевой раздел был виден.

SVG доступен с клавиатуры; на узком экране его область прокручивается. Под ним
есть обычный список с теми же названиями и связями. Без JavaScript доступны
все темы, карта и ссылки; фильтр и личные отметки требуют JavaScript.

## Добавление урока

Метаданные, блоки и минимумы описаны в [проверках качества](quality-checks.md).
Компоненты — в [lesson-components.md](lesson-components.md), интерактивы —
в [interactives.md](interactives.md). Сохраняй файл в `src/content/lessons/`.
Имя файла не определяет адрес: используются `section` и глобально уникальный `id`.

`id` — непустая строка длиной до 200 символов, не `.` и не `..`.
Она одновременно служит ключом уже существующей схемы `lessonProgress`.
Сегменты адреса кодируются; изменять id опубликованного урока без переноса
сохранённого прогресса нельзя. Неизвестные пререквизиты, повторы id и циклы
роняют сборку. Уроки упорядочиваются после своих пререквизитов, затем по названию;
«Предыдущая/следующая тема» остаются внутри раздела.

В MDX доступны метаданные `frontmatter`. Вызов заголовка:

```mdx
import LessonHeader from '../../../components/lessons/LessonHeader.astro';

<LessonHeader lesson={frontmatter} />
```

Относительный путь зависит от расположения файла. При отсутствии явно переданного
`lessons` заголовок берёт ссылки на пререквизиты из коллекции. Оглавление создаётся
в MDX через TOC: его ссылки должны совпадать с id блоков. Страница урока рендерит
Content, добавляет возврат к каталогу, навигацию по разделу и canonical URL.

## Значение прогресса

«Урок пройден» — ручная обратимая отметка ученика. Это не автоматическая оценка
знаний и не результат мини-теста. `LessonCompletion` подключается в LessonHeader.
До гидратации кнопка выключена; результат действия объявляется живой областью.
При печати отметка и управление скрываются.

Используется существующая область `lessonProgress` версии 1. Запись меняет только
`completed`, сохраняя `quizCorrect`, `quizTotal` и `levels`. Перед записью хранилище
обновляется, чтобы учесть изменения соседней вкладки. Повторное нажатие не создаёт
дубликата. Отметки отсутствующих уроков сохраняются для импорта и не увеличивают
счётчик каталога. Прохождение считается только среди уроков текущего списка.

Настройки сайта экспортируют, импортируют и сбрасывают эти данные вместе
с остальными областями. При отказе localStorage можно работать в памяти страницы;
глобальное уведомление поясняет ограничение. Если импортированная область достигла
лимита 500 записей, новая отметка показывает ошибку и сохраняет прежние записи.

## Проверки

- `tests/unit/materials.test.ts`: соответствие разделов и номеров, граф,
  фильтр, порядок и адреса, целостность прогресса и границы хранилища.
- `tests/unit/materials-build.test.mjs`: сборка двух настоящих MDX-уроков
  с генераторами, мини-тестом и интерактивом во временном каталоге; маршруты,
  автоматические ссылки пререквизитов и порядок навигации.
- `tests/e2e/materials.spec.ts`: фильтр/история, SVG/клавиатура, практика №13,
  реальный независимый ответ №10, вкладки, экспорт/сброс/импорт, ошибки хранилища,
  отсутствие JavaScript, темы, reduced motion, 360 px и увеличение текста 200%.
- `/materials/` добавлен в постоянный набор Lighthouse с прежними бюджетами.

Проверочные MDX из теста и `/dev/materials/` не публикуются и не входят в минимум
45 уроков. Dev-каталог ссылается на рабочую галерею компонентов, чтобы проверить
полный цикл отметки до появления учебных глав. Публичные уроки добавляются
в T7.5–T7.11 вместе со своими интерактивами и предметным ревью.
