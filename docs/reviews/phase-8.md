## Десять случайно выбранных упражнений без ответов

Seed выборки **20261025**. В каждой игре перемешаны уровни [1,2,3], взяты первые
два; затем перемешаны все десять выбранных упражнений. Это обеспечивает охват
всех пяти игр. Seed относится к выборке для ревью; условия самих уровней
фиксированы. Открой ссылку и выбери указанный уровень.

Воспроизведение (JavaScript, Fisher–Yates; порядок игр: склад, пакет, Робот,
сортировка, ворота):

```js
let s = 20261025;
const next = () => ((s = (Math.imul(s, 1664525) + 1013904223) >>> 0) / 4294967296);
function shuffle(a) {
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(next() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}
shuffle([0, 1, 2, 3, 4].flatMap(game =>
  shuffle([1, 2, 3]).slice(0, 2).map(level => [game, level])));
```
