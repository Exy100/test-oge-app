## Ответы проверяющему

### 1. №2

Ответ: **АБВВЕБВБ**.

В таблице «Б» — `~`, а «В» — `~#`. Короткий код совпадает с началом длинного. Поэтому при выборе буквы нужно проверить, удаётся ли разобрать оставшуюся часть сообщения.

С позиции 5 записано `~#~#~##~~#~`. К началу этой строки подходят «Б» — `~`; «В» — `~#`.

Если выбрать букву «Б» (код `~`):

Остаётся `#~#~##~~#~` (с позиции 6). К началу этого остатка не подходит ни один код из таблицы.

С таким выбором прочитать сообщение целиком не получится.

Берём код `~#` — это буква «В». Ниже проверим разбиение всего сообщения.

Разделим всю запись на коды букв:

`### / ~ / ~# / ~# / ~## / ~ / ~# / ~`

| № буквы | Код | Буква |
| --- | --- | --- |
| 1 | `###` | А |
| 2 | `~` | Б |
| 3 | `~#` | В |
| 4 | `~#` | В |
| 5 | `~##` | Е |
| 6 | `~` | Б |
| 7 | `~#` | В |
| 8 | `~` | Б |

Читаем буквы сверху вниз: **АБВВЕБВБ**.

Проверим обратным кодированием: «А» → `###`; «Б» → `~`; «В» → `~#`; «В» → `~#`; «Е» → `~##`; «Б» → `~`; «В» → `~#`; «Б» → `~`.

Соединив коды без разделителей, получим `###~~#~#~##~~#~` — исходную запись. Значит, все знаки использованы. Ответ: **АБВВЕБВБ**.

### 2. №3

Ответ: **8**.

Нужно ложное значение всего выражения, поэтому условие поиска после раскрытия отрицания: (X ≥ 8 И (X < 27 ИЛИ X нечётное)).

При X = 8 выражение ложно. При меньших натуральных X оно истинно.

Проверка соседнего числа: при X = 7 выражение истинно. Первое ложное значение достигается при X = 8.

### 3. №4

Ответ: **30**.

До A расстояние 0. Прямые дороги из A: B: 5 км. При переходе к соседу прибавляй длину дороги; сохраняй меньшую из найденных сумм.

Минимальные расстояния от A: A — 0; B — 5; C — 8; D — 16; E — 24; F — 30 км.

Кратчайший маршрут: A → B → C → D → E → F. Проверка по таблице: 5 + 3 + 8 + 8 + 6 = 30 км. Число дорог само по себе длину пути не определяет.

### 4. №6
