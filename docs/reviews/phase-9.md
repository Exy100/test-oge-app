- 0–5 минут: открыть случай 1 или 2, прочитать условие без подсказок, назвать

## Ответы проверяющему

### 1. №2

Ответ: **АБВВЕБВБ**.

В таблице «Б» — `~`, а «В» — `~#`. Короткий код совпадает с началом длинного. Поэтому при выборе буквы нужно проверить, удаётся ли разобрать оставшуюся часть сообщения.

С позиции 5 записано `~#~#~##~~#~`. К началу этой строки подходят «Б» — `~`; «В» — `~#`.

Если выбрать букву «Б» (код `~`):

Остаётся `#~#~##~~#~` (с позиции 6). К началу этого остатка не подходит ни один код из таблицы.

С таким выбором прочитать сообщение целиком не получится.

Берём код `~#` — это буква «В». Ниже проверим разбиение всего сообщения.

Разделим всю запись на коды букв:

`### / ~ / ~# / ~# / ~## / ~ / ~# / ~`

| № буквы | Код | Буква |
| --- | --- | --- |
| 1 | `###` | А |
| 2 | `~` | Б |
| 3 | `~#` | В |
| 4 | `~#` | В |
| 5 | `~##` | Е |
| 6 | `~` | Б |
| 7 | `~#` | В |
| 8 | `~` | Б |

Читаем буквы сверху вниз: **АБВВЕБВБ**.

Проверим обратным кодированием: «А» → `###`; «Б» → `~`; «В» → `~#`; «В» → `~#`; «Е» → `~##`; «Б» → `~`; «В» → `~#`; «Б» → `~`.

Соединив коды без разделителей, получим `###~~#~#~##~~#~` — исходную запись. Значит, все знаки использованы. Ответ: **АБВВЕБВБ**.

Эталон: `python-pairs-v1:content-audit-20261027:8:reference`. Прочитай критерии и исходные файлы карточки.
