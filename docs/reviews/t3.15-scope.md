# T3.15: подтверждённые форматы и количественный минимум

Подготовлено 2026-10-16; согласовано владельцем 2026-10-17 (Asia/Novosibirsk),
Q-I9 / ADR-038. Принят предлагаемый критерий ниже.

Основание: [матрица](../exam-matrix.md), официальные комплекты D25/D26/D27
и [T3.15](../../tasks.md). Запрос к `https://oge.fipi.ru/bank/` из среды снова
вернул HTTP 503: upstream connection timeout. Это результат запроса из среды,
не утверждение о доступности сайта для других пользователей.

## Подтверждённый объём №1–12

| Номер | Что подтверждают демоверсии | Расхождение, которое можно исправлять сейчас |
|---|---|---|
| 1 | Удаление слова и разделителя, 8/16 бит на символ | Сохранить подтверждённый формат, вычислять сложность из параметров |
| 2 | Полная расшифровка; повторяющиеся буквы в любом порядке | Непрефиксный код и несколько допустимых ответов |
| 3 | Число натуральных решений; минимум при ложном выражении | Полноценные вложенные выражения, оба вида вопроса |
| 4 | Кратчайший простой путь по таблице | Сохранить подтверждённую структуру |
| 5 | Любая подходящая программа не длиннее пяти команд | Квадрат; принимать все подходящие программы |
| 6 | Параметр по девяти запускам, минимум/максимум/любое значение | Поиск параметра вместо результата одной программы |
| 7 | Сборка URL, цифровые метки 1–7 | Метки и протоколы FTP/HTTP/HTTPS |
| 8 | Условное объединение и пересечение трёх запросов | Воспроизводить структуру опубликованной таблицы |
| 9 | Подсчёт путей на ориентированном рисунке | Рисунок вместо матрицы, 7–8 вершин |
| 10 | Сумма чисел в разных основаниях | Несколько слагаемых, ответ в десятичной системе |
| 11 | Контекстный поиск по автору/персонажу в корпусе | Поиск по содержимому и достаточный объём файлов |
| 12 | Подсчёт файлов нескольких расширений в каталогах | Несколько корней/расширений, достаточное число файлов |

Это 13 строк матрицы (M02a/M02b отдельно), а не доказательство четырёх
экзаменационных подтипов на каждый номер. Например, D25–D27 не подтверждают
перестановку строк исполнителем №5, хотя сейчас она засчитывается в минимум.
Отсутствие в демоверсии не доказывает отсутствие в экзамене: статус таких
упражнений остаётся UNVERIFIED до проверки других официальных источников.

## Предлагаемый критерий

1. Готовность №1–12 требует закрыть все подтверждённые строки матрицы,
   выполнить официальные фикстуры и независимые проверки генераторов.
2. Упражнения без подтверждения не входят в экзаменационный подбор V01–V10
   и не выдаются за подтверждённое экзаменационное покрытие; их исходники/проверки
   сохраняются как учебные материалы, без создания преждевременных страниц уроков.
3. Количественный минимум 4/3 остаётся видимым инвентарём, но не подменяет
   подтверждённое покрытие. Его роль в приёмке согласована владельцем: справочный инвентарь отдельных учебных
   упражнений, обязательна полнота подтверждённой матрицы. Пороги кода сохраняются.
4. Покрытие кода ≥90%, 500 seed на генератор, отрицательные проверки,
   детерминизм, схемы, браузеры, доступность и бюджеты производительности сохраняются.
5. Файловый масштаб обосновывается количеством файлов и объёмом содержимого,
   при котором необходим поиск. Пределы текущего ZIP (1 МиБ/файл, 8 МиБ/набор,
   100 записей) отдельно учитываются в техническом решении; простое увеличение
   лимитов без ограниченной проверки больших наборов не считается исправлением.

Альтернатива: сохранить требование четырёх/трёх **подтверждённых** структурных
подтипов и закрывать T3.15 после получения других официальных источников.
Исправление подтверждённых ошибок проверки ответов от этого выбора не зависит.
