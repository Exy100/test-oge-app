# T5.2 — ручная проверка экзамена

Подготовлено 2026-10-18 (Asia/Novosibirsk). Это сценарий, не отзыв ученика.
Человеческий вердикт не получен; T4.8 и пробный экзамен T5.8 не закрыты.

1. Открой [V01](https://exy100.github.io/test-oge-app/variants/V01/), нажми
   «Пройти с таймером». Выбери 13.1 или 13.2, начни экзамен.
2. Реши №1. Ответ для проверки после завершения: «сосна». Запиши свой ход решения
   в черновик, отметь номер для возврата. Перейди на №2 и вернись на №1.
3. Подожди 10 секунд, перезагрузи страницу и продолжи работу. Сверь ответ,
   черновик, отметку и оставшееся время. Уходи и возвращайся через каталог.
4. Открой эту работу во второй вкладке. Проверь, что два редактора не работают
   одновременно. Закрой первую вкладку и продолжи во второй.
5. В №13 запиши имя файла с работой. Отмени смену альтернативы, затем подтверди
   её. Должны очиститься только запись и черновик №13. Скачай исходный ZIP:
   нужные текст, картинки и макет есть, эталонных работ в нём нет.
6. Открой [V02](https://exy100.github.io/test-oge-app/variants/V02/), попробуй
   начать новый экзамен, затем отмени замену прежнего. Вернись к сохранённой работе.
7. Нажми «Завершить экзамен». Сверь список номеров без записи и отметки возврата.
   Отмени завершение; затем заверши. Проверь свой ответ №1 и открой разбор.
8. Перезагрузи страницу завершённой попытки. Ответы и разбор должны остаться;
   новой записи в истории не появляется. Скачай JSON со своими ответами.
9. Повтори основные действия клавиатурой, на телефоне, в тёмной теме и при
   увеличенном тексте. Без JavaScript готовые условия остаются читаемыми.

Для №13–14 указывается имя файла, сохранённого на компьютере; сайт не получает
и не проверяет сам файл. Отсутствующая оценка практики не должна выглядеть
подтверждённым нулём. Экзамен не приостанавливается при закрытии страницы.
