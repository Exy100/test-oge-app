# T4.2 — карточка задания и ввод ответа

Дата: 2026-10-17, Asia/Novosibirsk. Браузерная проверка и Lighthouse завершены локально; итоговый полный CI ожидается.

## Что получает ученик

Публичная `/stream/` с выбором №1–16 и обеих альтернатив №13. В карточке —
условие, схема, точный текстовый ввод ответа и проверка ядром, файлы ZIP,
критерии и отдельное подтверждение самооценки. Для №15 доступен местный
интерпретатор с шагом/паузой/сбросом и проверочными полями; для №16 —
редактор Python, экспорт кода и примеры для проверки на своём компьютере.
Ссылка на практику находится на главной.

## Границы

Ошибка формата не создаёт попытку; каждый оценённый ответ отправляется один раз.
Следующая карточка очищает черновик, код, самооценку и освобождает Blob URL.
Срок жизни данных объяснён на странице. Фильтры и URL — T4.3, подсказки и
разбор — T4.4, постоянная статистика — T4.5, замена старой главной — T4.7.
Практические работы оценивает сам ученик; произвольный офисный файл не проверяется.
Python запускается локально, как согласовано для первой версии.
