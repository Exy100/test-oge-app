# T6.3 — локальная сборка промптов

Worker готовит три версионированных набора сообщений после пересборки задачи.
Краткий ответ/черновик, практическое решение и ответы по критериям отделены
от серверного условия, эталона, критериев и окончательного вердикта №1–12.
Внешнего обращения к ИИ нет: сайт сохраняет демо, health false и HTTP 503.

## Реализация и трассировка

| Требование | Реализация и проверка |
| --- | --- |
| spec §11.6, три версионированных промпта | worker/src/prompts/{stream-feedback,part2-grade,variant-summary}.ts, версии v1; семь снимков сообщений |
| Серверный вердикт окончателен | feedbackPrompt получает только check.verdict, эталон и решение из восстановленной задачи; снимки верного/неверного ответа |
| Недоверенный ввод внутри student_input | shared.ts сериализует JSON и экранирует &, <, >; единственные роли system/user заданы сервером |
| Пятнадцать инъекционных вводов | ai-prompts.test.ts проверяет черновик, решение, значения и ключи criteriaAnswers, одинаковый system и точное восстановление исходных данных |
| Настоящий Workers runtime | Частный tests/fixtures/ai-prompts-worker.ts: 45 случаев инъекций и одна сводка совпадают с Node; production entry fixture не импортирует |
| Эталон/контекст выбираются с сервера | Все зарегистрированные генераторы и 24 кураторские работы: совпадение условия/решения/критериев; seed, id, datasetId/referenceId и нормализованный ввод не передаются |
| Офис без балла, программы предварительно | Снимки №13/14 и №15/16; серверные assessment criteria-help/null или preliminary/maxScore 2; правила не разрешают модели менять режим |
| Сводка только по агрегатам | Явная проекция n/score/timeSec и part2Self, без variantSeed; null не становится нулём; список допустимых токенов с сервера, каждый урок сверяется с MDX |
| Новый код используется | index.ts вызывает buildPrompt после prepare; HTTP-тест подтверждает вызов во всех трёх режимах без исходящего fetch и без возврата сообщений |

## Проверки и границы

Новый целевой набор: 26 тестов, семь снимков; проверка настоящего Workers runtime
прошла. Общий набор ai-prompts, ai-worker, ai-reconstruction,
ai-reconstruction-failure, ai-feedback и ai-demo-provider: 150 тестов в шести
файлах, все успешны; снимки проверены без обновления.

- `npm run typecheck`: 560 файлов, 0 ошибок/предупреждений, два прежних
  уведомления XMLValidator. Итоговый `tsc --noEmit` также успешен.
- `npm run worker:check`: 1385,99 KiB / gzip 229,51 KiB, два файла,
  секретных маркеров нет. Это серверная сборка, клиентские бюджеты не меняются.
- Gitleaks: исходники Worker 623,16 KB и сборка 3,63 MB, 0 находок.
- `npm run check:forbidden`: 599 файлов, 0 нарушений.

Полный ESLint и Prettier успешны. Итоги CI и Pages фиксируются в описании PR
после завершения.

Матрица экзамена и решатели не меняются: контекст берётся из уже проверенного
ядра. Баллы №13–16 и отсутствие офисного файла отражены по действующей матрице;
новых форматов, автопроверки практики или исполнения ученического кода нет.

ADR-061 уточняет порядок локального среза. Структурные тесты не проверяют,
как реальная модель соблюдает инструкции, число слов, содержательную верность
или JSON-контракт. Это НЕ ПРОВЕРЕНО без подключения модели; T6.4–T6.10,
Gate 6 и человеческие Gates открыты. Наблюдения учеников не подменяются тестами.
Заголовки, лимит тела, демонстрационный источник и данные браузера сохраняются.

Следующий шаг — T6.4, клиент OpenRouter. Внешний вызов потребует выбранных
владельцем моделей, бюджета, домена и размещения Worker; ключ — только секрет сервера.
