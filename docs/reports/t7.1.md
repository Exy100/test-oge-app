# T7.1 — схема и сборочная проверка урока

Дата: 2026-10-22 (Asia/Novosibirsk).

## Результат

Коллекция Astro `lessons` читает реальные MDX из `src/content/lessons/**/*.mdx`.
Загрузчик до синхронизации проверяет все девять блоков spec §10.2, их порядок
и вложенные минимумы: две визуализации, один интерактив, три примера, три ошибки,
пять вопросов. Удаление любого блока останавливает настоящую сборку с указанием
файла, строки и причины. Проверка выполняется и при наличии кеша Astro.

Общая Zod-схема метаданных используется коллекцией и `check:coverage`.
Сборка также отклоняет повторные идентификаторы, неизвестные и собственные
пререквизиты. Тело MDX проверяется при изменениях файла в dev-сервере; рендер
отложен до вызова `render(entry)` страницей урока.

`check:coverage` считает валидные уроки, разделы и каждый обязательный блок.
`InteractiveFallback` запрещён с фазы 7; загрузчик новой коллекции отклоняет
его всегда. Требования полного объёма и `currentPhase = 3` сохранены по правилам
промежуточных коммитов из `docs/quality-checks.md`.

Ученических страниц этот шаг не добавляет. Уроки и интерактивы создаются вместе
в T7.5–T7.11; тестовые MDX находятся только во временных проектах и не увеличивают
учебное покрытие сайта. Минимумы структуры не заменяют проверку содержания,
вычисляемых примеров, локальных ответов и соответствия формату ОГЭ.

## Трассировка

- T7.1, spec §10.2: `src/content.config.ts`, `src/lib/lessons/schema.ts`,
  `scripts/quality/lesson-loader.mjs`, общий адаптер `scripts/quality/lessons.mjs`.
- Подсчёт блоков и запрет замен: `scripts/check-coverage.mjs`,
  `tests/unit/check-coverage.test.mjs`, `docs/quality-checks.md`.
- Сборочная приёмка: `tests/unit/lesson-collection.test.mjs` запускает Astro
  во временных проектах, проверяет успешную загрузку полного урока и ошибки
  при удалении каждого из девяти блоков, уменьшении каждого вложенного минимума,
  статичной замене, неверном времени чтения, повторном id и потерянном пререквизите.
- Границы метаданных: `tests/unit/lesson-schema.test.ts` — обязательность всех
  полей, номера 1–16 без повторов, положительное целое время, разделы i1–i14,
  уникальные непустые пререквизиты без приведения строк к числам.

  `XMLValidator` в офисном модуле.

- `npm run check:contrast`: 60 пар, минимум 5.51:1, 0 нарушений.
- `npm run build`: 30 страниц, успешная production-сборка. Предупреждение о
  пока отсутствующем каталоге уроков ожидаемо; прежнее предупреждение Vite о
  размере чанка сохраняется.
- `npm run check:coverage -- --phase=7`: **ожидаемый код 1**, 24 нарушения:
  нет 45 уроков, минимумов 14 разделов и девяти обязательных блоков. Gate 7 открыт.

Форматы M01–M16, генераторы, критерии и экзаменационные фикстуры не менялись.
