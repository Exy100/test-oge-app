# T6.11 — материалы по теме из локального разбора

После завершения демонстрационного примера ученик видит опубликованные уроки
по номеру текущего задания. Ссылка открывает урок в новой вкладке. После её
закрытия исходная карточка остаётся с прежним ответом, черновиком и разбором.
Регистрация и API не требуются; это тематический подбор, не рекомендация ИИ
по содержимому ответа. Порядок локального среза зафиксирован в ADR-057.

## Реализация

`TaskCard` передаёт `taskNumber` в `AiPanel` отдельно от запроса источнику.
Панель использует существующий каталог `preparationLessons`, создаёт ссылки
через `sitePath` и `target="_blank" rel="noopener"`. Ответ, черновик и seed
не попадают в адрес урока. Провайдер, его контракт, генераторы, оценка и схема
хранения не менялись.

Навигация доступна только после завершения вывода. Остановка, ошибка, повтор
и изменение черновика не показывают прежние ссылки как результат нового
разбора. Произвольные ссылки и HTML источника по-прежнему удаляются общим
безопасным renderer. Адреса переходов принадлежат приложению.

Ссылки имеют область касания от 44 px, перенос длинных названий и обычную
клавиатурную навигацию. Заголовок навигации называет номер задания; перед
ссылками явно объясняется открытие новой вкладки.
На узких экранах уменьшены отступы карточки и панели: при 200% текста
названия получают больше места, а область касания ссылок сохраняется.

## Трассировка и проверки

| Требование | Реализация и проверка |
| --- | --- |
| spec §11.0: материалы после примера | `AiPanel`, `TaskCard`; сценарии №9 и №10 в `ai-demo.spec.ts` |
| Исходная карточка сохраняется | Клавиатурный переход в настоящий урок, ожидание готовности, закрытие вкладки; сверка URL, ответа, черновика, разбора и статистики |
| Безопасные адреса и локальность | Каталог приложения, `sitePath`, `noopener`; отсутствие API и сторонних запросов в обеих вкладках; прежние 14 XSS-входов |
| Доступность | Axe панели в обеих темах при 200% текста; отсутствие горизонтального переполнения в Chromium и на экране 360 px |

Локально прошли 34 unit-теста источника и потребителя; TypeScript/Astro:
0 ошибок и предупреждений, два прежних уведомления XMLValidator. Общий lint
и Prettier прошли, сборка создала 76 страниц и sitemap 75 URL.

Браузерный набор Chromium и мобильного Chromium: 18 успешных сценариев,
включая новый переход к уроку. После расширения проверки до обеих тем
и 200% текста повторно прошли оба затронутых сценария. Баллы, сохранённая
тренировка и локальность проверены прежними регрессиями.
После уменьшения мобильных отступов весь набор повторён: 18 успешных
сценариев. Панель дополнительно просмотрена на ширине 360 px в тёмной теме
при 200% текста; горизонтального переполнения нет.

Полные CI точного исходного коммита и итогового main с Pages обязательны;
доказательства фиксируются в PR без коммита с результатом собственного CI.
Реальное API T6.1–T6.10 и человеческие Gates остаются открытыми. Живой пилот
владелец отложил; наблюдения не подставлялись.
