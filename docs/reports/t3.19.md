# T3.19 — подтверждённые форматы №16

Дата: 2026-10-28 (Asia/Novosibirsk). Q-I8 решён владельцем; ADR-055.

## Поведение для ученика

В потоке, вариантах и четырёх уроках Python доступны среднее положительных
с дробным результатом и количеством, сумма чисел с последней семеричной цифрой 1,
а также ввод до нуля с отбором четырёхзначных восьмеричных чисел на 5.
У каждого задания — десять тестов, редактор, экспорт answer.py, ZIP с настоящим
эталоном и локальным check.py. До завершения экзамена открыт только пример условия.
Четыре прежних упражнения сохранены в учебной галерее и регрессиях.

Среднее принимается с абсолютной погрешностью ≤10⁻⁶, количество — точное целое.
Разрешены точка и экспоненциальная запись среднего; у целочисленных задач
сохраняется строгий формат. Вывод, ошибки завершения и таймаут проверяются
одинаково в TypeScript и экспортируемом Python. Политика записана в условии,
README и tests/index.json. Учебные 0/1/2 не заменяют экспертную оценку ФИПИ.

Новые попытки получают `pythonFormatVersion: 1`. Черновики и история без поля
восстанавливают прежнее №16 с сохранённым кодом и самооценкой. Версия передаётся
и worker, и резервному восстановлению в основном потоке. Существующие данные
не переименованы и не очищены.

## Сверка с экзаменом

M16a–M16c закрыты по D25 с. 16, 31–32, D26 с. 16, 31–32 и **проекту** D27
с. 17, 33–34. Все 11 официальных входов проходят продуктовый парсер, вычисление
ожидаемого результата, проверку вывода и настоящий Python-эталон. Условия собственные.
Все 20 строк матрицы имеют техническое покрытие; полнота открытого банка и
частотность форматов остаются UNVERIFIED.

Независимые проверки используют другой способ: запись в основании 7/8 против
арифметических условий эталона; групповой отбор против потокового накопления.
Каждый из семи подтипов проходит 500 seed с общим харнессом, файлами, CRC/SHA-256,
схемой, детерминизмом и Python на десяти входах — 35000 исполнений эталона.
Перебираются все значения 1–10000 для трёх новых форматов; мутации ловят
целочисленное деление, остаток 0 вместо 1 и неверные границы восьмеричной длины.
Общие положительные/отрицательные примеры проверяют согласованность двух checker.

«Реши как ученик»: десять seed разобраны агентом по входам до чтения expected.txt;
среднее дополнительно вычислено рациональной дробью, отбор — по записи числа.
Все результаты совпали. [Данные](../reviews/t3.19-student-check.json),
[пакет для человека](../reviews/t3.19.md). Это не наблюдение за учеником.

V01–V10 пересобраны с прежними seed. Остальные 150 заданий совпадают полностью,
120 вложенных ZIP/манифестов совпадают побайтово. Отдельная фикстура сохраняет
десять настоящих старых №16 из main `99b2e72`; восстановление проверяется по ней.
[Сверка вариантов](../reviews/t3.19-variant-check.json). Samples №16 — 12 архивов,
по четыре на подтверждённый формат; старые золотые задачи сохранены.
