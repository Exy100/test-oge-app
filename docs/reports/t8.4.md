# T8.4 и техническое завершение фазы 8

2026-10-25, Asia/Novosibirsk. Основа main c5799e8; T8.3 опубликована,
[CI/Pages](https://github.com/Exy100/test-oge-app/actions/runs/40191951646) успешен.

Пятая 3D-игра встроена в урок логических операций. Три уровня требуют условие
для двух включённых, ни одного и ровно одного включённого датчика. Зачёт
вычисляется на всех четырёх входах. Один правильный проход не даёт зачёта;
эквивалентные формы принимаются. Студент видит контрпример, таблицу и испытание
ворот по собственному выражению.

Старые четыре псевдонима в requiredIds 2D не совпадали с действующим реестром.
Они исправлены на numeral-lab/text-file-search/document-format/robot-lab,
с сохранением 18 обязательных сцен и всех минимумов. Отдельный тест сравнивает
точные множества requiredIds и реестра; пороги не снижались.

## Сверка с экзаменом

M03 и M06: НЕ/И/ИЛИ, приоритет и проверка условий. В игре два независимых
булевых датчика; реальные подстановки X/входных чисел сохранены в прежних
экзаменационных задачах. Новое покрытие форматов/частотности ФИПИ не заявляется.
Источники: docs/exam-matrix.md, Д25/Д26/Д27, с. 5–6.

Самопроверка: 00/01/10/11, обе формы де Моргана, исключающее ИЛИ двумя записями,
контрпример 11 для ошибочного A ИЛИ B, кириллические буквы, пустой/ошибочный
ввод. В unit цели независимо заданы масками 8/1/6 и перебираются все 16 функций.
Пакет ревью содержит десять упражнений для всех пяти игр и ответы отдельно.

## Проверки и восстановление

Облачная среда стала недоступна до коммита. До сбоя успела пройти структурная
проверка Gate 8; завершение начатых локальных unit/types/build не подтверждено.
Исходники восстановлены из выполненных правок через GitHub API.
Временная ветка подготовки получает форматированный исходник и предпросмотр
с правами contents:read, без записи коммитов из workflow; её workflow не входит
в итоговый срез. В [подготовительном запуске](https://github.com/Exy100/test-oge-app/actions/runs/40202897054)
прошли типы, Gate 8, 16 unit-проверок в двух файлах и production build.
Проверены реальные снимки закрытых/открытых ворот на 1280/360 px в обеих темах.
Четыре замечания линтера в тесте устранены без отключения правил.
Каноническая проверка итогового коммита — полный обычный CI:
lint/types/build, все unit с объединённым покрытием, браузеры/визуальные эталоны,
файлы, безопасность и Lighthouse. Фактический итог фиксируется при доставке.

НЕ ПРОВЕРЕНО: пилот с учеником, ≥50 fps на среднем физическом ноутбуке и отдельный
внешний аудит фазы. Gate 8 — [~] ждёт ревью, а не вердикт человека от агента.
Прежние Gate 3–5/7, Q-I6/Q-I8, currentPhase=3 и отложенная Фаза 6 сохранены.
Следующая кодовая фаза после доставки — 9; начало разрешено PROMPT §3.5,
человеческие вердикты обязательны перед фазой 10.
