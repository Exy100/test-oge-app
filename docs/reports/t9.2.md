## Проверки

`npm run lh` собирает production, запускает Lighthouse CI на 59 URL по три раза,
затем 17 сценариев взаимодействия по три раза. Четыре обязательных performance-job
покрывают каждую navigation и каждый сценарий ровно один раз. Все 45 уроков
сохранены в прежней матрице; добавлены about, privacy и settings.

| Шаблон/состояние | Navigation | Действие для INP |
| --- | --- | --- |
| Главная | `/` | Ввод и проверка ответа |
| Каталог материалов | `/materials/` | Фильтр номера, обновление списка |
| Урок без 3D | Все уроки | Прокрутка к сцене, управление 2D |
| Урок с 3D | Все уроки | Загрузка настоящего canvas, ввод в игре |
| Поток | `/stream/` | Ввод и проверка ответа |
| Каталог вариантов | `/variants/` | Смена темы |
| Фиксированный и случайный вариант | Обе страницы | Открытие подготовки, выбор работы №13 |
| Экзамен / тренировка | Оба query-режима | Старт, ввод, переход к №2 |
| Печатная версия | `/variants/print/?id=V01` | Подготовка полных условий |
| Результат фиксированный / случайный | Пустое и заполненное состояния | Раскрытие условия и разбора |
| Информационные страницы | about, privacy | Смена темы |
| Настройки | settings | Увеличение шрифта до 200% |
| Ошибка | Настоящий HTTP 404 | Смена темы; InfoLayout измеряется также на about/privacy |

У заполненных результатов фикстура строится настоящим генератором и проверяется
схемой хранения. Каждый повтор открывает новый browser context; navigation
очищает кеш/хранилище по умолчанию, init-script восстанавливает только фикстуру.
Таким образом, прежняя проверка сообщения «попытка не найдена» дополняется
холодной загрузкой полного разбора, без включения прогретого кеша.

Полные попытки обнаружили LCP 2,56–2,87 с. Исправление: результат начинает загрузку
после первого кадра, с приоритетом шрифтов и крайним сроком ожидания 200 мс;
зависший шрифт не удерживает интерфейс. Это проверяется реальными браузерными
таймингами; ожидание события FCP также ограничено 200 мс, поскольку WebKit
может не сообщить его до завершения зависшего WOFF2-запроса. Далее используются кадры.
Проверка удерживает настоящие сетевые запросы. Полный экзаменационный сценарий
возобновляет виртуальные часы после всех проверок дедлайна, чтобы rAF работал
и при последующем открытии результата. Убраны отдельные блокирующие запросы
bootstrap темы и 41-байтового стиля переходов: их точные CSP-хэши разрешены Astro,
чужой inline остаётся запрещён. SVG логотипа устраняет загрузку 40 КБ Mono ради
двух символов; оба подмножества основного шрифта предзагружаются. Стили результата
объединены, общий CSS остаётся кешируемым. Подробности — ADR-050.

Navigation-пороги сохранены: P ≥90 для всех страниц (включая уроки с 3D),
A/BP/SEO ≥95, LCP ≤2500 мс, CLS ≤0,05. Для INP — каждый замер ≤200 мс,
mobile viewport 412×823, CPU 4×, slow 4G через Lighthouse DevTools throttling.
Результат не усредняется до прохождения порога.

INP вычисляет официальная Google `web-vitals` 6.2.3: доверенные клики и клавиатура,
Event Timing и настоящий переход вкладки в фон. Отсутствие записей/ввода — ошибка.
Контрольная кнопка с задержкой 260 мс в отдельной вкладке должна превысить порог
и быть отклонена тем же gate. Она не входит в результаты продукта.
Причина отдельного измерителя — несовместимость timespan INP Lighthouse 13.5
с событиями Chromium 151; подробности и новые dev-зависимости — ADR-049.

JSON с метрикой и событиями, полные Lighthouse flow JSON/HTML и сводка сохраняются
в `.lighthouseci/reports/interactions/`, попадают в существующие CI-артефакты
`lighthouse-reports-1…4` на 7 дней. Зависимости измерителя не входят в сайт.

## Остальные бюджеты spec §15

- Начальный JS about/privacy/404: не более 60 000 байт gzip, включая фактически
  загруженные модули и исполняемые inline-скрипты (`page-js-budget.spec.ts`).
  Бывший порог 60 KiB усилен до десятичных 60 KB.
- Сохранены проверки всех 18 2D и пяти лёгких входов игр ≤80 000 байт gzip,
  объединённого графа шести 3D-модулей ≤250 000 байт gzip, а также отсутствия
  3D-запросов до появления сцены и выбора объёмного режима.
- Новый браузерный контракт: два локальных текстовых семейства, четыре latin/
  cyrillic subset, `font-display: swap`, preload обоих основных WOFF2,
  успешная загрузка файлов и отсутствие ненужного Mono на about.
  Математические глифы KaTeX — отдельная часть §13.
- Unit проверяют полноту матриц, распределение по группам, обязательность команды,
  отказ на отсутствующих/некорректных метриках, превышении INP/LCP/CLS и категорий.
