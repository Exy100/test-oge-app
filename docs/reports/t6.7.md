# T6.7 — API в потоке заданий

2026-10-31, Asia/Novosibirsk. Клиент выбирается публичной настройкой сборки
PUBLIC_AI_MODE=api; без неё опубликованный сайт сохраняет локальное демо.
Одинаковая панель используется после верного и неверного краткого ответа,
включая главную и тренировку. Экзамен до завершения не получает разбор.

При нажатии выполняется same-origin GET /api/ai/health без cookies и кэша.
Только строгий enabled:true допускает диалог/отправку. Выключение, неверный
JSON, HTML вместо API, отсутствие сети, отмена и дедлайн не отправляют ответ.
Проверка ответа, сохранённый прогресс, черновик и переход к новой задаче
работают независимо. Согласие, отзыв и ограниченный SSE остаются общими T6.6.

Новые тесты: ai-http.test.ts проверяет границы JSON/health и отмену; браузерный
ai-integration.spec.ts использует настоящую страницу потока с API-сборкой в
Astro dev и перехватывает только HTTP. Старые demo-тесты проверяют static build.
Локальные результаты и обязательный CI приведены в PR текущего среза.

Форматы экзамена, эталоны, баллы, генераторы и budgets не менялись.
НЕ ПРОВЕРЕНО: внешнее размещение Worker и реальные ответы OpenRouter;
имена моделей и серверный домен ещё не заданы. Человеческие Gates открыты.
