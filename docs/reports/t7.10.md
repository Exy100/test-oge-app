## Лаборатории и файлы

Документ показывает реальные строки и таблицу из набора, позволяет изменять
параметры и сохраняет их в ODT. HTML-предпросмотр схематичен и не обещает точной
печатной вёрстки. Слайд использует реальные иллюстрации, выбор объектов,
координаты/размеры и сохранение пропорций. Проверка основана на отношениях
между объектами, не требует единственной пары координат. ODP содержит весь текст,
три слайда и вложенные изображения.

Таблица содержит собственные 12 записей, нулевой балл и неравные категории.
Формулы разбираются ограниченным парсером без выполнения JavaScript: арифметика,
скобки, адреса/диапазоны, агрегаты, критерии и ROUND. Копирование сохраняет
фиксированные части и текстовые критерии. Ограничения языка явно перечислены.
Диаграмма использует собственную область; отбор для просмотра не меняет обычную
формулу. ODS содержит исходные ячейки, две формулы и редактируемую диаграмму.
Полный экзаменационный набор предоставляется отдельно, маленькая таблица его не заменяет.

Числовые поля сохраняют промежуточный ввод; до допустимого числа проверка
и экспорт блокируются. Скачивание создаёт файл текущего состояния; Blob URL
заменяется и освобождается при отключении. Экспорт загружается отдельно по
действию ученика. Данные и файлы остаются локальными.

Для загрузки отделены чистая геометрия слайдов и XML диаграммы от сборщиков
наборов. Прежние экспорты ядра сохранены, готовые наборы не изменились.
Самостоятельный модуль экспорта ODP отделён от ODT/ODS; бюджеты не ослаблялись.

## Независимая проверка офисных программ

`npm run check:office-lessons` создаёт 3 ODT, 3 ODP и 3 ODS, затем открывает
их в настоящем LibreOffice. Проверены три одностраничных документа Writer,
девять страниц Impress, исходные ячейки Calc, шесть формул с удалённым кешем
и три редактируемые круговые диаграммы с отрисованными подписями и легендой.

Результаты формул независимо вычисляются Python по исходным строкам;
проверка не читает сохранённый численный кеш вместо пересчёта. Порядок слов
при извлечении PDF может отличаться из-за выравнивания и соседних ячеек:
сохраняется точное количество всех текстовых токенов на странице, а порядок
ячеек дополнительно проверяется по ODF XML. После разделения модулей все девять
экспортов побайтово совпали с проверенными LibreOffice файлами.

Проверка добавлена в обязательный `check:office` файлового job CI, защищена
тестом release gate. Удалённый CI этой ветки не запускался.
