## Срез

Sitemap формируется из завершённой HTML-сборки, а не из ручного списка маршрутов.
Индексируемые страницы получают абсолютные URL с базой /test-oge-app/; noindex/404
не индексируются. Общая ссылка на карту добавлена в head. Новые HTML автоматически
попадают в карту; пустая сборка/карта останавливает build.

Браузерный обход читает карту и независимо сверяет её с каждым HTML на диске.
Неперечисленные страницы всё равно проверяются; отсутствие индексируемой страницы
в карте — ошибка. 404 проверяется настоящим запросом несуществующего маршрута.
В каждой теме и браузерном профиле проверяются вся страница через axe без
отключённых правил, язык, основной ориентир, заголовок, первый Tab/skip-link,
видимый фокус, загрузка ленивых интерактивов и отсутствие ошибок JavaScript.
Повторный axe видит раскрытые объяснения и размер текста 200 %; проверяется
отсутствие горизонтального переполнения страницы.

[Ручной чек-лист](../a11y-checklist.md) охватывает клавиатуру, NVDA/VoiceOver,
формулы/схемы/код, диалоги, таймер, 2D/3D, настоящий zoom, касание и 15-минутный
сценарий ученика. Человеческие галочки и вердикт агент не проставляет.
