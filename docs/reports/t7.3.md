# T7.3 — инфраструктура двумерных интерактивов

Дата: 2026-10-23 (Asia/Novosibirsk).

## Результат

`Interactive.astro` выводит цель, номера ОГЭ, управление и обязательную текстовую
альтернативу. React-оболочка подключается через `client:visible`, сцена — отдельным
динамическим импортом. Несуществующий путь к модулю вызывает ошибку сборки.
Сетевые ошибки и ошибки отрисовки изолированы error boundary с повторной попыткой.
Успешный модуль используется повторно; результат загрузки отключённого экземпляра
игнорируется. Неудачная загрузка не остаётся в кэше.

IntersectionObserver и Page Visibility управляют паузой; выключение анимации
в настройках сайта, в том числе из другой вкладки, и системный reduced motion
учитываются на лету. Пауза сохраняет состояние компонента. Общие hooks управляют
интервалом и animation frame, очищают их при паузе и отключении. Ручные действия
остаются доступны без анимации. Уменьшение движения не заменяется размонтированием.

Текстовое объяснение читается без JavaScript и раскрывается при печати. Состояние
загрузки, паузы и ошибки объявляется через живые области. До готовности клиента
кнопка паузы выключена. Фокус, нативные кнопки, светлая/тёмная темы и ширина 360 px
проверены. API, контракт ресурсов и шаблон карточки — [interactives.md](../interactives.md).

Сборочный тест обнаружил ошибку, незаметную в dev: URL сцены из серверного импорта
`?module-url` указывал на удаляемый prerender-чанк. Итоговый API принимает
`modulePath`; URL вычисляет клиентская карта модулей, а сборка проверяет наличие
файла. Тест собирает настоящий MDX с конфигурацией проекта и проверяет физическое
наличие клиентского чанка и его default-экспорта. Общий Vite-плагин не изменён.

Проверочная сцена `/dev/interactives` доступна только в режиме разработки.
В ней работают ручной и автоматический счёт битов, вычисление байтов и SVG.
Сцена не публикуется и не засчитывается в минимум 18 интерактивов. Учебных модулей
реестра пока 0; уроков — 0/45. Форматы M01–M16, генераторы и критерии не изменены.

## Проверки

- Vitest: **33/33**, три файла — жизненный цикл/загрузка (14), production MDX (1),
  регрессия данных и проверки вопросов урока (18).
- Playwright: **18/18** новых проверок в системном Chromium и мобильном проекте,
  по девять сценариев. Финальный прогон после исправления адресации — 45.6 с.
- Регрессия компонентов урока: **16/16** в тех же проектах, включая реальный ZIP,
  независимый ответ, навигацию, клавиатуру, печать и работу без JavaScript.
- В каждом из **20 циклов** подключения и отключения проверяется реальное
  количество ресурсов. Смонтированная сцена добавляет три нативных слушателя,
  один интервал, один animation frame и по одному Intersection/MutationObserver;
  после отключения все значения возвращаются к исходным. Успешный модуль
  повторно не запрашивается. Проверены также поздний результат загрузки,
  остановка интервала и кадров вне экрана и ручной шаг при reduced motion.
- Axe: **0 нарушений** в двух темах при 360 px; переполнения по горизонтали нет.
- `npm run lint`: успешно. `npm run typecheck`: 382 файла, 0 ошибок/предупреждений;
  два прежних hint об XMLValidator в ODF остаются.
- `check:forbidden`: 381 файл, 0 нарушений. `check:coverage`: текущая фаза 3,
  0 нарушений; пороги Gate 7 сохранены. `check:contrast`: 60 пар, минимум 5.51:1.
- Production-сборка основного сайта: **30 страниц**, успешно; dev-страницы
  в результат не попадают. Прежнее предупреждение о больших чанках сохраняется.

Firefox/WebKit локально **НЕ ПРОВЕРЕНО**: бинарники отсутствуют. Новый сценарий
входит в общую матрицу Playwright. Полные unit/e2e всей фазы и бюджеты публичных
уроков проверяются на Gate 7; текущий шаг проверен целевыми наборами. Подсчёт
ресурсов не является измерением heap. Собственные async-задачи и обработчики
каждого учебного модуля обязаны соблюдать документированный контракт очистки.
