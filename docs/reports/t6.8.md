# T6.8 — разбор практической работы

2026-10-31, Asia/Novosibirsk. В API-режиме экран завершённого варианта
предлагает разбор явно выбранного кода/алгоритма №15–16 и помощь по критериям
№13–14. В экзамене до завершения этих действий нет. Для №1–12 после завершения
используется общая панель T6.7; детерминированный вердикт не меняется.

Ученик видит и редактирует точный текст перед отправкой: до 3000 символов,
ответы по каждому уровню критериев — до 1500, весь запрос до 8 КБ. Длинная
сохранённая программа не изменяется: редактор явно сообщает о выборе фрагмента.
Имя офисного файла не подставляется вместо содержимого. Файлы не загружаются.

Оба края используют общий строгий gradeSchema. №15–16 допускают только
preliminary 0–2. Для №13–14 разрешены только criteria-help/score:null;
нулевой или другой балл отклоняется. Ответ показан текстом React, без HTML.
Кэш сохраняет только законченный проверенный JSON с повторной валидацией.

«Отклонить» сохраняет прежнюю оценку. «Принять» явно записывает aiAccepted
через существующую проверку актуальности попытки и пересчёт результата;
офисные предложения нельзя сохранить этим путём. Обычная самооценка сохраняет
источник self. Отзыв/смена данных/уход отменяют запрос и удаляют вывод.

Согласие теперь учитывает режим: прежняя policy разрешает только краткий
ответ, но не код или сводку. Импорт по-прежнему не переносит разрешение.
Новые unit проверяют типы/границы/согласие и происхождение сохранённого балла;
ai-work.spec.ts проверяет настоящий результат V01: отказ/принятие, кэш,
экранирование, office-null и ошибочный численный ответ. Локально два Chromium
сценария прошли; целевой unit-набор — 137/137. Полные результаты — в PR.

НЕ ПРОВЕРЕНО: качество реальной модели и внешнее развёртывание. Человеческий
вердикт по работам и Gate 6 не заполнялись. Форматы экзамена и шкала прежние.
