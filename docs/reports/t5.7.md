## Исправления, выявленные полным CI

1. Существующая проверка 1000 seed превысила лимит 30 с на порции из 250 seed.
   Теперь 8 порций по 125: сохранены все 1000 уникальных seed, обе ветки №13,
   проверки детерминизма/состава/баллов и покрытия генераторов в каждой порции.
   Лимит 30 с не изменён.
2. Визуальный тест не ожидал завершения асинхронной смены темы. Перед снимком
   проверяется фактический `html[data-theme]`. Эталоны и порог 0.5% не менялись.
3. При повторе unit-группы в CI оставались два blob с одинаковым именем;
   объединение выбирало старый отчёт с таймаутами вместо нового успешного.
   ADR-048: уникальные имена по попытке, выбор самого нового created_at для
   каждого shard и загрузка трёх конкретных ID. История сохраняется; отсутствующие,
   истёкшие, повреждённые и неоднозначные отчёты приводят к ошибке. Только
   coverage-job получил `actions: read` для метаданных текущего запуска.
