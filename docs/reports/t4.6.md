# T4.6 — горячие клавиши и полное прохождение потока

На странице https://exy100.github.io/test-oge-app/stream/ клавиши N, Т в русской
раскладке и → открывают следующее задание. Неотвеченная задача пропускается.
Переключатель «Горячие клавиши N и →» отключает эти действия до перезагрузки
страницы. Обычная кнопка перехода остаётся доступной; при включённых клавишах
она сообщает сочетания через `aria-keyshortcuts`.

Enter сохраняет обычное действие формы или кнопки. Форматная ошибка оставляет
фокус в ответе; после принятия ответа/самооценки фокус переходит к результату,
после смены задания — к его заголовку. Это позволяет прочитать вердикт и нажать
N/→ без прохода по остальным полям карточки.

Клавиши перехода не перехватывают ввод ответа, код, черновик, выбор критериев,
фильтры, ссылки, кнопки помощи, раскрытие details, прокрутку кода и MathML.
Игнорируются модификаторы, удержание клавиши, IME-композиция и уже отменённые
события. Блокировка перехода действует также при загрузке и пустом результате
подбора. Слушатель использует актуальные состояние/фильтры через React
`useEffectEvent` и удаляется при размонтировании.

## Переходы без сети

Рендерер условия загружается после гидратации, до активации полей и переходов.
Поэтому переход к следующей задаче в уже открытой странице не требует загрузки JavaScript:
потеря соединения во время решения больше не прерывает этот переход. Это
не обещает работу новых вкладок, подсказок и файловых загрузок без сети.

Перед подготовкой следующей задачи управление уступает кадр браузеру, чтобы
обновить состояние занятости. Синхронная блокировка исключает второй переход
в том же кадре; маркер навигации отменяет переход после внешнего обновления
статистики. При ошибках генерации, отображения или истории сохраняется текущая
карточка, а неуспешный переход не создаёт попытку и не продвигает очередь.
При недоступном localStorage продолжает работать прежний режим хранения в памяти
с видимым предупреждением.

Если первая загрузка рендерера не удалась, ученик видит исходное условие и
сообщение об ошибке; ввод и переходы остаются отключёнными. Тест принудительно
обрывает эту загрузку и проверяет сообщение, блокировку и отсутствие попыток.

Подпись очереди в фильтрах и её документация обновлены: после T4.5 она сохраняется
после перезагрузки. Сам алгоритм повторений и хранения этим шагом не менялся.

## Сквозной сценарий

`tests/e2e/stream-journey.spec.ts` проходит 20 задач публичного потока через UI:

- 13 верных и 7 неверных ответов, пять дополнительных ошибок формата без штрафа;
- три подсказки и всё решение в двух задачах, с сохранением черновика;
- смена выбранных номеров после шестого ответа, без лишней попытки;
- копирование ссылки при недоступном Clipboard API и открытие той же задачи
  с теми же фильтрами в отдельной вкладке;
- чередование N и → после принятого ответа, проверка сброса черновика/подсказок;
- проверка счётчиков после каждого ответа, точности 65% и сохранения 20 результатов
  после перезагрузки; axe на финальном состоянии.

Видеозапись включена для этого файла через `test.use({video:'on'})`, включая
успешные прохождения. Существующий CI сохраняет `test-results/` в артефактах
`quality-reports-1` / `quality-reports-2` на семь дней. Общие настройки трасс,
порогов, снимков, таймаутов и числа браузеров сохранены.

### Диагностика первого CI

В прогоне `fec7e3a`
[39053104710](https://github.com/Exy100/test-oge-app/actions/runs/39053104710)
группа unit 2/3 завершилась кодом 1. Публичная аннотация содержала только код
выхода; подробный лог через доступное подключение требует входа в GitHub.
Причина этого первого сбоя не подтверждена. Та же группа локально, с покрытием
и прежними параметрами сбора, прошла: 18 файлов / 438 тестов, 140,57 с.

Явные `default` и `blob` заменяли автоматический GitHub-репортёр Vitest.
В команду unit-групп добавлен штатный `github-actions`, чтобы сбой получал
название теста, сообщение и позицию в публичной аннотации. Порог общего покрытия,
параметры шардирования, таймауты и отсутствие автоматических повторов сохранены.
`actionlint` 1.7.7 прошёл; архив инструмента сверён SHA-256 из релиза.
Положительная проверка репортёра: 8/8 unit. Отрицательная проверка в отдельном
игнорируемом каталоге сохранила exit 1 и выдала аннотацию с названием и строкой
намеренно неверного теста. Этот тест не входит в репозиторий или CI.

WebKit выявил проблему отложенной загрузки рендерера: после принудительного
обрыва JS-запросов приложение не восстанавливалось ни перезагрузкой, ни открытием
новой вкладки. Диагностика в
[39056149874](https://github.com/Exy100/test-oge-app/actions/runs/39056149874)
показала `Error hydrating Stream: TypeError: Importing a module script failed.`
Внутренняя причина сохранения отказа в WebKit не установлена. Итоговое исправление
устраняет сетевую загрузку из перехода: рендерер готов до активации полей.
Его статическое включение в стартовый код проверялось и превысило бюджет LCP;
поэтому загрузка выполняется после гидратации, с блокировкой ввода до готовности.
Тест теперь требует успешных переходов через 20 задач при отключённой сети и
запрете новых JS-запросов. Пороги, таймауты, снимки и четыре браузерных проекта
сохранены; WebKit проверяется полным CI.

Повторный CI диагностического коммита `924f493`,
[39053966299](https://github.com/Exy100/test-oge-app/actions/runs/39053966299),
успешно выполнил все три unit-группы и объединённое покрытие. Первый unit-сбой
не воспроизвёлся ни локально, ни в повторном CI; подтверждённая причина
не установлена.

## Локальная запись видео

В этой облачной среде CDN Playwright отвечает `403 Domain forbidden`.
Для локальной проверки использован установленный системный FFmpeg 7.1.5,
через отдельный адаптер путей в `/tmp`; штатный пакет Playwright не подменяется
в репозитории и его загрузка не объявляется успешной. Команды перед тестами:

```sh
mkdir -p /tmp/oge-playwright/ffmpeg-1011
test -e /tmp/oge-playwright/ffmpeg-1011/ffmpeg-linux || ln -s /usr/bin/ffmpeg /tmp/oge-playwright/ffmpeg-1011/ffmpeg-linux
export PLAYWRIGHT_BROWSERS_PATH=/tmp/oge-playwright
export PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium
export ASTRO_TELEMETRY_DISABLED=1
```

CI устанавливает штатные Chromium, Firefox, WebKit и FFmpeg через существующий
`npx playwright install --with-deps chromium firefox webkit`; локальные пути
и системный FFmpeg туда не переносятся.
