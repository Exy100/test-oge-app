# T4.6 — горячие клавиши и полное прохождение потока

На странице https://exy100.github.io/test-oge-app/stream/ клавиши N, Т в русской
раскладке и → открывают следующее задание. Неотвеченная задача пропускается.
Переключатель «Горячие клавиши N и →» отключает эти действия до перезагрузки
страницы. Обычная кнопка перехода остаётся доступной; при включённых клавишах
она сообщает сочетания через `aria-keyshortcuts`.

Enter сохраняет обычное действие формы или кнопки. Форматная ошибка оставляет
фокус в ответе; после принятия ответа/самооценки фокус переходит к результату,
после смены задания — к его заголовку. Это позволяет прочитать вердикт и нажать
N/→ без прохода по остальным полям карточки.

Клавиши перехода не перехватывают ввод ответа, код, черновик, выбор критериев,
фильтры, ссылки, кнопки помощи, раскрытие details, прокрутку кода и MathML.
Игнорируются модификаторы, удержание клавиши, IME-композиция и уже отменённые
события. Блокировка перехода действует также при загрузке и пустом результате
подбора. Слушатель использует актуальные состояние/фильтры через React
`useEffectEvent` и удаляется при размонтировании.

## Восстановление и сохранение

Проверка отказа загрузки выявила, что повторный dynamic import после сетевой
ошибки не во всех случаях восстанавливается в той же вкладке. Поток предлагает
явную перезагрузку: перед ней нужно скопировать черновик и скачать свой код.
До нажатия кнопки карточка и данные сохраняются. Неудачный переход не создаёт
попытку и не продвигает очередь. Если LocalStore работает в памяти, сообщение
отдельно предупреждает о возможной потере результатов при перезагрузке.

Подпись очереди в фильтрах и её документация обновлены: после T4.5 она сохраняется
после перезагрузки. Сам алгоритм повторений и хранения этим шагом не менялся.

## Сквозной сценарий

`tests/e2e/stream-journey.spec.ts` проходит 20 задач публичного потока через UI:

- 13 верных и 7 неверных ответов, пять дополнительных ошибок формата без штрафа;
- три подсказки и всё решение в двух задачах, с сохранением черновика;
- смена выбранных номеров после шестого ответа, без лишней попытки;
- копирование ссылки при недоступном Clipboard API и открытие той же задачи
  с теми же фильтрами в отдельной вкладке;
- чередование N и → после принятого ответа, проверка сброса черновика/подсказок;
- проверка счётчиков после каждого ответа, точности 65% и сохранения 20 результатов
  после перезагрузки; axe на финальном состоянии.

Видеозапись включена для этого файла через `test.use({video:'on'})`, включая
успешные прохождения. Существующий CI сохраняет `test-results/` в артефактах
`quality-reports-1` / `quality-reports-2` на семь дней. Общие настройки трасс,
порогов, снимков, таймаутов и числа браузеров сохранены.

## Локальная запись видео

В этой облачной среде CDN Playwright отвечает `403 Domain forbidden`.
Для локальной проверки использован установленный системный FFmpeg 7.1.5,
через отдельный адаптер путей в `/tmp`; штатный пакет Playwright не подменяется
в репозитории и его загрузка не объявляется успешной. Команды перед тестами:

```sh
mkdir -p /tmp/oge-playwright/ffmpeg-1011
test -e /tmp/oge-playwright/ffmpeg-1011/ffmpeg-linux || ln -s /usr/bin/ffmpeg /tmp/oge-playwright/ffmpeg-1011/ffmpeg-linux
export PLAYWRIGHT_BROWSERS_PATH=/tmp/oge-playwright
export PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium
export ASTRO_TELEMETRY_DISABLED=1
```

CI устанавливает штатные Chromium, Firefox, WebKit и FFmpeg через существующий
`npx playwright install --with-deps chromium firefox webkit`; локальные пути
и системный FFmpeg туда не переносятся.
