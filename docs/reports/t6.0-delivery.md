# Доставка T6.0 — готовность уроков в Firefox и WebKit

Демонстрационный разбор T6.0 слит в PR №20, исходный коммит `f9cf93c` прошёл
21 обязательную группу CI и полный локальный verify. Итоговый `main 572ef7d`
не прошёл CI 40685519026: старый сценарий `materials.spec.ts` на mobile Firefox
не снял отметку урока после перезагрузки, а WebKit прервал переход из урока №4
в поток внутренней ошибкой браузера. Успешны 19 из 21 обязательной группы;
публикация пропущена. Доставка требует полного успешного CI исправления
и итогового main.

## Причина и исправление

Трасса фиксирует реальную последовательность: после reload кнопка уже доступна
с `aria-pressed="false"`, хотя сохранённый урок пройден и React ещё не подключён.
Клик начат на отметке времени 401137; гидратация происходит на 401302.
React сообщает несовпадение `disabled`: ожидается `true`, фактически атрибута нет.
Ранний клик не снимает отметку; каталог верно показывает сохранённое `1 из 1`.

Firefox восстанавливает динамическую доступность кнопок между загрузками.
Для кнопки «Урок пройден» эта возможность отключается `autocomplete="off"`.
Исходный `disabled={!ready}` теперь сохраняется до подключения обработчика,
после чего восстанавливается настоящая отметка из локального хранилища.
Это поддерживаемый Firefox атрибут, отсутствующий в типе кнопки React;
использовано локальное типизированное расширение без подавления TypeScript.

Меняется только восстановление доступности этой кнопки. Формат хранилища,
переключение отметок, результаты квиза и уровни игр остаются прежними.
Демонстрационный адаптер и панель T6.0 не изменялись.

Трасса WebKit подтверждает клик по правильной ссылке и попытку навигации,
после которой документ потока завершился ошибкой `WebKit encountered an internal error`.
В этот момент модуль отметки урока ещё загружался; его импорт отменён навигацией.
Сценарии плана подготовки теперь проверяют готовность кнопки «Урок пройден»
до ухода из урока. Сохраняются обычные клики, проверки URL, номера задания
и готовности потока; адрес, геометрия ссылки и код навигации не меняются.

## Регрессия и проверки

Новый браузерный сценарий сначала сохраняет пройденный урок, затем задерживает
модуль `LessonCompletion` при reload. После загрузки документа и прокрутки
кнопка должна оставаться отключённой. После освобождения модуля проверяются
настоящая отметка, обычный клик снятия и сохранение снятой отметки после reload.
Исходный сценарий между вкладками сохранён целиком, включая финальное `0 из 1`.
Нет принудительного клика, повторного клика, подмены хранения или увеличения ожиданий.

Предварительная проверка WebKit в CI дополнена переходами через уроки №3, №4 и №9.
Вместе с прежними переходами через уроки №5 и №6 это 20 повторных сценариев:
два сценария, пять повторов, настольный и мобильный WebKit. Полная матрица
всех шести браузерных профилей и 20-минутные ограничения сохранены.

TypeScript/Astro: 0 ошибок, 0 предупреждений, два прежних уведомления XMLValidator.
Сборка: 76 страниц, sitemap 75 URL; ESLint и форматирование изменённых файлов прошли.
Пять unit-проверок обязательных CI-групп и actionlint прошли. Первый локальный
запуск двух unit-проверок был заблокирован запретом дочернего процесса в среде;
повтор в доступном режиме прошёл все пять без изменений кода или проверок.
Локально Chromium и мобильный Chromium прошли 40 сценариев: исходная проверка
отметки между вкладками, новая регрессия с задержанным модулем и два сценария
переходов через уроки — каждый по пять раз в обоих профилях.
Браузерные результаты и CI точных исходного/итогового коммитов фиксируются в PR доставки.
Проверки Firefox в полном CI обязательны; локальный Chromium их не заменяет.
