# T7.4 — каталог материалов, карта и прогресс

Дата: 2026-10-23 (Asia/Novosibirsk).

## Результат

Добавлен `/materials/`: 14 разделов по spec §10.1, SVG-карта учебных основ,
доступный список, несколько выбранных номеров 1–16 и рабочие переходы к практике.
№4/9 объединены в графы, №11/12 — в файлы; №13 ведёт отдельно к презентации
и документу. Компьютерная часть выделена в списке. Каталог доступен из основной
навигации и с главной. Пререквизиты на карте — рекомендуемый порядок повторения,
не ограничение доступа и не официальный порядок тем ФИПИ.

Фильтр хранится в URL, восстанавливается при перезагрузке и работает с историей
браузера. Ошибочная ссылка показывает все темы с пояснением. Ссылки карты
и учебных основ снимают фильтр перед переходом к разделу. SVG прокручивается
на узком экране, узлы доступны с клавиатуры. Длинные стрелки обходят другие узлы.

Настоящая коллекция формирует карточки и маршруты
`/materials/[section]/[lesson]/`. Проверяются повторы id, существование основ
и отсутствие циклов. Урок располагается после пререквизита; навигация остаётся
внутри раздела. LessonHeader автоматически получает ссылки из коллекции.
Правила id и подготовки MDX — [materials.md](../materials.md).

«Урок пройден» — ручная обратимая отметка. Она использует существующий
`lessonProgress` v1, сохраняет результаты мини-теста и уровни, обновляется
между вкладками и переносится экспортом/импортом настроек. Отметки отсутствующих
уроков не увеличивают прогресс. При отказе localStorage доступна память страницы
с честным уведомлением; превышение лимита 500 записей не удаляет старые данные.
Тренировки и самооценки показаны отдельно и не отмечают урок автоматически.

Уроков в публичной коллекции пока **0/45**, учебных интерактивов **0/18**.
Фиктивных карточек и процентов 0/0 нет. Все темы уже ведут на настоящую практику.
Dev-каталог использует рабочую галерею компонентов; два полноценных MDX из теста
собираются только во временном проекте и не засчитываются в учебный минимум.
Экзаменационные форматы, генераторы и критерии не изменены.

## Производительность

Каталог и карта рендерятся Astro; `src/scripts/materials.ts` меняет фильтр
и локальные счётчики. React подключается на страницах уроков, где он нужен
для учебного взаимодействия. Это выполняет бюджет страницы без интерактивов:
**38 252 байта gzip (37,36 КиБ)** всех загруженных JS-модулей и встроенного кода.
В Playwright добавлена проверка лимита **60 000 байт**, учитывающая реальные
запросы страницы. Порог spec §15 и остальные проверки не ослаблены.

Три финальных мобильных прогона Lighthouse с прежними assertions проекта:

| Метрика | Результат |
|---|---|
| Performance | 99 / 98 / 98 |
| Accessibility / Best Practices / SEO | 100 / 100 / 100 во всех прогонах |
| LCP | 1,81–1,96 с |
| CLS | 0 |

Отчёты сохраняются в `.lighthouseci/materials/`; новый URL добавлен также
в постоянную матрицу `lighthouserc.cjs`. Измерялся отдельный новый маршрут,
с теми же порогами и тремя запусками, без параллельной нагрузки браузерных тестов.

  №13.1/13.2, реальный независимый ответ №10, вкладки, экспорт/сброс/импорт,
  ошибки хранилища, отсутствие JavaScript, бюджет JS, темы и размер текста 200%.

  Визуально просмотрены карта на большом экране и мобильные карточки.
- Финальные `lint` и `typecheck` успешны: 395 файлов, 0 ошибок/предупреждений;
  два прежних hint об XMLValidator в ODF сохраняются.
- `check:forbidden`: 395 файлов, 0 нарушений; `check:coverage` текущей фазы 3:
