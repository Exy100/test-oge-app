# T5.3 — рабочее место №13–16 в экзамене

Дата: 2026-10-21 (Asia/Novosibirsk).

## Возможности ученика

В варианте с таймером для №13 явно выбирается презентация или документ.
Смена работы требует подтверждения и очищает только прежнюю запись №13.
Для №13–14 доступны исходные файлы, макеты и учебные критерии; запись имени
работы не заменяет сохранение самого файла на компьютере. Эталонных офисных
файлов в экзаменационном ZIP нет.

№15 использует общее с потоком рабочее место Робота: поле из условия,
текстовый редактор, описание языка, шаг, запуск, пауза, сброс выполнения
и выгрузка `answer.txt` в UTF-8. Все действия доступны с клавиатуры; Tab
выводит фокус из редактора. До завершения доступно только поле из условия.
Успех на нём не выдаётся за доказательство для семейства или официальный балл.

№16 использует общий редактор Python с выгрузкой `answer.py` в UTF-8,
примером ввода и вычисленного вывода из условия. Инструкция объясняет запуск
`python3 answer.py`, вариант Windows `py -3 answer.py` и ввод строк примера.
Python выполняется на компьютере ученика. Остальные тесты и эталон появляются
в полном наборе после завершения экзамена.

Оба редактора работают с ответами текущей попытки, а не отдельным несохраняемым
состоянием. Навигация, тики таймера и перезагрузка сохраняют код и черновики.
Лимит экзаменационного кода — 20 000 символов, одинаковый у редактора,
контроллера и схемы хранилища. Экспорт сохраняет исходные символы и переводы
строк. При возврате к Роботу выполнение начинается заново, код остаётся:
старая анимация не продолжается на другом номере. Интервалы, выполнение
и ссылки выгрузки освобождаются при уходе. Просмотр файлов получил собственные ограничения
ширины и высоты в `task-files.css`: длинный README в завершённом разборе
больше не расширяет мобильный viewport. Проверка раскрывает оба разбора
и скачивает файлы обычными нажатиями, без принудительных кликов; отдельно
сверяется `scrollWidth` с `clientWidth`.

## Общие компоненты и сверка

- `ExamRun.tsx` подключает существующие `RobotPractice` и `PythonPractice` в
  режиме экзамена и передаёт код через `ExamSession.answer`. В потоке остаётся
  тренировочный режим этих же компонентов.
- `CodeEditor.tsx` принимает размер текущего режима; в потоке сохранён предел
  32 000 символов. `CriteriaLevels.tsx` показывает один рубрикатор для потока
  и экзамена; выбор самооценки в экзамене не добавлен этим шагом.
- spec §9.6: выбор №13 и исходники — `VariantExam`, `ExamRun`, `ExamTask`,
  `TaskFiles`; Робот — `RobotPractice`; Python — `PythonPractice`, `CodeEditor`;
  восстановление — существующие `ExamSession` и `variantDraft`.
- spec §7.3: учебный характер проверки и критериев явно указан; офисные файлы
  не передаются серверу, вычислитель Python в браузер не добавлен.
- spec §14 / §10.4: доступный текстовый ввод, Tab, клавиатурное управление,
  обе темы, 360 px / 200%, reduced motion и очистка ресурсов проверяются e2e.
- Генераторы, данные и матрица M13p/M13d/M14/M15/M16 не менялись. Открытые
  расхождения №16 (Q-I8) и предметное ревью Gate 3 сохраняются. «Реши как ученик»
  для новых генераторов к этому изменению не относится: новых задач нет.

## Восстановление загрузки T5.2

Последний исходный коммит `bcfae3d` не был опубликован: в CI
[39127682421](https://github.com/Exy100/test-oge-app/actions/runs/39127682421)
один тест WebKit упал после искусственного прерывания загрузки условий
случайного варианта. В сохранённой трассе первая загрузка модуля отменена,
после перезагрузки запроса этого модуля нет, в интерфейсе остаётся ошибка.
Остальные 478 тестов этой группы прошли; публикация была пропущена.

Исправление оформлено отдельно от T5.3: небольшой Vite-плагин
`scripts/lazy-module-url.mjs` возвращает URL собранного ESM-модуля. Загрузчик
условий добавляет свежий параметр к URL при новой попытке. Это тот же модуль
и тот же сборщик, без дублирования заданий. В dev используется Vite URL исходника.
Содержание загружается только при раскрытии номера. Разрешения CSP и зависимости
не менялись. Исходный тест с `route.abort()` сохранён и дополнен проверкой,
что после перезагрузки сделан новый запрос по тому же пути сборки.

## Проверки и продолжение

Сценарии включают экспорт обоих языков, сохранение 20 000 символов Python,
восстановление обоих редакторов и черновика, клавиатурное выполнение Робота,
исходники без эталонов, альтернативы №13, доступность №13–16 и разбор после
завершения. Локальные результаты:

- 48/48 браузерных проверок вариантов: Chromium и эмуляция телефона, включая
  все сценарии T5.2, новый рабочий стол и восстановление отменённой загрузки.
- 130/130 существующих проверок общей карточки прошли до переноса ограничений
  предпросмотра. После переноса 16/16 файловых сценариев повторно прошли:
  точные ZIP №11–16, критерии с клавиатуры и освобождение object URL.
- 11/11 профильных unit-тестов `ExamSession`: время, сохранение, смена №13,
  конфликты вкладок, лимиты и завершение.
- ESLint/Prettier, Astro/TypeScript: 0 ошибок, две прежние подсказки XMLValidator;
  запреты: 308 файлов, 0 нарушений; инвентарь: 0 нарушений; контраст: 60 пар,
  минимум 5,51:1; статическая сборка: 18 страниц.
- Полный локальный `npm run verify` был прерван после таймаутов неизменённых
  ODF-кампаний и теста сборщика при одновременном прогоне тяжёлых проверок.
  Таймауты, число seed и пороги покрытия сохранены. Поэтому успешный локальный
  полный `verify` не заявляется: обязательные полные unit/coverage и проверки

  запуска не скрыты и не засчитаны как успешные тесты.
- Firefox и WebKit локально не установлены; их полный прогон, включая исходный
