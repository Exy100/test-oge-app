# T5.2 — прохождение варианта с таймером

Дата: 2026-10-18 (Asia/Novosibirsk).

## Доступный срез

На любой странице V01–V10 и случайного варианта есть «Пройти с таймером».
Ученик явно выбирает 13.1 или 13.2 и запускает экзамен. До запуска время не идёт.
В экзамене доступны все 16 номеров, краткие ответы, черновики, записи файлов
офисных работ и программы в текстовом поле. Номер можно отметить для возврата.
Запись имени файла помечена как запись, а не как проверенная готовая работа.

Продолжительность берётся из `examConfig`: 150 минут по S27, без отдельных
таймеров для частей. `Date.now()` сравнивается с началом работы; сон вкладки
и закрытие страницы не приостанавливают экзамен. Сохранённое прошедшее время
не уменьшается при переводе часов назад. По истечении срока работа завершается
на первом тике, вводе, возврате вкладки или восстановлении. Время ограничено
дедлайном; поздний ввод не меняет отправленные ответы.

Каждые 10 секунд, при `visibilitychange`, `pagehide` и уходе сохраняются ответы,
черновики, отметки и выбор №13. Навигация внутри варианта сохраняет поля в памяти;
при восстановлении открывается первый номер без записи. Незавершённая работа
видна в каталоге. Замена текущей работы и смена №13 требуют подтверждения;
во втором случае очищаются только прежние записи и самооценка №13.

До конца отсутствуют проверка ответа, подсказки, эталоны и переходы в практику.
Досрочное завершение показывает пустые и отмеченные номера, допускает отмену.
После завершения ответы фиксируются в истории, очищается текущий черновик,
открываются проверка №1–12 и разбор. Практика не получает выдуманный ноль;
общий балл в новой записи остаётся `null`. Адрес с `exam=<attemptId>` повторно
открывает сохранённый разбор после перезагрузки.

## Реализация и устойчивость

- `src/core/variants/exam.ts`: контроллер попытки, время, сохранение,
  защита от внешней замены данных, завершение и последние 100 попыток.
- `src/components/variants/ExamEntry.tsx`: лёгкий экран запуска с сохранением
  статичных условий без JavaScript. Генераторы загружаются при начале работы,
  разбор — при открытии завершённой попытки. `VariantExam` — выбор работы, восстановление и замена;
  `ExamRun` — интерфейс, события браузера и очистка ресурсов после завершения.
- Web Locks допускает одного редактора текущего экзамена. При отсутствии API
  остаётся проверка сохранённой версии перед записью; атомарная одновременная
  запись нескольких вкладок в таком браузере не гарантируется.
- Изменение или удаление черновика в другой вкладке останавливает писателя,
  оставляя локальные ответы для скачивания. Блокировка и переполнение
  localStorage используют общий режим памяти с явным предупреждением.
- Сохранение результата и очистка черновика выполняются общей транзакцией
  LocalStore с журналом. При слишком большой истории завершённая копия остаётся
  доступной для скачивания, сохранённый черновик не удаляется молча.
- JSON с собственными ответами можно скачать во время работы и после неё.
  Офисные файлы не загружаются, персональные данные не запрашиваются.
- `exam-dataset.ts` выбирает исходники №11–14 и данные заданных макетов.
  `reference/`, примеры оценок, критерии и README с указанием эталона не попадают
  в офисный экзаменационный ZIP. Байты исходников остаются прежними.
- `TaskFiles` переиспользован с режимом `exam`, текст и рисунки — общие.
  Условие мемоизировано и не форматируется заново каждую секунду таймера.
- Схема хранения сохраняет version 1 и прежние поля. Верхняя граница `variantId`
  расширена с 200 до 240, чтобы сохранить допустимый seed длиной 200 символов
  вместе с префиксом сборщика; старые данные и экспорты продолжают читаться.

## Трассировка требований

| Требование | Реализация и проверка |
| --- | --- |
| spec §9.6, 150 минут и сон вкладки | `exam.ts`; unit и браузерная подмена времени через дедлайн |
| Навигация и отметки | `ExamRun`; все 16 номеров, восстановление ответов и отметок |
| Автосохранение и восстановление | `ExamSession.save`, события браузера; 9/10 секунд, перезагрузка и `visibilitychange` |
| Предупреждение при уходе | `beforeunload`; переход из случайного варианта с несохранённым кодом |
| Завершение | Контроллер и Modal; отмена, список пустых, дедлайн, одна запись истории |
| Выбор №13 | `VariantExam`, `choose13`; отмена и подтверждение, очистка прежней работы |
| spec §8, отказ хранилища | Общий LocalStore; unit квоты и e2e запрета доступа, скачивание своей копии |
| spec §15, доступность | Общий Modal, фокус, подписанные поля, таймер без ежесекундного live; axe, клавиатура, темы, 360 px / 200% |

## Фактические проверки

- 51/51 unit: 11 проверок экзамена, исходные файлы всех V01–V10 и обеих работ
  №13, четыре проверки ссылок и существующие проверки хранения.
- 38/38 браузерных проверок Chromium/mobile: 22 новых и 16 регрессий каталога.
  Восстановление, дедлайн после сна, раннее завершение, две вкладки, удаление
  данных, скачивание исходников, смена №13, длинный seed, отказ хранилища и
  подтверждение замены текущей работы и отказ загрузки экзаменационного модуля.
  Повторные прогоны не суммируются.
- Axe: запуск, прохождение, диалог и завершение в обеих темах; клавиатура,
  возврат фокуса, 200% текста и ширина 360 px. Ошибок JavaScript и переполнения нет.
- ESLint/Prettier, Astro/TypeScript (0 ошибок, две прежние подсказки XMLValidator),
  сборка 18 страниц, запреты и инвентарь пройдены. Контраст: 60 пар, минимум 5,51:1.

Финальная сборка: по три замера Lighthouse затронутых страниц; все assertions
пройдены. Accessibility, best-practices и SEO — 100, CLS — 0.

## Границы шага

Генераторы и матрица M01–M16 не менялись; используются подтверждённые ранее
форматы и источники `docs/exam-format.md`. Это T5.2, не завершение фазы 5.
Редактор и экспорт программ, учебный запуск Робота и расширенное восстановление
практической работы — T5.3. Общий комплект и памятка — T5.4, тренировка — T5.5,
полная страница результата с самооценкой — T5.6.

Человеческий пилот не проводился: T4.8, предметное ревью Gate 3 и будущий T5.8
остаются открытыми. Сценарий проверки — [t5.2.md](../reviews/t5.2.md).
