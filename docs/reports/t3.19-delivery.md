# T3.19 — неподвижная ссылка из урока в практику

Основной срез слит в PR №17 (`c1025c8`), но доставка остановлена проверкой
`main` 40589005560: в повторном сценарии mobile WebKit клик из урока №5
не открыл поток. Остальные проверки не обходятся; нужен полный CI исправления
и успешная публикация итогового main.

## Причина и поведение

Трасса фиксирует смену текста статуса `InteractiveHost` с «Интерактив готов
к работе» на более длинное сообщение об остановке вне экрана во время клика.
Панель меняет высоту и сдвигает расположенную ниже ссылку. Локальный тест
воспроизводит изменение на мобильном экране: панель 124 → 152 px, положение
практики 9657 → 9685 px. Поэтому одно ожидание загрузки сцены проблему не решает.

Панель теперь резервирует место для каждого настоящего сообщения средствами
CSS Grid при текущей ширине и размере шрифта. Невидимые измерительные элементы
не содержат DOM-текста, не принимают события и скрыты от accessibility tree;
текст через CSS берётся из тех же строк статуса. Живая область сообщает только
актуальный статус. Изменения паузы, предпочтения анимации и видимости сцены
сохраняют положение ссылок ниже неё без таймеров и измерений JavaScript.

## Проверка

Добавлен браузерный сценарий, который проверяет неизменность высоты панели
и положения практики при паузе, продолжении, reduced motion и уходе сцены
из viewport, затем выполняет настоящий клик по ссылке. До исправления сценарий
падает на мобильном Chromium со сдвигом 28 px; desktop проходит.

Существующий переход из результатов через уроки №5/6 в практику остаётся
в прежнем виде и в обязательном CI повторяется пять раз в каждом профиле
WebKit. Проверка не подменена клавиатурной навигацией, прямым переходом по URL,
повторным кликом, force или допуском координат. retries=0 и лимиты сохранены.

Изменены только общий статус интерактива, его CSS и регрессия. Форматы №16,
генераторы, сохранённые попытки, числовые проверки и критерии не меняются.
Фактические результаты локальных проверок и CI итогового SHA фиксируются
в PR доставки; эта запись не подтверждает ещё не выполненные проверки.

Локально после исправления: 20 сценариев успешно — регрессия геометрии и
исходные переходы через уроки №5/6, каждый по пять раз на Chromium и mobile.
TypeScript/Astro: 0 ошибок, 0 предупреждений, два прежних уведомления
XMLValidator. Сборка, ESLint и форматирование изменённых файлов прошли.
Проверки всех браузеров, доступности, Lighthouse и печати обязательны в CI.

Человеческие Gates 3–5/7/8/9 остаются открыты. Финальная приёмка и ИИ-фаза
не объявляются выполненными.
