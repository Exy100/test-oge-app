# T4.8 — замечание владельца о текстах №2

Дата: 2026-10-18 (Asia/Novosibirsk). T4.8 остаётся открытой: наблюдений учеников нет.

## Проблема и исправление

Владелец прислал скриншот подсказок «Сопоставь начальные знаки сигнала с кодами
таблицы» и «Сохрани порядок всех букв». Эти фразы почти не помогали сделать
следующий шаг. Один и тот же шаблон использовался для всех форматов расшифровки,
а решение сразу показывало готовое разбиение, не объясняя выбор кода.

Все три экзаменационных формата №2 теперь используют `decode-guidance.ts`:

- Для кодов одной длины объясняется деление на группы с указанием длины,
  первых групп и соответствующих букв.
- Если один код совпадает с началом другого, указаны настоящая позиция развилки,
  подходящие коды и остатки, которые нельзя прочитать. Например, при выборе
  `~#` в записи `~###` остаётся `##`, к которому не подходит ни один код таблицы.
  Проверяются все достижимые продолжения; допустимый вариант не объявляется ошибкой.
- В полном разборе показаны все группы и таблица «номер буквы / код / буква»;
  для обычной расшифровки выполнена проверка обратным кодированием.
- В задании на повторяющиеся буквы подсчитана каждая буква и объяснено,
  почему в ответе она записывается один раз.

Матрица форматов: M02a, M02b. Условия, ответы, генераторы данных и идентификаторы
по seed сохранены. Обновлены производные примеры №2 и готовые комплекты V01–V10,
чтобы скачанные разборы совпадали с текущей версией генераторов.

  `variants.test.ts`. Включены общий harness с 500 seed на каждый генератор,
  независимые экзаменационные решатели, фикстуры и воспроизводимость комплектов.
- Шесть новых предметных тестов: правильный короткий и длинный коды, тупик
  после нескольких групп, развилка после первой буквы, отсутствие развилки,
  подсчёт повторов и обратное восстановление групп на 32 seed каждого формата.
- Playwright: 34/34 Chromium/mobile, включая шесть новых проверок трёх форматов
  №2, пошаговое раскрытие, клавиатуру, таблицу разбора и axe.
- ESLint/Prettier и Astro/TypeScript пройдены; 0 ошибок, две прежние подсказки

- Проверки запретов и инвентаря успешны; 60 пар контраста, минимум 5,51:1.
