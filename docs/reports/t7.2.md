# T7.2 — компоненты урока

Дата: 2026-10-22.

## Результат

Добавлены LessonHeader, Motivation, Theory, Examples/Example, Mistakes/Mistake,
Quiz/Question, StreamLink, CheatSheet, LessonNav и TOC. Они работают в настоящем
MDX: `src/dev/lesson-components.mdx`, маршрут `/dev/lessons` только для dev-сервера.
[Свойства и использование](../lesson-components.md).

Example восстанавливает задачу по реестру и seed, показывает условие, рисунок
и шаги вычисленного решения. Шаги открываются по одному с переводом фокуса;
без JavaScript доступны через нативное раскрытие. Для авторского документа D01
готовится настоящий ZIP с `source/material.odt` и `reference/answer.odt`.

Question проверяет краткий ответ общим checker и поддерживает вопросы с выбором.
Можно исправлять ответ; состояние соседних вопросов сохраняется. Объяснения
известных ошибок, формат и алфавит поступают из данных задачи. Artifact-работа
не допускается в автоматический мини-тест; границы проверки поясняются в Quiz.

TOC и пререквизиты ведут к реальным целям; StreamLink сохраняет Pages base,
номера и ветку №13. Шпаргалка сворачивается и печатается. При печати видны все
шаги, включая ещё не открытые, а тёмная тема заменяется чёрным текстом на белом.
Проверены оба оформления и ширина 360 px; горизонтального переполнения нет.

Общий TaskFiles теперь выключает кнопку до готовности клиентского модуля.
Это устраняет потерянное нажатие при ленивом подключении файлов к примеру.
Генераторы, форматы M01–M16, критерии и экзаменационные фикстуры не изменены.
