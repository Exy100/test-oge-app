# T6.12 — практика из локального разбора

После завершения демонстрационного примера можно открыть поток по текущему
номеру задания. Практика открывается в новой вкладке. Решение новой задачи
обновляет общий прогресс, а исходная вкладка сохраняет ответ, черновик и разбор.
Регистрация и API не требуются; подбор основан на номере, а не анализе ИИ.

## Реализация и границы

`AiPanel` создаёт обычную ссылку через существующий `lessonStreamHref`.
В адресе только `numbers`, без исходного seed, ответа и черновика.
`target="_blank" rel="noopener"` и пояснение заранее сообщают об открытии
новой вкладки. Источник ответов, его контракт и безопасный рендер не менялись.
Во время загрузки, остановки, ошибки и после изменения черновика ссылка
недоступна. Для неё используются прежние стили с областью касания от 44 px.

Прежняя подписка `Stream` на общий прогресс размонтировала открытую карточку
после каждого результата из другой вкладки. Теперь обычное обновление
счётчиков сохраняет карточку и признак уже принятого результата. Переход
к следующей задаче читает актуальную статистику и не добавляет старый ответ.
Переходы, начатые до изменения общего прогресса, по-прежнему отменяются.
Если общий счётчик уменьшается после удаления данных или восстановления
более раннего прогресса, принятая карточка сбрасывается прежним способом.

Форматы экзамена №1–12, генераторы, ответы, оценка, схема хранения и правила
очереди повторений не менялись. Порядок локального среза — ADR-058;
реальное API T6.1–T6.10 и человеческие Gates остаются открытыми. Живой пилот
владелец отложил; его результаты не подставлялись.

## Проверки

Локально: 45 unit-тестов источника, безопасного потребителя и сохранения
прогресса прошли. TypeScript/Astro: 0 ошибок и предупреждений, два прежних
уведомления XMLValidator. Общий lint и Prettier прошли. Сборка создала
76 страниц и sitemap на 75 URL.

Браузерные проверки панели и прогресса: 34 успешных сценария в Chromium
и мобильном Chromium. Проверены оба тематических перехода, пропуск и решение
в новой вкладке, исходный черновик, отсутствие повторного зачёта и сохранность
тренировки. Прежние сценарии сброса, импорта, блокировки и заполнения хранилища
также прошли. Панель проходит axe в обеих темах при 200% текста и не создаёт
горизонтального переполнения; API и сторонних запросов нет.

Контент: 76 HTML / 313 исходников / 32 генератора / 24 кураторские задачи /
344 образца / 40 формул, 0 замечаний. Forbidden: 585 файлов, 0 нарушений.
Dist: 304 файла, секретных маркеров нет.

Полные проверки точного исходного коммита и итогового main с публикацией
Pages обязательны. Фактические результаты и ссылки на прогоны фиксируются
в PR без коммита с результатом собственного CI.
