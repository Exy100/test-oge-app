# T7.7: видимые номера команд исполнителя

На публичной странице materials/i5/executor-check/ у всех трёх примеров
списки команд имели вычисленный list-style-type:none. Номера присутствовали
в исходном Markdown и преобразовывались в ol/li, но сброс Tailwind скрывал
маркеры. Общая rich-text.css не восстанавливала оформление списков.

В общем контейнере .rich-text восстановлены decimal для ol и disc для ul,
добавлены внутренний отступ для маркеров и вертикальные интервалы. Условия,
алгоритмы проверки и соответствие номеров действиям не менялись. Исправление
используют уроки, практика, варианты и другие потребители RichText.

Регрессионный браузерный тест до изменения воспроизвёл none вместо decimal.
После изменения прошли 10 тестов rich-text в Chromium desktop/mobile,
включая проверку всех 12 примеров четырёх уроков И5, печатного режима и
клиентской карточки практики. Также прошли сборка 76 страниц, ESLint изменённого
теста, Prettier изменённых файлов и git diff --check.
