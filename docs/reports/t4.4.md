# T4.4 — подсказки, решение и типичные ошибки

Ученик открывает три подсказки по порядку и читает решение по одному шагу.
Код и формулы выводятся в читаемом безопасном виде; код решения можно скопировать.
Ответ, своя программа и черновик сохраняются. Неверный краткий ответ с известной
типичной ошибкой получает её пояснение сразу под полем. Справочник типичных ошибок
доступен отдельно, в том числе для практических работ.

Страница: https://exy100.github.io/test-oge-app/stream/

## Поведение

Помощь использует `hints`, `solution`, `commonMistakes` актуального экземпляра.
Видны только запрошенные подсказки и шаги решения. Начать решение можно без
обязательного открытия всех подсказок. Просмотр не изменяет результаты и очередь
ошибок. При смене задачи/попытки всё раскрытие сбрасывается.

Кнопки работают с клавиатуры и передают фокус на новый шаг. CSS-анимация раскрытия
отключается при reduced motion и в настройках. Отказ загрузки помощи сохраняет
карточку и черновик; запоздалый результат игнорируется после смены задачи.
Форматтер остаётся отложенным, поэтому стартовая карточка сохраняется в HTML.

Локальное пояснение использует вердикт существующего `checkTaskAnswer`:
нормализация едина, корректный ответ проверяется до списка ошибок. Форматная
ошибка не получает ложный диагноз и не считается попыткой; для неизвестной ошибки
причина не выдумывается. Справочник практики не назначает самооценку за ученика.

Несколько формул выявили повторные области с одинаковым названием. Их обёртка
заменена на доступную группу MathML с прежним tabindex, без создания landmarks.
Длинные блоки кода получили tabindex=0 для клавиатурной прокрутки.
Переполнение при 200% тексте в dev-галерее устранялось у поля seed, не у контента
задачи. Пороговые проверки и визуальные снимки сохранены.

  таблицы, MathML, буквальный код с обратными кавычками, XSS, границы шагов,

  загрузки. Публичный Python проверен с production CSP, сохранением кода/черновика,

- TypeScript/Astro: 0 ошибок; ESLint/Prettier, сборка шести страниц, запреты,
  инвентарь и 60 пар контраста (минимум 5,51:1) успешны. Контрактные строки

- Lighthouse: три прогона каждой из двух страниц, прежние бюджеты пройдены.
  Практика: performance 95–98, медианный LCP 2,41 с, CLS 0; пороги и способ
  агрегации сохранены.
