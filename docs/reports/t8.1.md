# T8.1 — 3D-база и объёмная схема битов

2026-10-25, Asia/Novosibirsk. Основа — main 9506b4f.

В двух существующих уроках о битах/байтах и кодовых таблицах доступна объёмная
схема остатка: восемь ячеек, прежние поля и точный расчёт. Переключение вида,
сбой загрузки и потеря контекста сохраняют введённое число. Без WebGL2 остаётся
тот же SVG; тяжёлый модуль не запрашивается. Новых экзаменационных допущений нет:
используется прежняя byteGroups. Это наглядная база, не одна из пяти игр с уровнями.

## Реализация MUST

| Требование | Файл/доказательство |
| --- | --- |
| Canvas, свет, dpr ≤2 | src/lib/three/SceneCanvas.tsx; настоящий буфер canvas при deviceScaleFactor 3 |
| three + R3F + drei | BitCells3D, выборочная регистрация классов, официальный createRoot и Center |
| Общий граф ≤250 КБ gzip | Бюджет всего статического графа в three-base.spec.ts; без снижения порога |
| Ленивая загрузка/WebGL2 | ThreeScene.tsx, capability.ts; ноль запросов 3D до выбора/без WebGL |
| Та же учебная функция в 2D | Общая byteGroups и SVG BitCells.tsx, прежние поля и текстовый расчёт |
| Пауза/reduced motion/вне экрана | Контракт InteractiveRuntime, режим demand; проверены нативные вызовы рисования |
| Ручное обновление при паузе | Изменение числа действительно рисует новый кадр |
| Ошибка/потеря контекста | Error boundary, fallback с прежним вводом и повтором |
| Dispose, 20 циклов | Нативный аудит buffers/programs/textures/shaders и других WebGL-объектов |
| FPS только в dev | Реальные кадры/с и gl.info.memory; строк монитора нет в production-графе |
| Клавиатура и доступность | Tab/пробел/стрелки, подписи canvas/SVG, axe двух тем на 360 px |

Стандартный Canvas регистрирует весь namespace three: предварительный замер
267 105 байт gzip не укладывался в 250 КБ. Официальный createRoot позволяет
подключать только используемые классы; стек и бюджет сохранены.
Закреплены three 0.186.1, R3F 9.8.2, drei 10.7.9 и типы three 0.186.0.

## Восстановление и каноническая проверка

Окружение стало недоступно перед сохранением коммита. Текст изменений восстановлен
из истории работы через GitHub API. Временная отдельная ветка с CI только для
форматирования и lock-файла не входит в итоговый срез. Она имеет contents: read
и не отправляет коммиты от имени workflow. Восстановленный срез прошёл полный
обычный CI со всеми unit, браузерами, Lighthouse, аудитом, файлами и исходными
визуальными эталонами. Канонический размер 3D-графа — **188 501 байт gzip**
при неизменном бюджете 250 000 байт; размеры выше сохранены как локальные замеры.
