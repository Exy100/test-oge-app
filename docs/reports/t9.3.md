Дата: 2026-10-26, Asia/Novosibirsk. Основа — опубликованный main `22d66ee`
([PR №9](https://github.com/Exy100/test-oge-app/pull/9),

Доставка T9.3 требует полного успешного CI итогового коммита и Pages из main.

## Реализация

- `scripts/security-headers.mjs` проверяет полный набор директив spec §12,
  запрещает дубликаты, пропуски и расширенные источники. Для каждого inline-блока
  вычисляет SHA-256 по фактическому UTF-8 содержимому; хэш должен присутствовать
  именно в `script-src` или `style-src`. CSP по-прежнему перемещается перед скриптами.
- `tests/fixtures/security-browser.ts` наблюдает за запросами контекста, WebSocket,
  CSP-событиями и сообщениями консоли с начала навигации; после сценария проверяет
  отсутствие cookies. CSP-события сохраняются в тестовом процессе и не теряются
  при переходах. Контроль не отключает политику и не подменяет ресурсы приложения.
- Контроль подключён к существующему полному обходу `a11y-site.spec.ts`:
  76 HTML, включая noindex и реальную 404, две темы, четыре браузерных профиля.
  Все отложенные 2D-интерактивы загружаются до завершения проверки.
  Он также подключён к существующим полным экзаменационным прохождениям
  №1–16 и сценариям ввода/клавиатуры потока, включая восстановление после ошибок.
- `security-journeys.spec.ts`: полные сохранённые фиксированный и случайный
  результаты, настоящий Worker, раскрытие всех 16 разборов и подготовка печати.
  HTML-подобный ответ/черновик остаётся текстом, внешний `img` не создаётся.
  Ещё пять сценариев включают настоящие 3D-сцены в Chromium/mobile, меняют уровень
  и тему, затем выключают сцену. Другие движки используют доступный WebGL/fallback.
- Три отрицательные пробы проверяют тот же контроль: реальные CSP-нарушения,
  сторонний запрос в изолированном документе без CSP и настоящая browser cookie.
  Ответ внешнего сервера подставляется Playwright, поэтому контрольный запрос
  не покидает тестовую среду. Во всех случаях защитный контроль обязан отказать.
- `scripts/check-dist-secrets.mjs` проверяет байты всех файлов, включая бинарные:
  маркер OpenRouter и блоки приватных ключей запрещены. `.env*`, symlink и пустой
  dist также приводят к ошибке. Значение найденного секрета не печатается.
  Команда `check:security` обязательна после сборки в `verify` и задании `quality`.
  Gitleaks по всей Git-истории и dist, npm audit и все прежние release gates сохранены.

## Трассировка и границы

| Требование | Реализация / проверка |
| --- | --- |
| spec §12: строгая CSP | build hook, unit CSP, браузерный полный обход и отрицательная проба |
| spec §12: секреты не попадают в сборку | check:security, Gitleaks history/dist, тесты бинарных файлов |
| spec §12: цепочка поставок | прежние lockfile, SHA действий/Gitleaks и обязательный npm audit |
| spec §13: без сторонних ресурсов и cookies | общий наблюдатель, все HTML/темы/профили, результаты и 3D, отрицательные пробы |
| spec §17: красный CI блокирует публикацию | quality + unit/coverage + files + шесть browsers + четыре performance → deploy |

Новые зависимости не добавлены; отклонений от spec нет. Экзаменационные форматы
№1–16 и матрица не меняются; полные результаты используют настоящие генераторы.
`currentPhase` остаётся 3. Gate 3–5/7/8/9 и предметные/ученические ревью остаются
открытыми. Фаза 6 отложена: тесты не подтверждают отсутствующий ИИ-прокси.
GitHub Pages не применяет `_headers`; ограничения ADR-001 сохраняются, HTTP-заголовки
проверяются только на локальном Cloudflare Pages runtime. Физический FPS,
скринридер, touch и пилоты этим срезом не подтверждаются.
