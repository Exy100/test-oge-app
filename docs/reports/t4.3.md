# T4.3 — фильтры практики и воспроизводимые ссылки

Ученик выбирает любые номера №1–16, тему, вычисленную сложность, повторение
ошибок и работу №13. Кнопка копирования передаёт точный экземпляр с фильтрами;
при запрете буфера обмена доступно поле для ручного копирования.

Страница: https://exy100.github.io/test-oge-app/stream/

## Поведение и границы

Выбор записывается в URL. Минимальная ссылка `task/seed` определяет номер и
ветку №13 по заданию. Явные противоречивые фильтры и некорректные параметры
отклоняются с понятным сообщением. Back/Forward восстанавливают карточку и
фильтры без добавления попытки, в том числе при возврате к исходному адресу
без query. Условие и архивы восстанавливает общее ядро.

Сложность сравнивается с реальным `TaskInstance.difficulty`, вычисленным по
данным генератора. Подбор проверяет до 16 seed на источник и все наборы банка.
Номера без кандидатов явно перечислены; выдача другой сложности или темы не
подменяет пустой результат. Формула 50/50 действует среди номеров с кандидатами,
а количество генераторов не становится весом номера. Это ограниченный поиск,
а не доказательство отсутствия подходящего seed во всём пространстве.

Повторение ошибок соблюдает очередь 3/10/30. Пустая очередь и оставшееся число
других заданий объясняются отдельно. Подходящая неотвеченная карточка сохраняется
при применении фильтров. Очередь до T4.5 остаётся в памяти вкладки и через ссылку
не передаётся. Прямая ссылка открывает конкретную задачу даже у получателя без
истории ошибок; следующие повторы используют его очередь.

Транзакционный переход сохраняет прежнюю карточку, ответ, черновик, адрес и
результаты при ошибке загрузки. Стартовая карточка остаётся в статическом HTML,
query восстанавливается после гидратации; ограничение без JavaScript объяснено.
Форматтер остаётся отложенным. CSP, зависимости, пороги и снимки не менялись.

- 73/73 unit: существующий движок, фильтры и URL. Проверены все 33 генератора,
  все 24 seed банков, Unicode/спецсимволы, 200 случайных seed ссылок, неверные
  границы, реальные темы/сложность всех 16 номеров, веса и очередь повторений.

  схему состояния. `configureStream` теперь переносит только собственные поля;
  отдельный тест защищает интеграцию. Подписи select связаны явно через id.
- 26/26 Playwright в Chromium и mobile, 29,8 с: выбор нескольких номеров,
  пустые фильтры, реальная сложность, история в обе стороны, копирование с обоими
  исходами Clipboard API, точные ZIP №13.2/14, очередь/ожидание/перезагрузка,
  ошибки ссылки и сбои загрузки. Обе темы: axe 0 нарушений; 360 px и 200% текст
  без горизонтального переполнения. Прежние публичные сценарии T4.2 также прошли.
- ESLint/Prettier, Astro/TypeScript (0 ошибок), production-сборка шести страниц,
  запреты, инвентарь и 60 пар контраста (минимум 5,51:1) успешны.
- Lighthouse: по три прогона главной и практики, все прежние бюджеты пройдены.
  Практика: performance 95–99, остальные категории 100; медианный LCP 1,96 с,
  CLS 0. Пороги и метод агрегации не менялись.
- Визуально проверена страница с открытыми фильтрами и отобранной задачей №2.
