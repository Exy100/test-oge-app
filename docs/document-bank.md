# №13.2: авторские документы

Банк `curated-documents-v2` содержит 12 наборов. Ученик получает неоформленный
ODT/TXT и визуальный `layout/sample.pdf`, затем воспроизводит образец в Writer.
PDF показывает тот же текст и таблицу; редактируемый ответ находится отдельно,
в `reference/answer.odt`. Прежний образец ODT с другим текстом заменён.

Воспроизводятся три структуры демоверсий:

| Семейство | Наборы | Операции |
|---|---|---|
| Описание D2025 | D01/D04/D07/D10 | Текст перед таблицей, объединённый заголовок, первый столбец слева, второй по центру |
| Инструкция D2026 | D02/D05/D08/D11 | Таблица перед текстом, два столбца заголовков, выделения |
| Разделы D2027 | D03/D06/D09/D12 | Два абзаца, одна таблица с двумя объединёнными строками разделов, первый столбец по центру, второй слева |

В D2027 одна таблица с разделами, а не две отдельные таблицы. В официальной
фикстуре исправлена прежняя ошибочная транскрипция. Все наборы: 14 пт,
заголовок прописными буквами по центру (для инструкции — полужирный и подчёркнутый), основной текст по ширине, первая строка
1 см; интервал 115% или 150%, промежутки 14 пт без пустых абзацев; таблица
15 см по центру при ширине основного текста 17 см, вертикальное выравнивание
по центру. Полужирные, курсивные и подчёркнутые фрагменты — реальные текстовые
выделения. Таблицы содержат настоящие ячейки, включая объединённые строки.

Критерии разделены на основной текст и таблицу. Допуски текстовых ошибок 5/3;
для 1 балла применяются официальные исключения по группам. Это самооценка,
а не автоматическая экспертиза произвольного файла. Для каждого набора есть
реальные ODT: только заголовок (0), полностью верный текст без таблицы (1),
полный эталон (2).

[Наборы и загрузки](../samples/13-2.md). `scripts/check-documents.py` независимо
проверяет XML, стили, объединения, порядок элементов, PDF-образцы и все 36 работ
в Writer/Poppler: текст, строки, столбцы, границы и одну страницу A4. Фиксированные
PDF принимаются валидатором только при полном совпадении с одним из 12 авторских
файлов; профиль импорта произвольных PDF не расширяется. Материалы CC0-1.0;
встроенные шрифты DejaVu сохраняют свою лицензию (Bitstream Vera / DejaVu).
