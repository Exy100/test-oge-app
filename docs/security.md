# Безопасность статической сборки

GitHub Pages применяет meta-CSP из каждой HTML-страницы и meta referrer.
Astro вычисляет SHA-256 для своих встроенных скриптов и стилей. Хук сборки
перемещает CSP сразу после charset, до первого скрипта. Внешние ресурсы,
неразрешённые встроенные скрипты и eval не разрешены политикой. Заголовок
frame-ancestors в meta не поддерживается и туда намеренно не добавляется.

`public/_headers` содержит все HTTP-заголовки spec §12. При сборке
`scripts/security-headers.mjs` добавляет в `dist/_headers` объединение хэшей
из CSP всех страниц. Небезопасный источник, отсутствие CSP или превышение
лимита строки Cloudflare прерывают сборку. Не редактировать выходной файл вручную.

GitHub Pages игнорирует `_headers`. Поэтому собственные HSTS, nosniff,
Permissions-Policy, COOP и запрет встраивания через frame-ancestors там не
гарантируются. Их наличие проверяется на локальном Cloudflare Pages runtime;
это не утверждение об HTTP-заголовках опубликованного GitHub-сайта (ADR-001).

## Проверка

`npm run build`, затем `npm run e2e` запускает также Wrangler Pages dev на
порту 4326. Временная копия `.cache/pages` воспроизводит базовый путь сайта;
она не публикуется. Cloudflare-аккаунт и токен для локальной проверки не нужны.
Wrangler закреплён в devDependencies. Playwright отключает его телеметрию.

Сценарии проверяют реальные HTTP-заголовки, работу практики и темы без ошибок
CSP, а отдельно на Astro preview — блокировку внедрённого inline-скрипта
через meta-CSP. Галерея `/dev/ui` не входит в production: CSP Astro не работает
на Vite dev server, поэтому проверяется собранный сайт.

ClientRouter заменён обычными переходами с CSS `@view-transition`: встроенная
CSP Astro не поддерживает этот маршрутизатор. При отсутствии поддержки API
переход остаётся обычным; reduced motion отключает анимацию. Theme-скрипт
работает до появления body и обновляет тему при возврате из bfcache.
