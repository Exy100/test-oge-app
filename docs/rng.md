# Воспроизводимый генератор T2.1

`src/core/rng.ts` — чистый TypeScript без платформенных зависимостей.
Версия алгоритма: `fnv1a-utf16le-mulberry32-v1` (`RNG_VERSION`).
Одинаковые seed и порядок вызовов дают одинаковые результаты. Изменение
алгоритма, хеша или расходования состояния требует новой версии: иначе
сохранённые параметры будущих задач перестанут воспроизводиться.

```ts
import { Rng } from '../src/core/rng';

const rng = new Rng('oge-2027/1');
const count = rng.int(2, 10);
const letters = rng.shuffle(['А', 'Б', 'В']);
const answerRng = rng.fork('answers');
```

## Контракты

- `hashSeed`: FNV-1a 32 бит по байтам UTF-16LE строки, младший байт первым.
  Нормализации Unicode нет; непарные суррогаты сохраняются. Пустая строка допустима.
- `Rng`: Mulberry32, целочисленные операции JavaScript и `Math.imul`.
  Это учебная псевдослучайность, не криптографический генератор. Хеш имеет
  32 бита: разные строки могут дать одинаковое состояние.
- `int(min, max)`: обе границы включены и являются safe integer; ширина не
  больше 2^32. Rejection sampling исключает смещение от остатка при делении.
  Числовой результат конечен; отрицательный ноль преобразуется в обычный.
- `pick(items)`: выбор из непустого плотного массива; значение может быть
  `undefined`. Возвращается исходный элемент, без клонирования объектов.
- `shuffle(items)`: Fisher–Yates, новый массив, исходный не изменяется;
  ссылки на элементы и их кратности сохраняются. Входной массив плотный.
- `chance(p)`: конечная вероятность от 0 до 1 включительно.
- `weighted([{ value, weight }])`: конечные неотрицательные веса, хотя бы один
  положительный. Нулевой вес никогда не выбирается. Нормализация на наибольший
  вес предотвращает переполнение суммы больших весов. Вычисления ограничены
  точностью Number и 32-битным случайным значением; крайне малые относительные
  веса могут округляться до нуля. Это не точная рациональная арифметика.
- `fork(label)`: новый RNG от `JSON.stringify([исходныйSeed, label])`.
  Метка — строка. Положение родителя не влияет на ветку; создание и использование
  ветки не расходуют родителя. Одинаковая метка повторяет ту же ветку.
  JSON-разделение исключает неоднозначность простого склеивания строк,
  но не исключает коллизии 32-битного хеша.

`int(x, x)`, выбор единственного элемента, перемешивание 0–1 элементов,
`chance(0)` и `chance(1)` не расходуют состояние. `weighted` расходует одно
случайное число даже при единственном положительном весе. Ошибочные числовые
параметры, пустой `pick` и недопустимые веса отклоняются до расходования состояния.

## Проверки

- Эталонные хеши и последовательности для пустой строки, ASCII и кириллицы
  с emoji; смешанные вызовы и независимость именованных веток.
- Границы safe integer, диапазон 2^32, диапазон с частыми отбрасываниями,
  недопустимые числа, отсутствие отрицательного нуля, неизменность массивов.
- `int`: 100 000 выборок, 10 корзин, χ² < 27.877 (9 степеней свободы, α = 0.001).
- `weighted`: 100 000 выборок с весами 1:3:6 и нулевым весом,
  χ² < 13.816 (2 степени свободы, α = 0.001).
- Один смешанный сценарий на семи seed сравнивается с Node в реальном workerd
  через Miniflare и в браузерах Playwright. Для них встроенный Node
  `stripTypeScriptTypes` удаляет только типы из того же исходного кода;
  отдельной копии алгоритма нет.

Команды: `npm run verify` и `npm run e2e`. Статистические проверки используют
фиксированные seed и не являются доказательством криптографических свойств.
Подключение к генераторам заданий и сохранённым ссылкам — последующие шаги.
