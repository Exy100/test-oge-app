# UI-кит

Компоненты находятся в `src/components/ui/`. Они используют общие CSS-токены,
React и нативные элементы браузера, без дополнительных зависимостей. Импортируй
нужный компонент непосредственно из его файла: главная использует только Button,
Card и Badge. Интерактивная галерея всех компонентов доступна на `/dev/ui/` только
в режиме `npm run dev`.

| Компонент | Контракт и состояния |
| --- | --- |
| Button | `variant`: primary, secondary, text; `size`: sm, md, lg. По умолчанию `type=button`. `loading` устанавливает disabled и aria-busy, показывает индикатор и доступный текст. Поддерживает нативные атрибуты и ref. |
| Card | Неинтерактивный контейнер, `tone`: surface или soft. Заголовок и действия передаются детьми; не добавляет лишнего landmark. |
| Tabs | `label`, уникальные `items` с value/label/content/disabled, необязательный defaultValue. Автоматическая активация стрелками, Home/End, пропуск отключённых пунктов. Содержимое неактивных панелей скрыто, состояние ввода сохраняется. |
| Modal | Управляемый `open`, title, description, onClose и children. Native dialog/showModal: фон становится inert. Фокус сначала на заголовке, Tab/Shift+Tab остаются внутри, Esc и кнопка закрытия вызывают onClose. При закрытии или размонтировании фокус возвращается инициатору, если он ещё в документе. |
| Tooltip | `label` кнопки и `text` пояснения. Наведение, фокус или касание открывают текст. Можно навести указатель на панель, Esc закрывает её; уход фокуса и указателя либо касание вне панели закрывают её. Не помещать в tooltip необходимые инструкции или интерактивные элементы. |
| Toast | Управляемые message (null означает отсутствие сообщения), tone: info/success/error, onDismiss. Постоянные live regions status/alert. Не скрывается по таймеру, закрытие возвращает фокус инициатору. |
| Disclosure | Нативные details/summary, summary, children, defaultOpen. Работает также до загрузки React. Enter/Space переключают состояние. |
| Badge | Текстовая метка, tone: neutral/accent/success/error. Цвет дополняет текст; компонент не создаёт live region. |
| ProgressBar | Доступный label, max > 0, конечное value. Значение ограничивается диапазоном 0…max; отсутствие value даёт неопределённый прогресс. Используется нативный progress. |
| Kbd | Семантический kbd; клавиши показываются текстом, без дополнительных обработчиков и остановок Tab. |
| Skeleton | Доступный label загрузки и 1–3 декоративные строки. aria-busy=true. Намеренно статичен, не требует анимации для понимания состояния. |
| SegmentedControl | Управляемые value/onValueChange, label, options, disabled. Нативная группа radio с уникальным внутренним именем. Четыре стрелки переключают выбор и фокус по кругу, пропуская disabled; явный обработчик согласует переход через границу группы в WebKit. Значения options должны быть уникальны. |
| Slider | Управляемые value/onValueChange, label, min/max/step, unit и disabled. Нативный range: стрелки, Home/End и доступное численное значение. Подпись согласована с сеткой шага, даже если max между шагами. Некорректный диапазон отвергается. |
| NumberInput | Нативный input type=number, label, hint, error, все обычные атрибуты и ref. Required/min/max/step/readOnly/disabled задаёт вызывающая форма. Текст error связывается с полем и включает aria-invalid; бизнес-валидация остаётся у формы. |

Размер sm также сохраняет высоту цели не меньше 44 px. Для Modal и Toast передавай
`returnFocusRef` на инициатор
действия: это сохраняет правильный возврат фокуса также в Safari, где щелчок
по кнопке не обязательно фокусирует её. Без ref используется предыдущий фокус.
Все цвета взяты из
проверенной палитры; описание ошибки проверяется на фонах canvas/surface/soft.
Новые сочетания цветов добавляются в матрицу `scripts/check-contrast.mjs`.
Анимация индикатора загрузки отключается при prefers-reduced-motion.

Уведомление не заменяет ошибку у поля. В форме сначала проверь native validity,
задай понятное русское сообщение и переведи фокус на ошибочное поле. NumberInput
не предназначен для экзаменационных ответов с ведущими нулями или произвольной
целочисленной точностью: в текущей практике сохранён текстовый ввод и существующая
проверка BigInt.

## Галерея и проверки

`src/dev/UiGallery.tsx` показывает все 14 компонентов и их состояния: варианты,
размеры, loading/disabled, открытые и закрытые панели, уведомления трёх типов,
пустой/частичный/полный/неопределённый прогресс, поля с ошибкой, обязательные,
дробные, только для чтения и отключённые. Значения в галерее — явно обозначенные
примеры, не статистика ученика. Её код не включается в production-маршруты.

В `tests/e2e/ui-kit.spec.ts` есть отдельный сценарий на каждый компонент, а также
axe для открытых состояний в обеих темах и проверка при 200% тексте на 360 px.
Проверяются реальные события, состояние ввода, последовательность фокуса и
границы чисел. Эти сценарии запускаются во всех четырёх проектах Playwright.
`tests/unit/ui-range.test.ts` проверяет дробный шаг, смещённый и отрицательный
диапазоны, границы между шагами и отказ при некорректных параметрах.

Команды: `npm run verify`, `npm run e2e`, `npm run lh`.

В CI встроенный GitHub reporter публикует подробности упавших браузерных проверок
как аннотации к исходникам. Это дополняет обычный вывод и сохранённые trace-артефакты,
не меняет число сценариев, повторы или критерии успеха.


Modal синхронизирует `showModal`/`close` в layout effect до следующей отрисовки.
Нативный `close` обрабатывается только для действительно закрытого текущего
окна. Позднее событие предыдущего закрытия не меняет состояние нового открытия.
Нативное `dialog.close()` также синхронизирует управляемое состояние и возвращает
фокус. Это проверяется отдельным браузерным регрессионным сценарием.
