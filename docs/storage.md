# Браузерное хранилище и настройки

Страница `/settings/` меняет тему, размер шрифта (100/125/150/200%), анимации
и предпочтение разбора с ИИ. Настройки действуют на всех страницах, синхронизируются
между вкладками и применяются до отображения страницы. Системное уменьшение
движения имеет приоритет. Без JavaScript страница объясняет ограничения,
элементы изменения данных отключены.

`src/core/storage/schemas.ts` задаёт строгие Zod-схемы семи областей. Ключи
`oge:informatics:v1:<area>`, каждый объект содержит `version: 1`:

- `settings`: тема, процент размера шрифта, анимации.
- `streamStats`: попытки, верные ответы, последняя активность по номеру.
- `reviewQueue`: generatorId, seed, номер, шаг повторения 3/10/30 и dueAfter.
- `variantAttempts`: ответы, выбор №13, время, балл и происхождение самооценок.
- `variantDraft`: текущая незавершённая попытка или null.
- `lessonProgress`: мини-тесты, завершение уроков и уровни игр.
- `aiConsent`: предпочтение предлагать разбор с ИИ, по умолчанию выключено.

Последнее поле **не является согласием на отправку данных неизвестному провайдеру**.
Сервис ИИ ещё не подключён. Перед первой передачей необходим отдельный экран
с провайдером, составом отправляемых данных и подтверждением (фаза 7).
Импорт этого предпочтения не разрешает сетевой запрос.

`LocalStore` предоставляет read/write/snapshot/replace/clear/subscribe/refresh.
Он возвращает копии данных и проверяет запись до изменения состояния. Повреждённая
область сбрасывается отдельно с уведомлением. Ошибка доступа или квоты переводит
весь экземпляр в память страницы с баннером; экспорт читает именно актуальную память.
Переход на другую страницу/перезагрузка может потерять несохранённые изменения.
При ошибке удаления интерфейс сообщает, что часть постоянных данных могла остаться.
Удаляются только известные ключи проекта; `localStorage.clear()` не используется.

Миграции: реальный старый ключ `oge.theme` → settings v1; также поддерживается
минимальный объект settings v0 `{version:0, theme}`. Новый корректный settings
имеет приоритет. Все области читаются до записи миграций: квота не должна стирать
уже прочитанные данные. Legacy удаляется после успешной записи новой настройки.

Экспорт — строгий JSON `{format:'oge-informatics', version:1, areas, aiCache}`.
Импорт сначала проверяет весь файл, затем требует подтверждения замены. Невалидный
JSON, неизвестная версия, лишние поля и превышение лимитов отклоняются.
Для семи постоянных областей импорт использует полный журнал `transaction`:
он записывается до областей и удаляется после них. Незавершённый журнал является
источником восстановления при следующем открытии. Если даже журнал не помещается,
постоянные области не изменяются, новая копия остаётся в памяти с уведомлением.
Кэш текущей вкладки относится к отдельному временному sessionStorage.

Ограничения: файл до 2 000 000 байт; постоянные области суммарно до 1 300 000 байт;
код/ответ до 20 000 символов, рассуждение до 1500. Максимум 100 попыток, 1000
повторений, 500 записей уроков. Исходные офисные файлы и поля для персональных
сведений отсутствуют; сохраняются учебные ответы и идентификаторы наборов/вариантов.

`SessionCache`: отдельный `oge:informatics:v1:aiCache` в sessionStorage,
ключ записи — `(mode, taskId, SHA-256(ответа))`. Исходный ответ в ключе не хранится.
До 30 записей и 500 000 байт; старые записи вытесняются, один ответ ИИ ограничен
20 000 символами. При запрете хранения кэш работает в памяти. В экспорт включён
кэш текущей вкладки, удаление очищает его вместе с постоянными областями.

Функциональные страницы потока, вариантов и уроков используют этот API на своих
этапах. Счётчик базовой практики на главной пока остаётся в памяти страницы:
T2.8 не подменяет его полноценной статистикой будущего потока.
